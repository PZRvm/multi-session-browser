    移动到工作区

    交互裁定注记（实装前确认）：①混合归属 = 幂等赋值，已在目标工作区的勾选会话静默跳过，弹层目标按钮右侧计数展示「勾选中在该工作区 / 勾选总数」；②「移出（未分组）」仅在勾选中存在非未分组归属时显示；③移动成功后清空勾选并保持批量态，反馈条短暂显示（约 2.4s 淡出）。

    响应式双形态：面板宽度 <~300px 时文字钮降级为 20×20 图标钮（点右上「面板宽度」切换体验；实装由 App 的 panelWidth 状态驱动，非媒体查询——板头外观入口先例）。

    器件来源：批量操作栏 / 复选框 / ws-tag / 翻牌计数均为既有器件原样；新增仅「移动到工作区…」次级钮与弹层计数徽标；弹层为产品内 antd Modal（移动弹层）形态近似——实装复用既有 Modal，不新造器件。次级钮语义 = 组织动作，不进第二行主钮位（板脚唯一大面积强调色惯例）。
