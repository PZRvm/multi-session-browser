# ADR-012 截图插件单次点击授权

截图插件应先写入系统剪贴板，再显示工具栏 Popover。普通 Chrome 使用扩展 Worker 和原生 action Popover。Electron 的后台剪贴板写入由主进程承担，结果承载复用扩展工具栏 Popover。

Electron 由可信工具栏点击签发短期授权，绑定实际扩展、会话分区、窗口、标签和按钮位置。采集与复制只接受该授权一次，主进程从绑定标签取得原始 PNG。结果状态由主进程的采集与写入回执限制。Worker 提交原图 ID 后，主进程在同一个工具栏锚点显示结果。来源失效时结束本次交互。

截图数据属于来源扩展分区，剪贴板是本次点击的系统出口。该决定沿用宿主的受限预加载和内置 PNG 写入机制。 [扩展预加载边界](ADR-006-host-owned-extension-preloads.md) · [实现与验证](../../plans/2026-11-27-截图插件结果弹窗与编辑器适配.md)
