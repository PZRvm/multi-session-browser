# ADR-006：宿主创建受限扩展 preload

状态：Accepted，2026-11-13。对应 L 级 UA 与 Worker 隔离修复计划。

## 背景

electron-chrome-extensions 4.10.0 构造器会立即注册两个无 URL 过滤的 preload。宿主随后异步生成和替换文件，普通网站 SW 因而会接收兼容桥。持久 SW 可在等待期间恢复，构造后同步替换也不足以证明不存在执行窗口。

## 决定

采用调研方案 C。固定版本的安装补丁取消库构造器默认注册，改为在其他副作用前校验宿主已有两条仅匹配扩展来源的注册。宿主先生成脚本，再受限注册，再构造引擎；过滤使用 Electron 45.3 原生 includeGlobs，不新增来源握手。

产品名称与网络 UA 分开管理，默认 UA 使用真实 Chromium 主版本和运行时平台前缀。Client Hints 保留引擎真实信息。

## 后果

首次注册起即受限，生成失败不产生注册，普通网页不需要暂停或删除已有 SW。库升级必须复核补丁锚点、版本与正反例；补丁安装/构建失败必须报错，生产挂载也验证补丁标记。不增加第三方依赖，不直接把未归档的 node_modules 修改作为交付。

保留主进程 scope/扩展 ID/Session 校验和合法 content scripts。既有存活 SW 中已暴露对象须正常重启应用后消失，不能靠改注册撤销已暴露对象。

## 2026-11-14 构造异常恢复边界

依赖没有可靠释放接口，构造中段抛错后不尝试清私有单例或重复构造。以进程级 Session 弱映射记录需重启状态，正常撤销本轮注册；后续请求在生成/注册前拒绝，原生提示每 Session 一次。生成/注册阶段错误仍可重试，已有健康实例冲突不污染原实例。原始 cause 与清理/提示失败诊断保留，不自动重启。R1 按此明确策略关闭。
