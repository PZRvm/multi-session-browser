# ADR-004 应用更新所有权和安装交接

状态：采用，2026-11-13；实现及实机验收由应用自动更新计划跟踪。

Windows 复用 electron-updater；Mac 引擎与信任由 [ADR-005](ADR-005-macos-sparkle-update.md) 替代；主进程持有单例，renderer 仅镜像递增 revision 快照和发意图。可信来源为登记的主窗、独立窗、设置窗顶层 frame。构建策略不可由设置写入；双隐藏不联网。

安装必须经过原生确认、录屏 busy 复核、写命令排空、恢复集和历史严格保存。普通退出容错不承担安装成功判定。保存失败恢复定时写入；超时保留互斥直到底层任务落定，不把 Promise.race 当取消。调用 quitAndInstall 前设专用退出标志，错误时恢复。第三方不可观察录屏不宣称可全面保护；自研 offscreen 保守判忙。

历史 Mac Developer ID / 公证门禁由 ADR-005 的 EdDSA 门禁替代。本决定的主进程所有权、严格保存和禁用策略继续有效；验证证据仍必须区分原型、产品隔离升级与真实数据验收。
