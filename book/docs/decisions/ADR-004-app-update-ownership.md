# ADR-004 应用更新所有权和安装交接

状态：采用，2026-11-13；实现及实机验收由应用自动更新计划跟踪。

复用 electron-updater；主进程持有单例，renderer 仅镜像递增 revision 快照和发意图。可信来源为登记的主窗、独立窗、设置窗顶层 frame。构建策略不可由设置写入；双隐藏不联网。

安装必须经过原生确认、录屏 busy 复核、写命令排空、恢复集和历史严格保存。普通退出容错不承担安装成功判定。保存失败恢复定时写入；超时保留互斥直到底层任务落定，不把 Promise.race 当取消。调用 quitAndInstall 前设专用退出标志，错误时恢复。第三方不可观察录屏不宣称可全面保护；自研 offscreen 保守判忙。

Mac 正式发布缺 Developer ID 与公证材料即失败。当前用户没有材料，所以本地验证与真实签名升级分列，不能用临时签名声称完成升级验收。
