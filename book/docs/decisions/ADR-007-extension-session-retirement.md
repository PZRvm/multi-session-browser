# ADR-007：永久删除的扩展 Session 不可重用

两轮基线复现表明仅清网页与分区目录会被全局安装重挂载复生。永久删除必须先同步封闭扩展入口、排空 pending mount/路径解析，再撤销桥、SW shim/preload、卸载扩展与清分区副本/登记。普通关闭与克隆保留可恢复语义，不以共用的 session-gone 事件触发永久回收。

固定 electron-chrome-extensions 4.10.0 没有完整公开 disposer；本轮不写不确定的私有释放补丁，也不把删除宿主 Map 当作全部释放。库内部 WeakMap/observer 对象保留到进程退出，但相应 Session 永久拒绝宿主挂载与特权桥；扩展已卸载、页面已关闭，不重构该 Session 引擎。此边界是有意保留的内存代价，不是同进程恢复能力。

删除元数据前先检查录制和排空，忙碌或失败保留列表与网页数据；元数据成功提交后，清盘失败必须通过原生错误框及 invoke 拒绝报告，不恢复可重新挂载的会话。终止超时保持封锁，内部清理可重试。全局包和其他分区不删除。

2026-11-16：普通关闭新增可恢复暂停，排空后卸载原生扩展，保留引擎和控制记录；激活时 resume 重载。暂停表仅供管理清理，不允许全局安装将其自动激活，见 ADR-008。
