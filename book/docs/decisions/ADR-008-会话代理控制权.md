# ADR-008：会话代理只有一个应用入口

内置非空手动配置优先；清除后选已加载且声明 proxy 权限的扩展，可信安装 generation 较新者优先，同序按 ID 决胜。插件可保留待生效配置，get 返回当前有效配置及真实 levelOfControl。配置保存在私有 userData/extensions/proxy-settings.json v1，不改 sessions.json。

插件 frame/SW 的原生 Session 和扩展身份决定授权，不信任 payload ID。只支持 regular，拒绝 incognito；支持 set/get/clear/onChange/onProxyError 与 callback/Promise。配置严格校验、队列串行、原生应用成功后原子落盘，落盘失败回退旧原生配置；回退失败阻断网络。全局卸载清除未激活和暂停分区的控制记录，永久删除清掉该会话记录。临时探测结束恢复合成后的有效配置。

mandatory PAC 交给 Chromium 执行；URL 有下载大小、超时和重定向限制，脚本结果附随机尾标，宿主只放行 resolveProxy 返回有效尾标的请求。错误或超时取消，不静默直连。主进程不 eval PAC。持久控制扩展暂缺时阻断网络，手动覆盖仍有效。

代理屏障仅处理 HTTP(S)/WS(S)，不拦截 chrome-extension 资源，否则切换代理会破坏后台初始化。MV2 非隔离背景使用来源已受原生过滤的桥；不放宽网站隔离。普通关闭先暂停入口、排空、卸载，重新激活再加载；保留库引擎，不调用不存在的完整 disposer。

已验收的样本与平台见[代理计划](../../plans/2026-11-15-代理插件兼容层.md)。不宣称 Chrome 全量 API、Windows 实机或认证成功路径已通过。
