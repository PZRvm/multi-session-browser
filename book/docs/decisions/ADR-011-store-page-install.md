# ADR-011：商店详情页自有安装按钮

2026-11-17用户明确选择同页自有按钮，确认全局安装与分区隔离运行。原按钮适配方案不实施。

按钮由独立storePreload在商店顶层文档创建，Shadow DOM隔离样式；既有官方按钮和UA均不修改。不要求用户安装伴随插件，不把应用window.api开放给网页。

manager先对Session注册仅匹配官方HTTPS商店的frame preload，再登记实际网页及动态父窗。主进程每次验证目标登记、来源主frame、精确origin、详情ID和生命周期；确认期间导航代号变化则撤销。只有status/install两条通道，禁止远程页面传文件路径、下载URL或任意IPC名称。

安装共用现有下载验签、全局清单与分区挂载，原生确认归属发起页面所在窗口。同ID单飞，安装和导入/卸载写事务协调；不引入第二套安装器。已确认后安装是全局操作，完成前页面离开时不向新页面弹结果。某分区加载失败须报错并广播清单变化。

代价：当前页面状态通过750ms轮询同步，仅商店详情页查询；商店页面自身可影响其DOM，按钮不能保证在网页主动破坏DOM时不可移除。固定下载源继续沿用原Node fetch策略，本轮没有更改代理路由。安装能力与插件运行兼容继续分别验收。
