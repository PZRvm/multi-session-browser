# 插件宿主协议草案

本文件自2026-11-10起冻结为**协议v1**，冻结范围与例外见文末冻结记录。Mac主要功能、商店安装卸载、全套编辑器Chrome适配、整段音频/同步和生命周期已通过，边录边听人耳确认已通过（用户回复“能听到”），见[最新结果](../../notes/summary/2026-11/20261110-非Windows插件补验结果.md)。统一信封、16项真实IPC（含PNG二进制往返、同分区未知第三方扩展拒绝与来源导航撤销）和后建C分区加载屏障已在夹具验证；生产shared/preload没有扩展入口，录屏订阅及finalizing模型只在工具内对账，生产未接线。Windows未测，跨平台能力保持unknown；接口形状冻结不受此影响。

## 已验证的技术分工

普通 Chrome 使用标准扩展 API：截图 `tabs.captureVisibleTab`，录制 `tabCapture` → `offscreen` → `MediaRecorder`。Electron 使用受限宿主桥：目标 `webContents.capturePage`、同分区可信采集器向指定 `WebFrameMain` 获取画面和音频，再用同一 Web 录制器编码。macOS 两端均生成 H264/AAC MP4；其他系统不能据此推定支持。

`electron-chrome-extensions@4.10.0`与`electron-chrome-web-store@0.13.0`为锁定实验候选，均MIT；尚未加入正式依赖。三款原版主要功能与第二窗口实测通过；原版React有上游SVG错误，独立fork实测零目标错误。商店安装卸载已完成最终页面确认，下载必须继续走自有验签边界，不能直接信任上游安装器。

## 公共信封与身份

工具已经检查的最小请求：

```json
{"protocol":1,"requestId":"req-1","method":"capture","target":"target-a"}
```

`protocol` 当前只接受 1；`requestId` 为 1—128 位字母、数字、下划线或短横线；方法为固定枚举。`target` 必须等于宿主绑定的、仍存活的目标 token。示例 token 仅为夹具，生产需宿主生成不可预测 token，并与扩展 ID、窗口、Session、Tab 和有效期绑定。

Electron不能相信payload自报来源：IPC核对event.sender、senderFrame、顶层frame、Session和宿主持有的目标。当前16项真实IPC包含握手、真实PNG二进制往返复制、摘要篡改/坏头拒绝、有效/过期/交错快照、未知能力/requestId/伪造目标/错误协议/失效目标/跨分区未知来源拒绝、同分区未知第三方扩展UNAUTHORIZED、来源导航撤销。跨源子frame无桥且SOP拒绝访问顶层桥，不能算作已经发出的非法IPC。跨窗口搬迁仍需生产适配验证。

工具已实现的返回格式（生产尚未接入）：

```json
{"protocol":1,"requestId":"req-1","ok":false,"error":{"code":"TARGET_GONE"}}
```

固定错误码包括`UNAUTHORIZED`、`PROTOCOL_UNSUPPORTED`、`INVALID_REQUEST`、`CAPABILITY_UNSUPPORTED`、`TARGET_GONE`、`SNAPSHOT_STALE`、`BUSY`、`INVALID_STATE`、`TIMEOUT`和`CANCELLED`；未知异常编码INTERNAL。非法requestId回传null，不返回异常消息、堆栈或路径。生产错误码与i18n展示分开。

`protocol-v1.mjs`的工具端点限制单请求JSON≤4096字节、每个目标最多128个requestId；同ID相同JSON复用原Promise，不重复操作，同ID不同JSON拒绝，账本满返回BUSY。关闭端点撤销所有请求并清空账本，不跨目标复用。按JSON字节序列比较，不声称字段重排等价。

默认超时5000ms，超时/取消/关闭会abort并屏蔽晚到结果；执行前已取消的操作不再启动，异步返回前重新检查目标。已经提交的文件和剪贴板副作用不能靠取消回滚，生产操作必须在提交点检查signal并定义事务。`check-protocol.mjs`验证这些边界，不能代替生产事务验收。

## 四组候选接口

| 组 | 候选操作与数据 | 当前实证 / 未决项 |
| --- | --- | --- |
| 安装清单 | ID、version、source、sha256、generation 与各 partition 的加载结果 | 真包验签/解包、重复去重和同版本冲突保留旧包已断言；`checkInstallRecord` 已断言 id/version/sha256/source/generation 与分区代次一致，`ready/partial/failed/not-loaded` 已分类。后建分区加载屏障已用真实样本在夹具验证（C分区首导航屏障、三插件可用、不污染A/B），非生产安装器已接线。全局持久清单、升级回滚、并发尚未实现 |
| 动作目标 | handshake、宿主target token、权限、动作路由 | 16项真实IPC（握手、二进制往返、篡改/坏头拒绝、快照有效/过期/交错、来源导航撤销、同分区未知第三方扩展拒绝），统一信封与部分能力握手；完整权限声明和状态订阅未实现，状态订阅/finalizing仅在工具模型对账 |
| 截图编辑 | capture→snapshotId/version与尺寸/PNG；image.copy/image.save | 两端PNG复制/下载，完整生产编辑器Chrome适配8项通过；有效/旧版/交错快照与PNG二进制往返/摘要篡改/坏头拒绝均为真实IPC检查。PNG二进制走同一invoke的独立ArrayBuffer参数，单图≤32MiB、像素≤64Mi、并行暂存≤64MiB完成后释放；摘要参与幂等指纹，真实解码后才复制。统一大图分块传输仍未实现 |
| 录屏音频 | start/pause/resume/stop/status、audio、状态订阅 | 两端H264/AAC、同步和整段隔离通过；6项真实媒体生命周期通过。finalizing/finish/订阅/取消订阅/晚到已在工具模型与真实PNG对账（check-schema）；生产 settle 在 drain/finalize 之前已推 idle（src/main/browser/recording/index.ts:161），与新模型不一致，接线时需迁移，不能说生产已对齐 |

握手必须逐项声明能力。当前真实IPC夹具只声明capture/imageCopy为true，tabAudio/subscription为false；真实音频另在媒体探测链路验证，不能据此声称已接同一端点。

请求信封的局部语义已有执行检查。事件订阅/取消订阅、录制finalizing已在工具模型（contracts.mjs createRecordingModel）与check-schema对账；生产全局安装事务由任务B实现；接口形状已于2026-11-10冻结为v1，实现进度不改变契约，例外见文末冻结记录。录制generation模型与真实媒体生命周期是两类证据，均保留各自范围。真实IPC链路未复验信封幂等命中/同ID不同JSON冲突（invoke助手每次递增requestId绕开了这两条路径），该语义仅工具端断言，见审阅记录。

## 全套编辑器迁移依赖

`editor-fixture.tsx`已实际复用生产EditorWindow、AnnotationStage、EditorToolbar及Konva历史状态，在Chrome内通过全套工具、撤销重做、裁剪、真实PNG剪贴板和下载检查。适配器只实现getEditImage/editCopy/editDownload：图像输入带captureId，Chrome用Clipboard API及下载，不依赖本地绝对路径。正式扩展构建、文件选择、i18n初始化和大图限制仍在后续产品范围；本轮适配夹具不是已交付的截图插件。

用户确认前置阶段按macOS收尾后，本契约冻结为v1。冻结范围：公共信封与固定错误码、四组接口的字段与语义（安装记录schema与分区代次、目标token与16项IPC守卫、图像二进制边界32MiB/64Mi像素/64MiB暂存、录屏状态机含finalizing/finish与订阅seq/取消订阅）、A—E文件所有权方向。
