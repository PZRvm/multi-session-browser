应用外观三模式专项

为整个应用程序增加统一的外观模式设置，支持“跟随系统”“白天”“黑夜”三种选择。

- 首次使用默认“跟随系统”；系统明暗主题变化时，应用无需重启即可同步。
- 用户显式选择白天或黑夜后，应用保持该选择，不再随系统变化；软件重启后选择不丢失。
- 切换应覆盖应用壳、Electron 原生界面和原生 DevTools；支持 `prefers-color-scheme` 的被测页面按 Chromium 当前主题响应，不对网页注入强制暗色 CSS。
- 切换主题不得刷新页面、重建 Tab、切换会话、清除登录态或破坏一会话一分区的隔离规则。
- 左侧“到发信息板”和右侧 Chrome 风格浏览器区都必须提供完整的亮、暗配色；继续遵守琥珀信号、行式栅格、无阴影和 Chrome 交互惯例。
- 设置入口保持紧凑、纯中文，在零会话和批量操作状态下均可使用。
