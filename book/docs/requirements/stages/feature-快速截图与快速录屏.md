# 快速截图与快速录屏专项

为浏览器区增加测试取证能力：一键截图（剪贴板 + 下载双出口）、一键录屏（仅下载，可暂停续录），详细规则见 PRD 3\.10/4\.13。作用域定稿（用户裁决「注意力只在一个会话中」）：始终作用于当前激活会话的当前激活 Tab，不跨 Tab 不跨会话，全应用同一时刻至多一个录制。

- 入口：工具栏图标钮两枚，并列置于开发者工具按钮左侧（自左向右 截图、录屏、开发者工具），主窗与独立窗口同规；悬停显示 popover（功能名＋已设快捷键键帽；反馈五定稿：**始终出现在 icon 正上方**——手写固定定位深色气泡（rgba(0,0,0,.85) 白字 + 下向箭头）钉在按钮上方 Tab 条壳层高度带内，壳层无页面原生层遮挡天然不被网页盖住；悬停方案迭代史（antd 弹层被盖/自动翻转 → 手写弹层同被盖 → 原生子窗 hint 复核回退 → 原生 title 位置不可控）均退役，仅壳层带内 DOM 弹层可行）；截图反馈条为**原生子窗全宽通知条**（建议面板同机制承载：贴导航栏下方覆盖在网页上方、Chrome 通知条形态、内容区布局零压缩、显隐瞬时无回弹空白——反馈三定稿+同日复核修正，停靠压缩版/胶囊右上/overlay 弹层方案均退役）；界面细节走 impeccable polish 定稿落 DESIGN.md
- 截图：`capturePage()` 截当前 Tab 可视区，无弹窗不打断；默认复制进剪贴板，反馈条带「下载」次动作按需落盘 PNG；直写系统下载目录不弹另存框，命名锚定会话名＋时间戳（非法字符清洗、同名追加序号不覆盖）
- 快捷键：默认**无**；设置窗新增「快捷键」项（3\.8\.2 扩展）自定义，与既有快捷键冲突拒绝、清除恢复「无」、即时生效并持久化（应用级偏好，4\.9 同规）；设置后页面聚焦态与界面聚焦态均可触发（同页内查找双通道口径）；录屏本期无快捷键
- 录屏：点击录制当前 Tab 画面流，按钮呈录制态（红点＋累计时长）；可暂停/恢复（暂停不落帧不计时长），输出单个 WebM 直落下载目录；完成反馈原生信息框，失败如实报错无半截文件
- 采集方向（契约方向，开发计划定稿）：优先 `getDisplayMedia` + `setDisplayMediaRequestHandler` 授予被录 Tab 的 frame（WebFrameMain），走 Chromium tab capture 管线——只录页面画布且 macOS 免屏幕录制 TCC 授权；兜底 desktopCapturer 窗口源＋裁切（需 TCC 与 dev 重签，同摄像头权限验收先例），仅前者验证失败才取。MediaRecorder 留渲染层，视频块经 IPC 流式交主进程写文件
- 生命周期：录制为主进程运行态，不持久化，重启恢复空闲；关被录 Tab、切 Tab/切会话、拖出独立窗口、删除该会话均自动停止并保存已录内容，同 Tab 导航不中断；录制中二次发起拒绝并提示
- 与 step\-12 关系：定稿二期清单「网页截图」项（原草述「绑定会话备注」修订为文件名锚定会话名）并新增录屏；二期其余项不在范围
- 本期不做：音频录制、区域截图、整页长截图、录屏预览/播放、断点续录、自定义保存目录、录屏快捷键、全局快捷键（globalShortcut，本期键位仅应用内生效）

## 截图编辑多窗口修复（2026-11-03）

用户反馈连续截图编辑仍聚焦上一张。按原始截图身份复用窗口：不同截图新开，同图还原聚焦；各窗绑定独立内存快照，旧窗继续复制、下载和续编。产出以 sender 和本窗版本校验，仅最近槽仍匹配输出前版本时回写，异步下载不覆盖新截图。关窗释放快照，主窗关闭/退出清理全部编辑窗；不保存历史或草稿。

2026-11-04 审查修复：编辑器加载失败由主进程显示原生信息框（三语），失败窗口释放后可重试；清除 slotSwitched 退役注释。
