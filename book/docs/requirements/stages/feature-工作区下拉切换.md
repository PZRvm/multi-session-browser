# 工作区下拉切换专项

为左侧会话列表增加「工作区」组织维度：板头下方一枚下拉形态的工作区切换框，切换后列表只显示该工作区的会话、右侧浏览器切到该工作区内上次激活的会话。解决多项目并行测试时会话列表过长、跨项目会话互相干扰的问题。交互与视觉概念演示见 book/docs/prototypes/workspace-switcher-demo.html（单文件、含完整交互；chips 横排与首页 grid 两个候选形态已在选型中否决，下拉为定稿）。

- 形态定稿：下拉 combobox——收起态显示当前视野（「全部会话」或工作区名）；新建唯一入口为下拉内过滤无命中的快捷新建行（输入名称回车即建即切入）；默认态零噪音：不创建任何工作区时界面与既有版本完全一致（PRD 4.8）
- 下拉交互：面板顶部过滤输入键入即按名称过滤定位工作区，↑↓ 键盘导航、Enter 选中、Esc 关闭、外点关闭；过滤词无匹配工作区时出现「新建工作区『关键词』」快捷行（与既有名称精确命中时不出现）；右键列表项重命名（弹窗输入）/删除工作区（确认弹窗明示影响范围）
- 切换语义（视野 + 激活位）：工作区视野过滤列表，右侧切到该工作区内上次激活会话（无记忆则该工作区首项，空工作区右侧空态）；「全部会话」视野不过滤、不改激活会话，未分组会话带归属标记
- 归属独占制（PRD 4.8）：一会话一工作区或未分组；会话行菜单增「移动到工作区」二级菜单；新建/克隆落入当前工作区（全部视野下落未分组）仍追加列表末尾；删除工作区 → 会话全部移入未分组，不连带删除、不动分区数据
- 批量与排序作用域：批量勾选/全选/打开测试地址作用于当前视野，「关闭全部会话」仍作用全部；拖拽排序仍是全局全序整单提交（4.7 契约不变），工作区视野内拖拽仅调整可见会话在全序中的相对位置
- 契约方向（详细通道与校验在开发计划定稿）：sessions schema v3 → v4——快照增 workspaces（id/name/lastActiveSessionId）与 activeWorkspaceId（'all' | id），StoredSession 增可空 workspaceId；v3 存量读取时全会话视为未分组、activeWorkspaceId 回退 'all'（与外观偏好同口径：两侧损坏互不连带）；会话域通道按需新增工作区 create/rename/delete/move（switch 复用 setActive + 视野态持久化），沿用整单校验拒绝制与中文提示惯例
- 主进程边界：工作区纯元数据，不触碰分区、webContents 与窗口编排；删除工作区零编排回调（与 reorder 同口径）
- 本期不做：工作区自身的排序、多重归属（标签模型）、按工作区共享配置（代理/UA/弱网——二期测试辅助功能若挂工作区维度另行修订 PRD）、工作区导入导出、独立窗口内的工作区入口（独立窗口无左栏，不涉及）

## 增量：批量移动会话到工作区（2026-09-17 用户裁决）

- 批量模式支持将选中会话一次性移动到指定工作区或移出未分组；交互形态采纳 book/docs/prototypes/batch-move-to-workspace-demo.html（板脚操作栏第一行次级钮 + 复用移动 Modal + 幂等跳过 + 反馈条）；追加裁决：窄栏仅剩图标时以 Tooltip popover 提示全称
- 语义：幂等归属赋值，已在目标静默跳过；会话数据与登录态不受影响、不改变激活会话；重启归属恢复（PRD 4.8 增补 + 验收 28）

## 增量：未分组视野（2026-09-21 用户反馈）

- 下拉增「未分组」固定末位视野行：仅存留未分组会话（workspaceId === null），零工作区时不渲染（零噪音基线与归属标记同规）；哨兵行不可拖不可落、无右键管理
- 切换语义：级联取全序首个未分组会话（无激活记忆位——记忆只存在于工作区），空则右侧空态；视野值 'ungrouped' 持久化（store 读盘净化同步放行，悬空仍回退 'all'）
- 契约：WORKSPACE_VIEW_UNGROUPED = 'ungrouped' 哨兵单源（shared/sessions.ts），workspaceSetActive 主进程原子级联同临界区；新建/克隆在未分组视野落未分组（与全部视野同值，语义各自成立）
