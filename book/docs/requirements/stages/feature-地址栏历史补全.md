地址栏历史补全专项

为浏览器区地址栏增加基于会话内浏览历史的输入建议，对齐 Chrome omnibox 的核心体验，解决「访问过的网址下次要重新输入/复制整段地址」的低效问题。

- 历史按会话隔离：A 会话访问过的网址不出现在 B 会话地址栏的建议中；克隆会话携带历史，删除会话（含批量关闭）彻底清除该会话历史。
- 会话内任意窗口（主窗与独立窗）的地址栏输入达到触发字符数时，下方即时弹出匹配的历史记录（favicon + 标题 + 网址），支持键盘上下选择回车、鼠标点击导航；无匹配时不弹出，保持现有体验。
- 匹配对齐 Chrome 习惯：网址（含域名、路径、query）与页面标题的子串匹配，前缀命中优先，按新近度与访问频次排序，最多展示 8 条。
- 输入响应必须流畅：建议的检索计算在 renderer 本地完成，地址栏编辑期间不产生 IPC 往返、不占用主进程；历史数据由主进程持有并持久化（每会话独立文件，重启保留）。
- 每会话历史上限 2000 条（超限淘汰最旧访问）；about:blank 不入史，file:// 纳入。
- 本期不做历史管理页面（查看/搜索/删除单条历史）、不做跨会话全局历史。
