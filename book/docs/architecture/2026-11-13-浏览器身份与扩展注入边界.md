# 浏览器身份与扩展注入边界

2026-11-13，基线 Electron 45.3.0、electron-chrome-extensions 4.10.0。对应 [ADR-004](../decisions/ADR-004-host-owned-extension-preloads.md)。

| 文件 | 当前职责 |
| --- | --- |
| `src/main/browser/userAgent.ts` | 从运行时平台前缀与真实 Chromium 版本构建默认 ASCII Chrome UA |
| `src/main/index.ts` | Session/窗口创建前写 app.userAgentFallback，产品展示名独立设置 |
| `scripts/patch-extension-preloads.mjs` | 固定依赖的 CJS/ESM 源码补丁；取消默认注册并在构造副作用前检查宿主受限注册 |
| `electron.vite.config.ts`、package postinstall | 构建/开发及安装的补丁检查入口，无原生依赖重编译 |
| `extensions/runtime/preload-guard.ts` | 异步生成文件，同步注册 frame/SW，原生 includeGlobs 只匹配 chrome-extension 来源；失败清理本库注册 |
| `extensions/runtime/index.ts` | 生成→注册→引擎→shim→加载的顺序；缺少依赖补丁时拒绝挂载 |
| `extensions/shims.ts` | 页面身份取顶层 senderFrame，SW 身份取 serviceWorker.scope/event.session，均验证当前分区已加载；payload.extId 不授权 |
| `tools/browser-environment/` | 隔离验证脚本与归档结果，不属于用户流程 |

原生过滤不改变插件自己的 content scripts/scripting 权限；不同 partition 仍拥有独立存储与运行时。Client Hints 不覆写。已有 SW 的旧对象须完整退出再启后消失，不用清站点数据实现生效。

2026-11-14：构造中段失败改为显式需重启状态，Session 以进程级 WeakMap 记录并在准备前后检查；dev-entry 每 Session 只弹一次三语言原生错误框。宿主注册回滚仍不等于完整释放库资源，故不自动同进程重试。[R1 已复审关闭](../../notes/issue/2026-11/2026-11-14-扩展初始化失败恢复复审.md)。
