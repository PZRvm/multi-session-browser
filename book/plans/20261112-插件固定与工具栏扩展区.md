# 插件固定与工具栏扩展区

分级 **L**：新增共享 IPC 契约（extensions:set-pinned / extensions:order-pinned / extensions:changed、pick togglePin 语义、ExtensionListItem.pinned），触碰 always-L 清单「共享 IPC/类型契约」一行；跨 main / preload / renderer 三层与面板原生子窗；无新框架，手势与提交语义照搬 TabStrip/useTabReorder 先例，动画为 TabStrip 未覆盖的新机制（槽位 transform + transition）。

调研报告：`book/notes/learn/2026-11/20261112190948-插件固定与工具栏扩展区调研报告.md`。用户 2026-11-13 批复假设：拖拽排序带 Chrome 式滑动动画必做、设置页加钉子开关、胶囊/hover 确认、无 action 可固定确认；假设 4（全局同规）已解释按全局执行。

## Phase 1 影响与风险

- **契约镜像真实存在性检查**：i18n 三语（zh-CN 源 + zh-TW + en-US）并行补 `browser.extpanel.pinAria/unpinAria` 与 `settings.extensions.pinAria/unpinAria`；`ExtensionListItem.pinned` 为可选字段，三处消费方（设置窗/面板/工具栏）兼容。
- **manifest 校验坑**：validateManifest 重建对象丢未知字段，加 pins 必须同步改校验，否则写入后下次读取被静默丢弃。
- **拖拽中外部刷新竞态**：拖拽进行期间抑制 changed 广播触发的重取应用（拖拽中忽略，提交回执后重取幂等收敛），防覆盖本地预览序。
- **disabled 语义变更**：固定图标钮不随 `!activeTab` 禁用（Chrome 对齐：无 tab 也可重排）；点击无 tab no-op；扩展按钮 disabled 链不变。
- 卸载联动：removeInstall 清 pins 后广播 changed（图标消失路径）；install/uninstall 成功后统一广播。
- 锚点公式（+30/+34）按拼图按钮调的，固定图标同 28px 尺寸理论沿用，dev 实测微调。
- 视觉与动画手感：胶囊形态按用户截图、滑动动画按 Chrome 手感，实现走 impeccable 技能定稿，验收以截图形态 + 亮暗主题为准。

## Phase 2 设计

### 契约（shared/extensions/management.ts + shared/extensionsPanel.ts）

| 项 | 值 |
| --- | --- |
| 新通道 | `setPinned: 'extensions:set-pinned'`（invoke，载荷 `{ id, pinned }` → `{ ok, error? }`）；`orderPinned: 'extensions:order-pinned'`（invoke，载荷 `{ ids: string[] }` 全序覆盖 → `{ ok, error? }`）；`changed: 'extensions:changed'`（主进程 → 全窗广播，零载荷） |
| 扩展类型 | `ExtensionListItem` +`pinned?: boolean` |
| pick 语义 | `ExtensionsPanelPickPayload` kind +`'togglePin'`，载荷 `{ kind: 'togglePin', id, pinned }`（id [a-p]{32}、pinned boolean 校验，ipc.ts 白名单转发宿主 shell） |
| 语义归 shell | 面板 pick togglePin → 宿主 shell 调 `extensions.setPinned({id, pinned})` 落库（状态机唯一在宿主 shell，面板纯展示零自治不破） |
| i18n 键 | `browser.extpanel.pinAria`（固定到工具栏）/ `unpinAria`（从工具栏取消固定）+ `settings.extensions.pinAria` / `unpinAria`（两处语境一致） |

### 主进程

- **manifest-store.ts**：`GlobalManifest` +`pins?: string[]`；validateManifest 携带 pins（缺省 []，逐项 [a-p]{32} + 去重）；新增 `setPins(ids)`（串行锁 + 原子落盘，幂等集合语义）；`removeInstall` 同步过滤 pins。
- **management.ts**：
  - `extensions:set-pinned` handler：senderFrame 主 frame 守卫 + 载荷校验（id 格式 + pinned boolean）→ `manifest.setPins` → `broadcastExtensionsChanged()`。
  - `extensions:order-pinned` handler：载荷校验（ids 数组逐项 [a-p]{32}、去重、过滤未安装 id、上限 64）→ `manifest.setPins` → 广播。
  - `broadcastExtensionsChanged()`：`BrowserWindow.getAllWindows()` 逐窗 `webContents.send('extensions:changed')`（settings:changed 先例；面板子窗/设置窗收到后无订阅即忽略）。
  - `list`：从 manifest.pins 计算 pinned 标记并入返回项；install-store / import-crx / uninstall 成功后同样广播。
- **ipc.ts**：pick 转发白名单 +togglePin（载荷校验后转发宿主 shell）。

### preload（index.ts + index.d.ts）

- extensions 命名空间 +`setPinned` / +`orderPinned` / +`onChanged(cb): () => void`；类型镜像。

### 渲染端

- **Toolbar.tsx**：挂载时 list 现取 + onChanged 订阅重取（拖拽进行中忽略重取，防覆盖预览）；渲染 `.chrome-ext-bar` 胶囊容器 = 固定图标组 + 扩展按钮；固定图标钮不随 `!activeTab` 禁用，click（未过拖拽阈值）→ 现读按钮 rect → `extensions.openPopup(id, {x, y})`，无 tab 时 no-op；TooltipSlot 悬停气泡显插件名。
- **新 hook useExtPinReorder.ts**（仿 useTabReorder）：本地预览序（仅 id 序）/中点换位判定（getBoundingClientRect 中点比对）/跟手位移 dragOffsetX/commit 全序提交（无位移短路零 IPC；回执 ok 后本地乐观落地新序再复位 transform 无跳变）/Esc + pointercancel 放回；**槽位 transform 滑动动画**：非拖动钮按预览槽位差 translateX + transition（时长/缓动 impeccable 定稿），拖动钮无 transition 跟手、释放吸附。
- **Toolbar 拖拽接线**：固定图标钮 pointerdown 手势（armed→reordering 状态机、`DRAG_ENGAGE_RADIUS_PX` 过阈值分流点击与拖拽、suppressClick 吞随尾 click、仅胶囊内水平重排不升级拖出）。
- **useExtensionsPanelWindow.ts**：onPicked +togglePin 消费（setPinned 落库 → refreshTick 重跑 show 全量刷新面板，面板不关）；开面板 show 的 items 已含 pinned 标记。
- **ExtensionsPanelWindow.tsx**：行右侧钉子开关（PushpinOutlined / PushpinFilled），click → pick {kind:'togglePin', id, pinned: !item.pinned}；钉子钮不参与行 disabled。
- **PaneExtensions.tsx**：行加钉子小钮（同 Pushpin 图标）→ `extensions.setPinned` → 本地 refresh；广播已同步工具栏。
- **CSS**：`.chrome-ext-bar` 胶囊容器 + 固定图标钮 + 槽位滑动动画 transition——**实现时走 impeccable 技能**定稿视觉与动画手感。

## Phase 5/6 发现

- **preload/index.d.ts 的 import() 类型在 web 项目解析为 any（既有问题，本轮发现）**：`extensions` 块的 `Promise<import('...').ExtensionListResult>` 等六处全部解析为 `Promise<any>`，web 侧类型网对该块失效（HEAD 版本既有四处即如此）——新增契约的类型安全靠 renderer 侧静态 import 兜底（如 PaneExtensions 顶部 static import 的 ExtensionListItem[] 仍严格）。仅记录不夹带修复（record-never-fix）；后续可将该块改为文件顶部 static import type 恢复严格性，属独立任务。详见 learn 2026-11-13。
- 实施轮将 list 契约细化为 `{ items, pins }`（ExtensionListResult）：拖拽重排需要 pins 全序，原计划的 pinned 布尔标记不携带顺序信息——计划 Phase 2 契约表的一处实施期修订。
- 本轮文档与代码写入多次遭生成污染（junk 注释/乱码残句注入，同 2026-11-11 计划先例）：计文档×2、hook×2、Toolbar×2、CSS×1 处污染全部即时发现修复，收尾全文扫描零残留；污染形态已补入 learn 2026-11-13。
