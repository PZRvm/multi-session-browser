# 设置专项阶段一开发计划：入口与设置窗口骨架

> 创建时间：2026-09-16 21:33:51（Asia/Shanghai）  
> 需求来源：`book/docs/requirements/stages/feature-设置窗口与全局偏好.md`（阶段一）  
> 执行模式：直通  
> 实施范围：设置的双入口（macOS 应用菜单「设置… ⌘,」+ 板头齿轮）与独立设置子窗口骨架（单例、级联、互不遮挡），外加偏好存储契约基建（`settings.json` 空骨架）——**不含任何设置项内容**（语言/外观对接/主题色/主页/关于/恢复出厂分属阶段二—六）  
> 目标结果：⌘,、菜单项、板头齿轮三条路径打开同一个独立设置窗口（重复触发聚焦不双开）；窗口打开期间浏览器页面保持可见可交互，关闭后零状态损失；板头齿轮恒在（不随宽度降级），外观三段展开阈值按设计定稿值上调；主窗关窗级联关闭设置窗  
> 当前进度：步骤 1—5 均未开始

## 1. 当前基线

- **菜单现状**：`src/main/index.ts:64-107` `installChineseMenu()` 在窗口创建前安装中文菜单——darwin 应用子菜单为 关于/服务/隐藏/隐藏其他/全部显示/退出，无设置项；非 darwin 子菜单仅退出（菜单栏 `autoHideMenuBar: true` 默认隐藏，`index.ts:117`）。菜单加速键优先于 before-input-event 的既有结论见函数头注释（这也是只加 darwin 子菜单项、Windows 靠齿轮的依据）。
- **板头现状**：`SessionPanel.tsx:406-427` `board-head-right` 依次为 `AppearanceEntry`（panelWidth 注入）、批量按钮、「会话」计数标签 + 翻牌计数；`AppearanceEntry.tsx:42` `APPEARANCE_SEGMENTED_MIN_WIDTH = 360`（≥360 三段 Segmented / 更窄 20×20 当前态图标钮 + Dropdown）。**面板宽度区间 220—420、默认 280**（`App.tsx:6-8` PANEL_MIN/MAX/DEFAULT）——阈值上调值必须 < 420，否则宽态形态在可拖区间内不可达（设计步骤的硬约束）。
- **偏好存储先例（本阶段照此立骨架）**：`src/main/appearance.ts`——`preferences.json` v1（仅 appearanceMode）、`loadAppearanceMode` 四路容错（ENOENT→默认 / 坏 JSON / 非对象 / 未知 version→中文告警回退）、`saveAppearanceMode` tmp+rename 原子写（失败 unlink 清残留）、`setModeQueue` 串行队列、`BrowserWindow.getAllWindows()` 广播主题快照。设置域另立 `settings.json` 分域存储（PRD 4.9：与 `sessions.json`、分区数据分别存储独立读写；不并入 `preferences.json`，避免两域共享一文件的写队列耦合）。
- **子窗与角色先例（设置窗照此装配）**：`src/main/browser/omniboxSuggest.ts` 头注释——parent 归宿主、ready-to-show 显窗、closed 级联销毁、`installShellInputGuard` 安装、dev 走 `ELECTRON_RENDERER_URL + query` / prod 走 `loadFile + query`（`windows.ts` 独立窗 `?role=tab-window&session=…` 同款）；`main.tsx:19-25` 已有第三角色 `?role=omnibox-suggest` 的求值期分流先例（不初始化 sessions/browser stores、App chunk 惰性分流）。与建议子窗的关键差异：设置窗**是** focusable 的正常有框窗（要焦点、有标题栏、可交互），不是透明无框不夺焦面板。
- **外观背景色与主题注入**：`index.ts:118` 建窗 `backgroundColor` 经 `getAppearanceBackgroundColor(resolvedTheme)`；`appearance.ts:158-176` 主题变化时 `getAllWindows()` 逐窗 `setBackgroundColor` 并广播快照——设置窗加入后自动纳入（同 preload + 同 renderer 包，CSS 媒体查询随 `nativeTheme.themeSource` 翻转，零新增主题通道）。
- **IPC 与 preload 现状**：`api` 现有 appearance/sessions/browser/omniboxSuggest 四命名空间；`OkResult` 定义于 `shared/browser.ts` 且被 sessions 域跨文件复用（preload `index.d.ts` 可查）——设置域照此复用。`src/main/ipc-utils.ts` 的守卫/日志惯例齐备；通道字符串仅存在于 shared 常量是既定纪律。
- **MSB_USER_DATA 隔离**：`index.ts:28-42`（一切运行时验证强制走隔离目录，不触真实 userData）。
- **契约差异（本阶段要补的缺口）**：`src/shared/` 无 settings 域文件；preload 无 `api.settings`；DESIGN.md 无「设置窗口」条目、板头条目无齿轮、外观契约阈值句为现行 360；PRD 3.8.1/验收 23 已定稿（book/docs/requirements/PRD.md，本阶段为其实施起点）。

## 2. 范围边界

### 2.1 本阶段必须完成

- `src/shared/settings.ts`：`SETTINGS_WINDOW_ROLE`、`SETTINGS_CHANNELS`（本阶段仅 `open` 一条命令通道）、类型定义；preload `api.settings` 命名空间三处对齐
- `src/main/settings.ts`：`settings.json` v1 空骨架偏好存储（load/save 原子写 + 四路容错 + 串行队列；仅 `version` 字段，无设置键）
- `src/main/settingsWindow.ts`：单例设置子窗控制器（create-or-focus、parent 归主窗、主窗 closed 级联、外观背景色注入、输入守卫、`?role=settings` 加载）+ `registerSettingsIpc`（sender 白名单 = 主窗 shell）
- `installChineseMenu()` darwin 应用子菜单增「设置… `CmdOrCtrl+,`」（关于之后）；`index.ts` 装配
- renderer：`main.tsx` 第四角色分流 + `SettingsWindow.tsx` 壳体（DESIGN 定稿形态）+ SessionPanel 板头齿轮（批量按钮与计数之间）+ `APPEARANCE_SEGMENTED_MIN_WIDTH` 上调为设计定值
- DESIGN.md 三处定稿（新「设置窗口」条目、板头条目修订、外观契约阈值句修订）；`book/docs/architecture/项目骨架.md` 与 `book/notes/summary/2026-11/legacy-process.md` 同步；验收文档落盘

### 2.2 本阶段明确不做

- 任何设置项内容与交互控件（语言=阶段五、外观对接=阶段二、主题色=阶段四、主页 URL=阶段三、关于信息=阶段二、恢复出厂=阶段六）——设置窗本阶段只有壳体
- `settings.json` 的任何设置键与 get/changed/set 通道（首个真实键随阶段二入住，契约本阶段只立文件与骨架）
- Windows/Linux 菜单入口（菜单栏默认隐藏，齿轮是唯一发现路径——PRD 3.8.1 既定）
- 设置窗 DevTools、多设置窗、独立于主窗的设置窗常驻（单例 + 级联为本阶段语义）
- i18n（阶段五前文案纯中文）

### 2.3 本阶段数据原则

- `settings.json` 本阶段只会被读取不会被写入（无设置项即无写路径）：ENOENT → 静默默认骨架，文件不存在是合法常态，不告警不落盘
- 偏好读取/校验异常一律中文告警 + 回退默认骨架，不得阻断启动、不得触碰 `sessions.json` / `preferences.json` / 分区数据
- 验收一律走 `MSB_USER_DATA` 隔离目录的 `npm run dev`；截图为真实运行态，不伪造

### 2.4 契约核对（编码前冻结）

1. **新契约 `src/shared/settings.ts`**：`SETTINGS_WINDOW_ROLE = 'settings'`（主进程建窗 query 与 `main.tsx` 分流共用的单源）；`SETTINGS_CHANNELS = { open: 'settings:open' }`（阶段二起随设置项扩展 get/changed/set）；载荷复用 `shared/browser.ts` 的 `OkResult`。同步：preload `index.ts` + `index.d.ts` 增 `api.settings.open(): Promise<OkResult>`。
2. **偏好文件定案**：设置域另立 `userData/settings.json`（v1 空骨架 `{ version: 1 }`），与 `preferences.json`（外观域）分域并行——两域各自的串行队列互不耦合；`src/main/settings.ts` 的容错语义与 `appearance.ts` 逐条对齐（中文告警文案以 `[settings]` 前缀区分）。
3. **DESIGN.md 三处**：新增「设置窗口」条目（壳体度量、标题栏形态、层级与单例行为、亮暗变体、空窗态）；「板头（Board Head）」条目增齿轮（位置=外观入口与批量按钮之后、计数之前；20×20；恒在不随宽度降级）；「应用外观扩展契约」的 360px 阈值句改为新定值（约束：新值 < 420）。
4. **文档同步（收尾）**：`book/docs/architecture/项目骨架.md`（shared/main/renderer 新文件行 + preload 命名空间四→五）、`book/notes/summary/2026-11/legacy-process.md` 阶段表与当前阶段行。

完成标志：`src/shared/settings.ts` 落盘且 `npm run typecheck` 通过；`rg "settings:open"` 仅命中 shared 常量与 preload 实现两处；DESIGN.md 三处修订随步骤 1 一并落盘。

### 步骤 3：主进程偏好骨架 + 设置子窗控制器 + 菜单接线

任务：

1. 新建 `src/main/settings.ts`：`settings.json` v1 空骨架存储——`loadSettings()`（ENOENT→默认静默 / 读失败 / 坏 JSON / 非对象 / 未知 version → `[settings]` 前缀中文告警回退默认）+ `saveSettings()`（tmp+rename 原子写、失败清残留）+ 串行写队列（模式逐条对齐 `appearance.ts`）

### 步骤 4：renderer 第四角色与板头齿轮

5. 同步更新 `book/docs/architecture/项目骨架.md`：shared/main/renderer 新文件行、preload 命名空间、`main.tsx` 角色清单
