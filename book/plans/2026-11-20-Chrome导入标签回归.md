# Chrome 导入标签回归

**L 级**。涉及会话分区静默、原生模态与标签生命周期。

## Step 0

用户在 Chrome 导入结束前后看到仍可点击的标签。切换或新建时主进程报未选择会话。导入表示完成时，原有标签和新建入口应当可以马上使用。确认后仍按现有会话、分区、数据类型和冲突策略执行。超长历史仍沿用现有网址限制。IndexedDB 只在兼容性得到实测的范围内调整门禁。

## Phase 1 与 Phase 2

无冲突路径在 dry-run 后提前关原生加载窗口。runtime 写入多个站点期间，registry 关闭旧页面并把运行时会话置空，renderer 仍显示旧标签。隔离 Electron 中人为暂停运行时存储读取，实际选择窗口已消失，此时切换、新建均报未选择会话。写入恢复后两项操作成功。

保留无冲突路径的加载窗口。冲突路径先切换到原有裁决窗口，确认后同样保留加载状态。主进程在 execute 取到匹配目标的窗口后接管其寿命，写入和恢复均落定后关闭原窗口再反馈结果。单纯选项探测仍保留既有超时。结果框显示已过滤的历史条数，以及全部不兼容时未导入的 IndexedDB 站点数。关闭和结束通知只作用于本次窗口。继续复用现有模态权限、IPC 载荷和文案。

IndexedDB 复验使用 Electron 45.3.0 生成的数据。实验放行 V8 序列化格式 16 后，空会话读写成功，但已有站点整体替换后仍可能读到旧值。现有版本门禁保留。仅在压实表中的版本仍无法核验，详见[已知问题](../notes/issue/2026-11/2026-11-19-IndexedDB导入版本门禁仍拒绝schema16.md)。
