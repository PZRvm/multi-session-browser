# 插件名称本地化修复

分级：M。单一插件管理功能内的缺陷修复，不改变共享 IPC、持久化 schema、权限或 webContents 生命周期。用户已确认[调研](../notes/learn/2026-11/20261117175313-插件名称本地化修复调研.md)全部假设并授权实施。

## Step 0：需求简报

背景：宿主直接显示 manifest 中的 __MSG_ 引用，用户无法识别插件。

范围：主进程名称解析与 list 输出；设置列表、打开的插件面板和固定图标提示刷新。排除插件内部网页语言、安装事务、包内容改写、持久化迁移及其他权限提示文案整改。

边界：普通名称保留；消息按应用完整语言、基础语言、default_locale 回退。缺键、坏文件、越界路径与超限文件不使整份列表失败。找不到名称时用可用旧普通名称，最后用 ID。繁体不自动转简体。无新宿主文案，无字典新增。

需求：旧安装不重装即可显示真实名称；应用语言切换后三处名称更新，快速切换不能被旧回包覆盖；拖拽期间暂缓的刷新在结束后补齐。

## Phase 1：分析（通过）

management.ts 优先保存的原始 name，导致仅修安装入口无效。主进程已有语言监听，renderer 已有 list/changed 通道；面板还缺 changed 订阅。固定图标已有拖拽期抑制重取。风险为不可信 locale 读取、异步回包乱序和语言派生值落盘。

## Phase 2：设计（通过）

数据流：getCurrentLanguage（list 调用时捕获）→ 包 manifest.name/default_locale → localizedName.ts 顺序读取消息 → list.name → 现有展示。语言变更复用 changed，消费者最新请求生效。普通旧名称只作后备，不保存语言派生值。

文件：新增 src/main/extensions/localizedName.ts；修改 management.ts、PaneExtensions.tsx、Toolbar.tsx、useExtensionsPanelWindow.ts。独立 Node 回归脚本放 scripts/，不添加测试框架。

解析：消息键和静态占位符键忽略大小写，支持多个 __MSG_ 引用、静态 $NAME$ 与 $$；动态参数/缺失引用降级。locale 仅允许字母数字和下划线/连字符并规范为下划线。文件 realpath 必须位于真实包目录下，末级禁止符号链接，读取上限 1 MiB，名称上限 4096 字符；失败继续候选。不缓存，避免版本与语言失效问题。

权限：仅主进程在已有包目录读取，不新增 IPC/权限。通知：复用 extensions.changed，无 toast、对话框或新文案。体验：三处名称一致，失败仍可凭 ID 管理插件。请求序号与 effect 清理阻止旧回包；工具栏拖拽态进入/退出时重建取数 effect，退出后重取。

验收：真实样本三语言和旧记录；纯名称/多引用/大小写/缺键/静态占位符；坏 JSON、超限、越界和符号链接；三处刷新与快速切换；typecheck、lint、隔离 dev:agent 交互验证。无新视觉设计。
