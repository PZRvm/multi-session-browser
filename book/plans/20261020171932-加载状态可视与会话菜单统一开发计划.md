# 加载状态可视与会话菜单统一 开发计划

> 创建时间：2026-10-20 17:19:32（Asia/Shanghai）  
> 需求来源：用户 2026-10-20 两项交互反馈——①浏览区加载中/加载失败均白屏不可区分（关联 `book/docs/requirements/stages/step-02-右侧浏览器基础功能.md` 浏览区基础交互）；②会话行右键菜单与 ⋮ 菜单项不一致，按多的那一项统一（关联 `book/docs/requirements/stages/step-12-测试辅助功能二期.md` 2026-10-15 反馈轮四行原生菜单）  
> 执行模式：直通  
> 实施范围：①主进程捕获主 frame 加载失败并注入自绘错误卡（加载中信号维持既有 Tab spinner + 停止钮，不加新器件）；②⋮ 短菜单退役，两触发器统一为全量菜单。不做：加载进度条、菜单触发时机口径变化、错误自动重试  
> 目标结果：页面加载失败时内容区呈现错误卡（可读失败原因 + 引擎错误码 + 重新加载），不再白屏；会话行右键与 ⋮ 菜单项完全一致（7 项全量）  
> 当前进度：步骤 1—3 均未开始

## 1. 当前基线

- **加载态（已有信号，弱）**：`src/main/browser/manager.ts` 以 `did-start-loading`/`did-stop-loading` 维护 `TabEntry.loading`，进快照 `BrowserTabState.loading`（`src/shared/browser.ts:72`）。renderer 侧信号已有两处：Tab 条在 favicon 槽位渲染 `LoadingOutlined` spinner（`TabStrip.tsx:359`）；工具栏在激活 Tab 加载中把刷新钮切换为停止钮（`Toolbar.tsx:314`）。加载中内容区为兜底底色（亮 `#ffffff` / 暗 `#202124`，`newTab` 建视图时 `setBackgroundColor`）——页面未渲染前无任何内容可看。
- **失败态（白屏根因，已实测）**：`did-fail-load` 仅 `console.warn`（`manager.ts:495`）；`manager.ts:627` 注释假设「导航失败由 Chromium 内建错误页呈现」。2026-10-20 最小 Electron 探针实测**推翻该假设**：Electron 39 主 frame 加载失败后页面落 `chrome-error://chromewebdata/`，DOM 为 `<html><head></head><body></body></html>` 完全空白（`backgroundThrottling:false`、readyState complete 下复测一致）——Chromium 错误页资源不在 Electron 分发内，失败＝白屏，与加载中不可区分。用户反馈属实。
- **行菜单双变体**：`src/shared/sessions.ts:336` 定义 `RowMenuVariant = 'full' | 'dots'`；`src/main/sessions.ts:936` full 变体 7 项（重命名/编辑备注/克隆/移动/导入 Chrome 数据/代理设置/删除），dots 变体仅 3 项（重命名/克隆/删除）。`SessionRow.tsx` 行右键发 `full`（:255）、⋮ 按钮发 `dots`（:389）；`dispatchRowMenuAction`（:191）已支持全部 7 个动作键——统一到全量后 renderer 编排零新增。
- **PRD 偏差（统一即修复）**：PRD 3.9 与验收 36 明文「入口为会话行右键/**⋮ 菜单**『导入 Chrome 数据…』」，dots 短菜单实际无此项；PRD 4.14/验收 40「会话行菜单『代理设置…』」同理。统一到全量使实现与 PRD 措辞一致，PRD 无需修改。
- **触发口径（本次不动）**：批量态两触发器均不弹；行内编辑态右键不弹、⋮ 可弹（2026-10-15 审查低-4 裁决：静默无响应不可接受）。本计划仅统一菜单项集合，触发 gate 不变。

## 2. 范围边界

### 2.1 本阶段必须完成

- 加载失败错误卡：manager 捕获主 frame `did-fail-load`（非 `ERR_ABORTED`）→ 该 Tab 的 view 内注入自绘错误卡，失败原因分两层说明——**可读原因**（常见错误码映射为当前语言短句，如找不到服务器/连接被拒/连接超时/断网/代理连不上，Chrome 错误页同构）+ **技术细节**（引擎错误码与描述原值 `ERR_*` 英文原样恒显）+ 目标 URL + 「重新加载」钮；映射不到的错误码以通用失败文案 + 原码兜底，不伪造具体原因。文案三语经 `shared/i18n` browser 命名空间新键，主进程 `t()` 构造期取词；视觉走 impeccable 定稿（chrome-\* 灰阶语系、亮暗两态）。
- 会话行菜单统一：删除 `RowMenuVariant` 与 `PopupRowMenuPayload.variant` 字段，主进程单一全量菜单构建；`SessionRow` 两触发点收口，触发 gate 口径不变。
- 文档同步：`DESIGN.md`（会话行条目修订 + 新增「页面加载失败卡」条目）、`book/docs/requirements/PRD.md` 3.4 补失败呈现归属句、`book/docs/architecture/项目骨架.md`（shared/sessions.ts、main/sessions.ts、SessionRow、manager 四行）、`manager.ts:627` 失败呈现注释修正（根因探针结论入注）。

### 2.2 本阶段明确不做

- 不新增加载进度条、内容区加载动画等新信号器件：加载中信号维持 Chrome 惯例（Tab spinner + 停止钮 + 兜底底色），失败卡落地后「转圈＝加载中、错误卡＝失败」语义闭环；若执行中设计轮裁决仍需加载信号增强，另立专项。
- 不改菜单触发时机口径（批量/编辑态 gate 不动）、不改 `RowMenuActionKey` 集合、不调整菜单项顺序。
- 不做错误自动重试、网络诊断面板等错误卡之外的扩展面。
- 零新增 IPC 通道、零 preload 桥方法变更（错误卡为 manager 内聚注入，不经 renderer；字典键为 `shared/i18n` 扩展，非通道契约）。
- 不触碰会话隔离面：注入目标仅限本会话 view 的 `chrome-error` 内部空白页，不改 webPreferences、不碰分区与存储。

### 2.3 本阶段数据原则

- 失败如实呈现：可读原因是错误码的确定性映射（映射单源、不猜测不引申），引擎错误码/描述恒以原值并列展示（`ERR_*` 英文原样）；映射不到不伪造具体原因，以通用失败文案 + 原码兜底；不伪造成功、不吞失败；加载中就诚实显示加载中（spinner + 停止钮），不以假进度误导。
- 错误卡是注入的纯展示 DOM：不产生导航 entry（不污染前进/后退与 onVisit 历史采集）、不写会话元数据、不落盘。

### 2.4 契约核对

1. **shared/sessions.ts 收敛菜单契约**：删除 `RowMenuVariant` 类型与 `PopupRowMenuPayload.variant` 字段（载荷收敛为 `{id, x, y}`），头注释改写（2026-10-20 用户裁决：⋮ 与右键统一全量，dots 短菜单退役）。需同步文档：`DESIGN.md` 会话行条目、骨架 3.5 `sessions.ts` 行。`RowMenuActionKey` 与通道数（24 条）均不变。
2. **shared/i18n 三语字典扩展**：browser 命名空间增页面错误卡键组（`pageError.*`：标题/可读原因映射/通用兜底/重试/技术细节标签等，zh-CN 为源，en-US/zh-TW 并行，缺键即 typecheck 失败）；错误码→可读原因映射表单源落 shared，主进程注入时消费。用户可见文案不入组件字面量。
3. **PRD 3.4 补归属句**：浏览区页面加载失败时内容区呈现错误卡（可读失败原因、引擎错误码与重试入口），不留白屏；加载中维持 Tab spinner 与停止钮信号。PRD 3.9/验收 36「右键/⋮ 菜单」措辞在统一后自然一致，不改。
4. **manager.ts 错误呈现注释修正**：`manager.ts:627`「Chromium 内建错误页呈现」按探针实证改写（Electron 无错误页资源，失败落空 `chrome-error` 页）。

完成标志：`npm run typecheck` 0 错误（含三语字典完备性）；`grep -rn "RowMenuVariant" src/` 零命中；PRD/DESIGN/骨架落笔可 grep。

3. `src/main/browser/manager.ts`：`TabEntry` 增 `loadError` 瞬态——`did-fail-load`（isMainFrame 且非 `NET_ERR_ABORTED`）置位 `{code, description, validatedURL}`，`did-start-loading` 清位；`did-stop-loading` 时若置位则以 `executeJavaScript` 向该 view 注入错误卡（文案经 main/i18n `t()` 取词，插值一律 `JSON.stringify` 转义；重试钮 `onclick=location.reload()`——执行期 CDP 验证 chrome-error 位置 reload 的重试原导航语义，不成立则改为注入脚本经回调触发主进程 `wc.loadURL(tab.url)` 兜底）；注入整体 try/catch 失败中文 warn 静默降级（维持现状白屏不劣化）。后台 Tab 失败同样置位注入，切回时错误卡在 view DOM 中自然可见。
4. `manager.ts:627` 注释按探针实证修正；确认主窗/独立窗共用 manager 无需分支。
