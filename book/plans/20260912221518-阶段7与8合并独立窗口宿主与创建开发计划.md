# 阶段 7—8 合并开发计划：独立窗口宿主模型与窗口创建（独立窗口二 + 三）

## 2. 范围边界

### 2.1 本阶段必须完成

- 主进程窗口宿主模型：`TabEntry` 增归属窗口；会话级 `activeId` 改每窗口激活表；单份 `bounds` 改每窗口矩形表；manager `getWindow` 参数化（原阶段 7 全部内容，作为内部检查点而非独立交付）。
- 快照与 IPC 窗口作用域化：命令按 `event.sender` 解析来源窗口路由；`stateChanged`/`focusAddress` 定向推送；`BrowserSnapshot` 增 `windowId`；preload 类型同步。
- `src/main/browser/windows.ts` 独立窗口登记表：创建 BrowserWindow（同一 renderer 入口 + query 独立窗口模式）、title=会话名、随重命名同步、关闭级联。
- tear-off 命令链：`browser:tear-off-tab` 通道 + Tab 条临时右键菜单入口（阶段 9 拖拽手势替换入口，通道语义保留）；摘 view 重挂新窗口、双侧快照推送、激活位补位。
- 独立窗口内可导航、新建/关闭/切换 Tab；F12 DevTools 随页面工作；最后一个 Tab 允许关闭且关掉即销毁窗口；直接关窗销毁其中全部 Tab。
- 会话级联：destroySession / closeSession（克隆前置）/ clonePartition / 批量关闭先关该会话全部独立窗口；before-quit 关全部独立窗口；macOS 关主窗独立窗口存活、主窗重开正常。
- 主窗口 0-Tab 新状态组合（sessionId 非 null 且 tabs 空，tear-off 唯一 Tab 后可达）的 renderer 空态处理。
- `DESIGN.md`（独立窗口条目 + 快照 windowId 语义 + 临时入口说明）、`src/shared/browser.ts` 头注释指向、`book/notes/summary/2026-11/legacy-process.md`（阶段 7/8 两行合并为一条指向本计划）、验收文档落盘。

### 2.2 本阶段明确不做

- 拖出/拖入/跨窗口转移手势与拖拽状态反馈（`browser:tab-drag-*` 类通道、光标轮询命中、半透明/高亮/回弹视觉）——阶段 9。
- Tab 跨已存在窗口转移（含拖回合并 mergeBack / reattachTab 复用路径的暴露）——阶段 10；本阶段 tear-off 只创建**新**窗口。
- 退出落盘归并（独立窗口中的 Tab 按 URL 归入主窗口 session 列表）与重启恢复独立窗口语义——阶段 10（PRD 3.6.4/验收 17）。过渡期事实：独立窗口中的 Tab 不参与落盘，退出即失（URL 级），重启不恢复——如实接受，不造假象。
- 异 session 转移校验（本阶段 tear-off 源必属当前作用域会话，无跨会话路径，校验留阶段 9/10 一并强化）。
- PRD 验收 14（跨窗口转移）/ 17（重启归并）——归阶段 9/10 验收。
- 独立窗口内的会话面板、批量模式、多选拖拽（定案 v2-1）。

### 2.3 本阶段数据原则

- 快照按窗口作用域构建，每窗口只看到自己托管的 tabs 与激活位；禁止把全会话 tabs 盲发给所有窗口（串台即事故）。
- tear-off 是 webContents 原样迁移：滚动/输入/登录态/分区/DevTools 全保留，任何"重开同 URL"的伪迁移形态禁止（think-report 2.3 方案 B 明确否决）。
- 持久化上报绑定**主窗口作用域**快照：tear-off 后落盘 tabs 不含独立窗口中的 Tab（过渡期如实行为，阶段 10 归并收口）；独立窗口 Tab 的加载态照常进会话状态灯聚合（后台会话真实加载态不造假，沿用 registry 既有口径）。
- 主窗口 0-Tab 空态如实呈现（Tab 条空 + 新建钮可用），不伪造占位 Tab。
- 独立窗口 title 与会话名严格同源（重命名经主进程同步，不做 renderer 侧乐观标题）。

## 3. 开始编码前的契约核对

本阶段涉及共享契约和基准文档的以下变更，必须在编码前冻结并同步（依据 `AGENTS.md`：实现与设计文档冲突时先改文档；`src/shared/browser.ts:1-3` 头注释同款义务）：

1. **窗口宿主标识 `windowId: string`**：主窗口浏览区固定常量 `'main'`（跨 macOS 关窗重建稳定，规避 BrowserWindow.id 重建漂移）；独立窗口用其 `BrowserWindow.id` 字符串化（创建时由 windows.ts 分配并写入登记表，生命周期内稳定）。renderer 自识别规则：URL 无 query = 主窗口（'main'）；有 `role=tab-window` query = 独立窗口，`windowId`/`session` 取自 query。需同步：`src/shared/browser.ts`（常量与注释）。
2. **`BrowserSnapshot` 增必填 `windowId: string`**：快照按窗口作用域构建（该窗口托管 tabs + 该窗口激活位 + devtoolsOpen 取该窗口激活 Tab）。主窗口零会话空态 = `{ windowId: 'main', sessionId: null, tabs: [], activeTabId: null, devtoolsOpen: false }`。renderer 守卫规则分流：主窗口模式 = `windowId === 'main'` 且 sessionId 与 sessions store activeId 相符；独立窗口模式 = `windowId` 与 query 相符（不依赖 sessions store）。需同步：`src/shared/browser.ts`、`src/preload/index.d.ts`（类型随 shared 引用自动生效，确认无独立定义残留）、`src/main/browser/manager.ts` buildSnapshot 注释。
3. **命令作用域化规则（通道名与 payload 零变更）**：12 条命令通道 payload 不变，路由规则冻结——主窗口来源（sender 属主窗口 webContents）→ 当前激活会话的 `'main'` 作用域（现行为）；独立窗口来源 → windows.ts 登记的绑定会话的该窗口作用域；来源无法解析（未知窗口/已销毁）→ 抛错拒绝（中文文案）。`setBounds` 的 windowId 由 sender 推导，payload 不加字段。需同步：`src/shared/browser.ts` 头注释（"命令一律作用于当前激活会话"修订为按来源窗口作用域）、`src/main/browser/ipc.ts` 注释。
4. **新增通道 `browser:tear-off-tab`**：payload `{ id: string }`（被移出的 Tab id，作用域 = 发起窗口），返回 `BrowserSnapshot`（发起窗口作用域快照）；执行语义 = 摘 view 保活 → windows.ts 建窗挂入 → 双侧窗口各自收定向快照。通道数为 14 → 15（命令 12 → 13），ipc.ts 注册日志同步。临时入口 = TabStrip 右键菜单「移出到独立窗口」（阶段 9 拖拽手势替换入口，通道与语义保留）。需同步：`src/shared/browser.ts`（通道 + `TearOffTabPayload`）、`src/preload/index.ts` + `index.d.ts`（`tearOffTab` 方法）。
5. **closeTab 作用域规则**：主窗口作用域维持"最后留一"no-op（现行为不变）；独立窗口作用域最后一个 Tab 允许关闭——关闭即销毁该 Tab 的 webContents 并销毁窗口；tear-off 不受"最后留一"限制（主窗口可至 0 Tab）。需同步：`src/main/browser/manager.ts` 接口注释。
6. **sessions IPC deps 增 `onRenamed`**：rename handler 成功后回调 `(id, name)`，index.ts 注入 → windows.ts 同步该会话全部独立窗口 title。需同步：`src/main/sessions.ts` deps 类型注释。
7. **`DESIGN.md`**：收尾步骤统一同步（新增「独立窗口」条目、快照 windowId 语义、临时右键入口说明、Not Yet 章节更新）——编码期以本节为准，DESIGN.md 不阻塞编码。

完成标志：`src/shared/browser.ts` 与 `src/preload/index.{ts,d.ts}` 落笔后 `npm run typecheck` 0 错误（manager buildSnapshot 等编译缺口允许在步骤 2 补齐——参照阶段 3 波次 2 的占位先例，占位处带注释声明步骤归属）；通道字符串 grep 仅存在于 shared 常量。
