## Phase 1 影响与风险

- 端到端依赖会话1宿主M1；此前用普通Chrome真机与前置工具夹具验证，不阻塞开发。
- 编辑器复用改造由本会话独占；不改原截图/录屏入口行为，原版插件样本不修改。
- 录屏独立audio开关对应Chromium“Tab静音仍录入音轨”的语义，开关语义按前置结论实现。
- 生产settle迁移由会话1的E执行；本会话按协议v1的finalizing模型消费状态，不自行改生产index.ts。

- 按用户主应用截图标准（红绿灯与工具键同源单行、无tabbar），编辑页加载后自动迁移到 Document PiP 无框窗口：实测扩展页可 requestWindow，工具行最左放关闭钮（PiP 无系统灯，功能等价关闭灯），84px 左让位取消（PiP 无灯），SW 收回原弹窗窗口。
- 迁移竞态两处修复：附着只认已稳定 PiP（url=editor.html 且标题继承非空，临时页标题为空且迁移后即关）；开窗后延迟 300ms 在迁移成功后通知后台。迁移失败场景（无调用态）回退常规弹窗并提供「浮动」入口按钮。
- **更正（同日深查）**：上述「自动迁移」从未真实发生——真机验证三条硬约束：① requestWindow 需**页内**瞬态激活（icon 点击的激活在 SW，编辑页没有，自动迁移必拒）；② PiP 不能活过 opener（关闭承载窗会连带关闭 PiP）；③ PiP 不是 CDP 目标且承载窗最小化后其 rAF 节流（跨窗搬节点会让 Konva 绘制卡死）。此前两轮 12/12 实际验证的是回退弹窗形态（harness 附着的 editor.html 目标即承载页自身）。
- **重写后的架构（当前形态）**：icon 点击 → 编辑弹窗打开（雾蓝配色已生效）+ 右下「浮动」钮 → 点击迁移 Document PiP 无框窗（页内点击供瞬态激活）；编辑器在 PiP 文档**自身上下文全新自举**（克隆样式 → root → chrome 桥借 opener 命名空间（PiP 非扩展上下文，chrome.* 不可用）→ module 入口 → 生命周期脚本），React/Konva/rAF 全在 PiP；承载窗最小化承载 PiP 生命周期（只缩不关），PiP 关闭（leave）后 SW 收回承载窗。工具行最左仿 macOS 三灯组（红=关窗功能灯，黄/绿示意）+ Ctrl/⌘ 滚轮缩放由 pip-lifecycle.js 在 PiP 上下文常驻承担。
- 雾蓝对账更正：plugin-theme.css 从「自造按钮覆写」改为按生产注入链 themeCssVariables('mist',…) 逐值映射 chrome 表面族（亮 #f1f3f4/#c7cbd1 系、暗 #292a2d/#3c4043 系）——此前页面无主题注入链，:root 缺省是琥珀值（#f9f6ef 暖米色工具区即用户所见）；按钮语言回归生产样式（透明圆钮 + 灰阶蒙版 + select-veil 选中），与主应用雾蓝编辑窗完全一致。

- 编辑器内容形态切换到生产 chrome=hidden-titlebar 形态开关（EditorWindow 内置）：84px 左让红绿灯位、工具条 app-region 拖动区、产出钮 no-drag——与主应用编辑图片窗口完全同源同布局；此前自制的全宽透明条/悬浮胶囊布局覆盖全部撤除，plugin-theme.css 只保留雾蓝配色。
- 窗口尺寸按图幅现算（scale=min(1,840/宽)，宽高各留工具条/边距余量并收口 1100×900），对齐主进程按图幅建窗的行为；document.title 置空弱化原生标题条。
- 浏览器硬约束如实记录：Chrome 扩展窗口无法隐藏系统标题栏（红绿灯由原生标题条承载，位于工具条上方）；主应用的无标题条窗体是 Electron 能力，插件侧做不到。

- 编辑器撤回悬浮胶囊方案：恢复全宽透明工具行（44px，功能键垂直居中，无色带）。
- 录屏「结束」按钮改回 icon（■ + tooltip 结束录制并保存 MP4），弹窗行宽重新收敛（min-width 280 防溢出）。
- 检查端文字落点根因修复：落点在可拖拽标注上会触发 Konva 原生拖拽（拖动标注而非开文本框），文字落点移至标注区域外，消除跨版本偶发失败。

- 截图编辑器：雾蓝主题（plugin-theme.css，仅插件页生效不改生产源）；顶部色带移除、功能键行 40px 垂直居中紧贴系统红绿灯行（原生标题栏无法与网页内容合并，为浏览器约束）；画布 Ctrl/⌘+滚轮缩放 0.25–4，普通滚轮保持滚动，zoom 施加于 Konva 容器并由 MutationObserver 在续编重挂后重新应用。
- 录屏弹窗：全部 icon 化 + tooltip；「停止」改「结束录制」；删除说明性文字，产物信息结束后单行呈现。
- 关键修复：popup 点击的同一任务内同步调用 getMediaStreamId（点击即调用态），拿到 streamId 再移交 SW——SW 侧取流在冷启动时会耗尽调用态窗口报 "Extension has not been invoked"（今日复现并定位）；启动期取消已丢弃未落地采集流。
