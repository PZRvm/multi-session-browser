## 1. 当前基线

- [Toolbar.tsx](../../src/renderer/src/components/browser/Toolbar.tsx) 已有原始草稿、行内补全、接受后的完整目标、指定引擎模式与聚焦期局部撤销记录。搜索标签只有文字，没有平台图标；普通模式没有默认引擎标识。
- [searchEngines.ts](../../src/renderer/src/components/browser/searchEngines.ts) 定义百度、必应、Google、DuckDuckGo、Brave Search、Ecosia、Yahoo、搜狗、360 的域名、别名和结果页构造；关键词通过 URLSearchParams 编码一次。
- 普通 Enter 当前优先选择可见高亮历史项，再处理行内/已接受目标，最后提交原文 URL。未提供普通文字默认搜索。主进程 [url.ts](../../src/main/browser/url.ts) 用补 https 与 `new URL()` 检查输入；该方法能把单词甚至中文单词视作主机，不能直接充当“网址或搜索词”分类器。
- Tab 已按原始输入精确匹配全部引擎，优先进入搜索；未命中才接受后缀，其余插 U+0009。这个反馈规则保留，不能因新增默认 Google 模式改回历史优先。
- 图标库 `@ant-design/icons` 已安装，`SearchOutlined` 为本计划唯一搜索图标；本地 LICENSE 为 MIT。`@ant-design/icons-svg/package.json` 也声明 MIT，无需新增整套图标依赖。
- 已有 28px 地址栏、Chrome 区 token、原生建议子窗与整框融合边界。只在该表面增加标识，不重建地址栏或弹层。
- [最新审查](../notes/issue/2026-11/20261106171834-地址栏补全搜索验收后审查.md)仍有待导航文本来源遗漏、原生撤销菜单和一处无关 CSS 换行。本计划的输入路由必须覆盖有效 pending 文本；其他遗留不自动视为已修复。

## 2. 范围边界

### 2.1 本阶段必须完成

**Step 0 简报。** 用户需要直接识别当前搜索平台，普通输入也能无需先按 Tab 就搜索 Google。指定引擎保留明确文字和关键词区；普通模式初始只显示 SearchOutlined，不常驻“搜索 Google”前缀文字。用户最新裁决为默认模式和全部九家指定引擎统一使用 SearchOutlined，通过显式模式的文字区分搜索平台。涉及 renderer 标识、输入分类、三语无障碍文案与相关产品文档，不改变会话/Tab 的数据所有权。

- 指定模式：`[SearchOutlined] [搜索 必应等文字] [关键词输入]`，图标在文字之前，宽度固定，不进入 input 值或复制内容。
- 普通模式：`[SearchOutlined] [地址/搜索词输入]`。初始输入为空，无“Google”或“搜索 Google”常驻前缀文字。导航网址时也不改为远程站点 favicon，避免增加未提出的图标抓取链。
- 普通非空、非网址原文无需 Tab；Enter 使用 Google 搜索。显式引擎模式依然使用当前引擎，默认 Google 不覆盖必应等已选模式。
- 空输入不导航、不发空搜索。已明确选择的历史条目和已接受的补全仍可访问；未接受的自动后缀不能改变原始输入的搜索/导航判断。
- 默认模式与九家显式模式显示同一个 SearchOutlined，保持相同尺寸与占位，不按 engineId 切换图形，也不实现图片加载/失败回退分支。
- 主窗与独立窗共用行为；简中、繁中、英文、亮暗主题与窄窗完整支持，新增可见文案和无障碍名称入三语字典。

### 2.2 本阶段明确不做

不收集或使用平台 Logo，不新增图标素材目录、按引擎图形映射、SearchEngineIcon 包装组件或逐家授权台账。不接入搜索 API、在线联想、自动下载站点 favicon、运行时 CDN、默认引擎选择设置、引擎增删管理、OpenSearch 发现或新的 Tab 搜索快捷键。不改主进程通用 normalizeInput 来影响主页、弹窗和其他调用者；不共享会话网络请求、Cookie 或代理。本轮按用户执行指令实施，不下载品牌素材或安装依赖。

### 2.3 数据与图标原则

- 搜索词只在用户 Enter 提交时成为当前会话 Tab 的导航；输入时的识别全部本地，不向 Google 或其他引擎发送击键、历史或待导航地址。
- 展示值与编辑原文分开：引擎/网址识别用原始输入，不能用自动补全后的 displayText。普通非编辑态按当前有效 `draft → pendingShown → mainUrl` 取编辑原文，解决本计划依赖的待导航读取缺口；自动后缀仅为展示。会话/Tab 切换清理模式、候选与标识派生状态，异步回执继续核对作用域和编辑版本。
- 路由结果限于 renderer 本地类型，不新增 IPC；结果 URL 仍交既有 submitUrl/navigate 链，由来源窗口当前会话加载，遵守该会话 partition 和代理。
- 图标直接复用已安装的 `@ant-design/icons` 中 SearchOutlined，继承现有 Chrome 区墨色，保留所用依赖的 MIT 版权和许可声明；不下载图片、不新增依赖或图标素材许可流程。

### 2.4 输入分类与键盘契约（Phase 1/2）

此次用户需求明确替代前轮“不增加默认搜索”的范围限制。实施步骤 1 先同步 PRD、PRODUCT、DESIGN，不能只改代码而保留旧规则。

**普通模式 Enter 顺序：** 空输入不提交 → 可见且用户明确高亮/点选的历史项访问 → 已按 Tab/右方向键接受的完整补全目标访问 → 对其余原始输入做下表分类。指定引擎模式直接搜索当前引擎的非空关键词，不走默认网址分类。

| 普通模式原文示例 | 规划结果 | 说明 |
| --- | --- | --- |
| `接口测试`、`electron devtools`、`hello` | Google 搜索 | 不需要 Tab；左侧仍为 SearchOutlined，不额外挤入前缀文字 |
| `site:example.com electron`、`C++ & React #1` | Google 搜索 | 支持常见搜索表达式，参数值编码一次，不能被通用 scheme 正则全盘拒绝 |
| `example.com`、`example.test/a?env=QA`、`例子.测试` | 直接导航 | 无空白且结构合法的带点域名，含 IDN，缺省协议沿用 https；不发 DNS 请求判断 |
| `localhost`、`localhost:3000/a`、`jenkins:8080` | 直接导航 | 保留测试环境常见 localhost/明确端口的主机形式；不把冒号端口当协议 |
| `127.0.0.1:8783/a`、`10.0.0.2`、`[::1]:3000` | 直接导航 | 先校验 IP/端口结构，不能仅凭点或冒号通过 |
| `jenkins`、`foo/bar` | Google 搜索 | 无协议、无端口的单标签主机/相对路径有歧义，默认视作文字；内网站点显式输入 `http://jenkins/` |
| 合法 `http://…`、`https://…`、`file:///…`、`about:blank` | 直接导航 | 显式合法网址继续交现有导航链，不改协议白名单 |
| `https://`、`https://bad host`、`example.com:99999`、`256.256.256.256` | 行内无效，不搜索 | 具有明确网址意图但结构无效，不能把误输的内部地址静默发给 Google |
| `javascript:…`、`data:…`、`vbscript:…`、`ftp://…`、`mailto:…` | 行内无效，不搜索 | 危险/当前未支持的显式导航意图不转换为外部搜索 |
| 普通网址中的中间 U+0009，如 `example.com/a\tb` | 行内无效 | 与前轮真实 Tab 约定一致，不能由 URL 解析器偷偷删除后访问，也不改成搜索 |
| 普通文字中的 U+0009，如 `接口\t测试` | Google 搜索 | 保留搜索词空白并编码；指定引擎模式同理 |

表内 `\t` 表示实际制表符。首尾空白沿用 trim；普通查询主体不做隐蔽替换。分类建议为本地纯函数 `classifyAddressInput(raw)`，返回 `empty / navigate / search / invalid` 及所需目标，不用“new URL 加 https 成功就是网址”这种会把 hello 识别为主机的规则。主机语法、URL 解析与显式意图校验结合，规则必须能由上表样例直接验收。

Tab 顺序保持原始引擎入口优先、其次历史补全、否则插字符；默认 SearchOutlined 不代表已进入显式 Google 搜索模式。普通词 `hello` 按 Tab 仍插字符，不因默认 Google 改为吞掉 Tab；Enter 才执行自动搜索。Esc、空关键词退格、失焦与 Shift+Tab 沿用已确认行为。

**计划采用的边界选择：** 未接受补全时，输入 `bai` 即使展示 `baidu.com` 后缀，Enter 按原始 `bai` 执行 Google 搜索；访问该历史 URL 需先 Tab/右方向键接受，或明确选择历史项。这样默认搜索不会被历史自动追加的文字抢走。实施前将这一变化列入 PRD 和手验，不沿用前轮“未接受后缀 Enter 也访问”的旧逻辑。

### 2.5 统一 SearchOutlined（最新裁决）

此前对平台 Logo 的检索用于评估素材来源；用户现已明确全部使用 SearchOutlined，因此原计划的逐家审批、Logo 回退和未来替换入口都取消，不再是实施前置项。

直接复用当前已安装的 SearchOutlined，默认空框和九家显式引擎模式显示同一个图形。平台差异只体现在显式模式的“搜索 必应”等文字与实际搜索 URL；普通模式默认 Google，初始没有引擎前缀文字。图标是装饰元素，`aria-hidden`；默认或显式搜索归属由输入框的三语 aria-label 表达，不增加冗余朗读或可聚焦按钮。

来源与许可：[Ant Design Icons MIT 许可证](https://github.com/ant-design/ant-design-icons/blob/master/packages/icons-react/LICENSE)。无需新建资产目录、逐品牌来源台账、图标包装组件或远程图片失败处理。

### 2.6 接入文件与界面方向

沿用 impeccable 的 scoped shape / Operate 模式：图标只帮助识别当前搜索归属，不成为按钮或引擎菜单；初始不显示名称和额外说明。图标约 14—16px、固定占位，与文字垂直对齐；具体值由现有 28px 工具栏度量确定，不能扩大地址栏高度或破坏原生下拉锚点。SearchOutlined 继承既有墨色，检查亮暗底可辨性。

| 文件 | 规划改动 |
| --- | --- |
| `components/browser/Toolbar.tsx` | 渲染默认/显式引擎图标与标签，整合 Enter 的网址/默认搜索分流；统一 pending 态编辑来源 |
| `components/browser/addressInput.ts`（新增，renderer 本地） | URL/查询/无效意图分类与纯函数规则；不访问网络/Node |
| `components/browser/searchEngines.ts` | 保持九家配置与默认 Google 引用单源，不新增图标映射或复制名称/模板 |
| `src/renderer/src/assets/app.css` | 图标槽、默认无文案布局、窄窗与融合态的局部样式 |
| `src/shared/i18n/locales/{zh-CN,zh-TW,en-US}/browser.ts` | 默认搜索归属与输入框无障碍名称，必要 placeholder 更新；不强行显示这些文字 |
| `book/docs/requirements/PRD.md`、`PRODUCT.md`、`DESIGN.md`、项目骨架 | 同步本次明确增加的默认搜索范围、标识状态与新文件职责 |

在 Toolbar 中直接导入并使用同一个 SearchOutlined 节点。仅新增行为分类所需的 addressInput.ts，不为相同图标建立 engineId 分支或新组件。
