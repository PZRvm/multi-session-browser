# 设置窗重构开发计划：侧栏双栏（方案一）

> 创建时间：2026-09-17 01:21:18（Asia/Shanghai）  
> 需求来源：`book/docs/requirements/stages/feature-设置窗口与全局偏好.md`（设置专项；本计划是对其阶段二交付物的设计返工）+ grill-me 决议（2026-09-17 用户选定方案一「侧栏 + 详情双栏」，视觉参照 `book/docs/prototypes/settings-redesign-demo.html`；同轮已定：快捷键=独立版面、恢复出厂=独立危险区常驻、导航选中态=琥珀反白）  
> 执行模式：直通  
> 实施范围：设置窗从单列平铺重构为侧栏 + 详情双栏（~700×480），五版面（通用/浏览/快捷键/关于/恢复出厂）——**纯壳重构，零功能边界不变**（外观/语言/主页控件仍受控只读，两步确认弹层零清理）；主进程仅调窗口度量常量；三套颜色系统（琥珀/雾蓝/苔绿，已定稿）不进本阶段，适配留阶段五专项  
> 目标结果：打开设置窗见 700×480 双栏窗——左侧分类导航（图标 + 文字，选中琥珀反白，恢复出厂红色沉底），右侧整版详情（44px 行带描述副行）；分类可点击切换版面；快捷键速查与关于升级为整版；两步确认弹层行为逐字保留；亮暗双主题全版面可读  
> 当前进度：步骤 1—4 均未开始

## 1. 当前基线

- **阶段二交付（重构对象）**：`SettingsWindow.tsx`（244 行）单列布局——ConfigProvider（algorithm 随 resolvedTheme、Segmented token 配方同板头）+ 通用/浏览/关于三组（组标题 11/500）+ 36px 行 + 危险区 + 自绘两步确认弹层（340px 卡片、confirmStep 本地 state、输入「重置」点亮、Esc 关闭）；`app.css` `.settings-window`（定位锚）/`.settings-body`（16px 留白 + 滚动）/`.settings-row`（36px 发丝线行）/`.settings-select-ghost`/`.settings-danger-btn`/`.settings-confirm` 全体系 + `--danger`/`--mask`/`--danger-veil`/`--settings-confirm-card-bg` 四对亮暗 token；`main.tsx` 第四角色 + appearance 只读镜像（失败不阻塞壳体）。
- **窗口度量现行**：`settingsWindow.ts` 初值 420×320 / min 380×260 / max 600×680——本阶段改双栏度量族（700×480 / 600×420 / 900×680）；建窗其余参数（parent/单例/级联/标题拦截/inputGuard）不动。
- **DESIGN.md 现行契约**：「设置窗口」条目为单列「内容契约 + 两步确认弹层」两段——本阶段**整段重写**为双栏契约；其中「阶段六危险区之前设置窗零琥珀」句需修订为「导航选中位琥珀反白例外」（位置信号，与会话行 Inversion Rule 同构，不稀释信号稀缺；内容区仍零琥珀至危险区）——规则修订在契约核对显式声明。
- **用户定稿事实**：方案一自 `book/docs/prototypes/settings-redesign-demo.html` 选定（该演示含三案，方案一为 700×480 侧栏双栏、可点击切版、行带描述副行、关于居中签名、键帽速查表——为本计划的视觉基准）；快捷键独立版面与危险区常驻已定；主题三色（琥珀/雾蓝/苔绿）已定稿于 `book/docs/prototypes/theme-systems-demo.html` 但适配属阶段五。
- **图标库存认**：侧栏五分类图标 `SettingOutlined`（通用）/`GlobalOutlined`（浏览）/`OrderedListOutlined`（快捷键——速查表列表语义，antd 无键盘图标）/`InfoCircleOutlined`（关于）/`WarningOutlined`（恢复出厂）均在 @ant-design/icons（图标统一纪律）。
- **契约现状（本阶段零变更）**：不新增/修改 IPC 通道、schema、preload；`src/main/` 仅动 `settingsWindow.ts` 度量常量。
- **快捷键占位口径**：速查表本阶段渲染占位键位（F12 唤起/关闭开发者工具、⌘F 页内查找、⌘L 聚焦地址栏、⌘T/⌘W 标签页——取自 DESIGN 既有记载），阶段三对齐 `src/shared/browserShortcuts` 键位表单源并补全。

## 2. 范围边界

### 2.1 本阶段必须完成

- DESIGN.md「设置窗口」条目整段重写：双栏契约（侧栏 176px/抬升层底/右缘发丝线/34px 分类行/15px 图标/琥珀反白选中/danger 分类沉底恒红、选中 danger 实底白字）+ 详情区契约（22/28 留白、版面标题 15/600 + 版面说明 11 次墨、44px 行 = label 13/500 + 描述副行 11 次墨 + 右对齐控件、发丝线分隔）+ 五版面逐版契约（通用=外观/语言/主题色行仍缺席；浏览=主页；快捷键=键帽速查表 kbd 样式 tile 底/砖线/3px 圆角/mono 11px；关于=居中产品签名 + 版本「—」+ 数据目录行；恢复出厂=大按钮 + 说明）+ 窗口度量族 700×480 / 600×420 / 900×680 + 零琥珀规则修订裁决记录 + 两步确认弹层契约原文保留

- `book/docs/architecture/项目骨架.md` 职责行同步；`book/notes/summary/2026-11/legacy-process.md` 状态同步；验收文档落盘；code-review 轮

### 2.2 本阶段明确不做

- 任何功能点亮（阶段三起）；快捷键真实数据与键位表单源对齐（阶段三）；主题色行与三套颜色系统适配（阶段五专项：DESIGN.md 色彩体系重写 + 对比度校验 + token 化）；语言 i18n（阶段六）

- `src/shared/`、`src/preload/` 任何改动（零契约变更）；`src/main/` 除度量常量外不动

### 2.3 本阶段数据原则

- 版本行占位「—」、快捷键占位键位——如实标注为演示值（注释注明阶段三接真实源），不伪造真实数据；外观行仍显示真实当前模式（只读镜像）

- 验证一律走 `MSB_USER_DATA` 隔离目录；截图为真实运行态

## 3. 分步实施

### 步骤 1：impeccable 定稿与 DESIGN.md 条目重写（主会话）

任务：

1. 以 `book/docs/prototypes/settings-redesign-demo.html` 方案一为视觉基准，走 impeccable scoped 路径把演示形态翻译为完整契约（demo 是概念级，定稿需补全：侧栏最小高度与滚动行为、详情区滚动职责、版面切换无动效或瞬切裁决、窄窗（600px 宽）下行控件换行行为、kbd 键帽组的度量与多键间隔、关于签名版面的留白节奏）
2. 重写 DESIGN.md「设置窗口」条目为双栏契约（范围见 2.1 第一条），零琥珀规则修订带裁决记录

验收：DESIGN.md 条目含侧栏/详情/五版面/度量族/弹层全部契约；与既有规则（无阴影、发丝线、图标统一 @ant-design/icons、两世界色域不互通、翻牌/反白语言）零冲突；demo 中未定的细节全部有具名裁决。

### 步骤 2：主进程窗口度量调整（主会话）

任务：

1. `src/main/settingsWindow.ts`：`DEFAULT_WIDTH/HEIGHT` → 700×480、`MIN_*` → 600×420、`MAX_*` → 900×680，头注释与 DESIGN 对账句同步

验收：`npm run typecheck` / `npm run lint` 0 错误；隔离 dev 开窗实测 700×480、可拉伸且不越 min/max。

### 步骤 3：renderer 侧栏双栏重构（派单个实现 subagent）

任务：

1. 重写 `src/renderer/src/components/SettingsWindow.tsx`：双栏骨架（`.settings-window` flex + `.settings-sidebar` + `.settings-detail`）；侧栏五分类（图标 + 文字 34px 行、当前版面本地 state、琥珀反白选中、danger 分类沉底恒红/选中实底白字、`aria-current`）；详情五版面按 DESIGN 契约（通用/浏览控件原样迁移、快捷键占位表、关于居中签名、恢复出厂版面）；两步确认弹层**整套原样保留**（含 Esc 与精确匹配逻辑）
2. `src/renderer/src/assets/app.css`：`.settings-*` 体系按新契约重写（侧栏/详情/44px 行带描述副行/kbd 键帽/新度量），既有四对亮暗 token 保留复用；弹层样式原样迁移
3. 同步 `book/docs/architecture/项目骨架.md`（SettingsWindow 职责行改「侧栏双栏全量骨架」、main.tsx 角色注释不变）

验收：`npm run typecheck` / `npm run lint` 0 错误；`git status` 确认 `src/shared/`、`src/preload/` 零改动、`src/main/` 仅步骤 2 常量；实现与 DESIGN 契约逐条对得上（含文案逐字与占位口径）。

### 步骤 4：验收收尾（主会话亲自）

任务：

1. `npm run build` 通过
2. 隔离目录 CDP 冒烟：开窗尺寸 700×480 断言；侧栏五分类逐个点击切版（各版面内容存在性断言：通用三行缺主题色/浏览主页/快捷键 ≥6 行键帽/关于签名与数据目录/危险区大按钮）；选中分类琥珀反白（背景色断言）；外观行只读断言回归（点选不生效 + 主进程 mode 不变）；两步确认完整走形回归（第一步清单/输入「重置」点亮/确认仅关闭/Esc）；亮暗双主题截图与可读性目检；窄窗拉伸不破版抽检
3. impeccable detector 对改动 UI 文件跑一次（命中既有器件如实裁决）
4. 验收文档落盘 `book/notes/summary/[时间戳]-设置窗重构侧栏双栏开发计划/[时间戳]-阶段验收.md`（含手动验收步骤：五版面走查路径）；`book/notes/summary/2026-11/legacy-process.md` 状态更新；code-review 审查轮（`book/notes/issue/` 清单，发现项按严重度裁决修复）

验收：三命令全绿；冒烟全项 PASS；验收文档与审查清单落盘；骨架/process 同步。
