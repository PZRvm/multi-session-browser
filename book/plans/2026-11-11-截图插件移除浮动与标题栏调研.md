# 截图插件移除浮动与标题栏调研

分级 M：同一截图功能区内的窗口交互修订，不改 IPC、原生窗口或会话生命周期契约。

## Step 0

背景：上一轮把 popup 没有标签栏误报为已去掉用户所指的顶部系统标题栏。用户要求先用 AnySearch 调研 Electron 和项目现有实现，再修改，并移除浮动功能；已确认运行于普通 Google Chrome。

范围：截图插件的 PiP 迁移、相关脚本/CSS、对应 Chrome 验证与文档。排除：另造 Electron 伴随程序、修改其他 worktree 宿主、录屏、图标、共享编辑工具行为。保留快照绑定、清晰缩放与原图像素导出，不新增权限或结果反馈。

## Phase 1 与 Phase 2

[双向调研](../notes/learn/2026-11/2026-11-11-截图编辑窗标题栏能力调研.md)已完成。Electron 用 hidden + trafficLightPosition，项目原编辑窗已有正确实现；普通 Chrome 没有改系统标题栏和原生按钮位置的 API。去除系统标题栏在当前运行环境无法实现，不能伪造成功。

实施：entry 直接挂载 EditorWindow，删除 PiP 的 head/script/chrome 桥与浮动入口；background 删除 PiP 消息；主题保留配色与 safe center；移除两个 PiP 独有脚本。检查脚本直接附着 popup，保留图标、画布密度、缩放、编辑和真实导出断言；新增无浮动按钮与无 PiP 窗口断言。Chrome 的原生窗框明确仍保留。
