## 2. 范围边界

### 2.1 本阶段必须完成

- 契约与白名单桥：schema v4 类型（`StoredWorkspace`、`StoredSession.workspaceId`、快照 `workspaces`/`activeWorkspaceId`）、`SESSIONS_CHANNELS` 11 → 16（新增 workspaces:create / rename / delete / move-session / set-active 五条 invoke，无新增推送）、create/clone payload 增可选 workspaceId；shared、preload 实现、`index.d.ts` 三处一致。
- 主进程：store.ts v1—v4 全版本解析迁移（v3 存量 → 空工作区 + 全会话未分组 + 视野 'all'）与容错（workspaces 坏数据回退空数组不丢会话、workspaceId 悬空置 null、activeWorkspaceId 悬空回 'all'，均告警）；五个新 handler 整单校验拒绝制；workspaces:set-active 在同一 `mutateSnapshot` 临界区内原子完成「视野落盘 + 激活位级联（含 onActiveChanged 编排）」；sessions:set-active 顺带更新该工作区 lastActiveSessionId。
- renderer：sessions store 增 workspaces/activeWorkspaceId 镜像与七个动作（切换/新建/重命名/删除/移动会话/新建与克隆带归属落点），乐观更新失败重拉权威；快照守卫与既有动作零回归。
- UI（先 impeccable）：板头下工作区切换框（收起态 = 当前视野名 + 箭头 + 「+」钮；展开态 = 过滤输入 + 选项列表 + 无匹配新建行 + 右键重命名/删除）、列表按视野过滤、全部视野未分组标记、翻牌计数随视野、会话行菜单「移动到工作区」二级菜单、批量作用域改可见列表（「关闭全部会话」仍作用全部）、拖拽全序在过滤视野下的合流、工作区空态。
- 回归与文档：重启恢复（视野 + 归属 + 各工作区激活记忆）、页面保活不变量（切换/移动/删工作区后输入/滚动/登录态/Tab/DevTools 绑定原样）、v3 存量迁移实测；同步 DESIGN.md / PRODUCT.md / `book/docs/architecture/项目骨架.md` / `book/notes/summary/2026-11/legacy-process.md`；`book/notes/summary/` 验收证据落盘。

### 2.2 本阶段明确不做

- 不做工作区自身的排序（下拉与快照均按创建序，`workspaces` 数组顺序即展示序）；多重归属（标签模型）——归属恒独占，PRD 4.8 已冻结。
- 不做按工作区共享任何配置（代理/UA/弱网等二期能力挂工作区维度时另行修订 PRD，本阶段工作区零配置语义）。
- 不做独立窗口的工作区入口（独立窗口无左栏，不渲染切换框；工作区通道只可能来自主窗，无需跨窗同步推送）。
- 不做下拉面板的拼音首字母过滤与模糊匹配（名称子串不区分大小写即可）；不做工作区图标/颜色/备注。
- 不改会话隔离链路：分区、WebContentsView 挂载、DevTools 绑定、Tab 拖出/拖入、状态推送通道全部不动；唯一编排触点是 workspaces:set-active 复用 onActiveChanged。
- 不引入新依赖（下拉自绘，不用 antd Select——其 dropdown 默认挂 body 且视觉语系不符板面）。

### 2.3 本阶段数据原则

- `sessions.json` 是工作区的唯一事实源：`workspaces` 数组（id/name/lastActiveSessionId）+ 会话 `workspaceId` 字段（null = 未分组）+ 快照 `activeWorkspaceId`（'all' 或工作区 id）；renderer 不另存归属与视野副本，store 只是镜像 + 乐观更新。
- **视野与激活正交**：激活事实唯一由 activeId 承载，视野是渲染层过滤。切工作区时主进程原子保证「视野 + 激活位」一致；除此之外（全部视野、移动激活会话出视野、删除工作区）activeId 照实不动，右侧浏览器不因视野变化重建任何页面。
- 工作区是纯元数据：不碰分区、webContents、窗口编排；删除工作区必留会话（降级未分组），坏工作区数据不得回退掉会话列表（状态不丢优先于格式洁癖）。
- 一切写通道整单校验拒绝制 + 中文错误 + 失败主进程 warn 留痕（logFailure 惯例）；乐观更新失败重拉主进程权威快照，不静默维持未落盘状态。
- 工作区 id 由主进程生成（`ws-<base36 时间戳>-<seq>`，与 SESSION_ID_RE 同构的 `WORKSPACE_ID_RE` 单源），跨 IPC 的 id 一律先过格式校验再过存在性（防篡改落盘 id，reorder 先例）；工作区名 trim 非空、上限 20 字符（`WORKSPACE_NAME_MAX` 单源）、与现存工作区重名拒绝。
- 运行时验证一律 `MSB_USER_DATA=<临时目录>` 隔离，禁止触碰真实会话数据。

### 2.4 契约核对（编码前冻结）

1. **Schema v3 → v4**：`SessionsSnapshot` 增 `workspaces: StoredWorkspace[]`（`{ id, name, lastActiveSessionId: string | null }`）与 `activeWorkspaceId: string`（常量 `WORKSPACE_VIEW_ALL = 'all'`，工作区 id 生成恒 `ws-` 前缀与之无碰撞）；`StoredSession` 增 `workspaceId: string | null`。`SNAPSHOT_VERSION = 4`；`parseSnapshot` 接受 1/2/3/4，v1—v3 读取时补默认值（workspaces: []、activeWorkspaceId: 'all'、各会话 workspaceId: null），写盘恒出 v4。容错分级：workspaces 缺失/非数组/元素坏 → 回退 `[]` 并告警（**不回退会话**）；会话 workspaceId 非 string/null 或悬空 → 置 null 并告警（会话保留）；activeWorkspaceId 非 string 或悬空 → 置 'all' 并告警。同步：`src/shared/sessions.ts` 文件头契约要点、阶段 6 计划第 2.4 节追加历史修订记录第 7 条（schema v4 + 五通道）、`book/docs/architecture/项目骨架.md` store.ts/sessions.ts 行。
2. **通道与 payload（11 → 16，全部 invoke，无推送）**：`SESSIONS_CHANNELS` 增 `workspaceCreate: 'workspaces:create'`（`CreateWorkspacePayload { name }` → `StoredWorkspace`）、`workspaceRename: 'workspaces:rename'`（`{ id, name }` → `StoredWorkspace`）、`workspaceDelete: 'workspaces:delete'`（`{ id }` → `OkResult`）、`workspaceMoveSession: 'workspaces:move-session'`（`{ sessionId, workspaceId: string | null }` → `OkResult`）、`workspaceSetActive: 'workspaces:set-active'`（`{ id: 'all' | 工作区id }` → `OkResult`）。`CreateSessionPayload`/`CloneSessionPayload` 增可选 `workspaceId?: string | null`（undefined = create 落未分组 / clone 落源会话归属；显式传值则须格式合法且存在，否则整单拒绝）。preload `index.ts` + `index.d.ts` 五方法 + 两 payload 扩展三处对齐。
3. **workspaces:set-active 原子语义（主进程内副作用，setActive 同模式）**：同一 `mutateSnapshot` 临界区内——`id === 'all'`：仅落 activeWorkspaceId，activeId 不动、零编排回调；`id` 为工作区：校验存在性，落 activeWorkspaceId = id，若当前 activeId 为 null 或 `activeId 会话的 workspaceId !== id`，则级联 activeId = 该工作区 lastActiveSessionId（已不存在或 null 则该工作区在全序中的首个会话；空工作区则 null），落盘成功后**仅当 activeId 变化**回调 `deps.onActiveChanged(nextActiveId)` 触发浏览器切换；activeId 本就属于该工作区时零回调（纯视野切换）。
4. **激活记忆归主进程**：`sessions:setActive` 成功路径在同一临界区内顺带更新被激活会话所属工作区的 `lastActiveSessionId`（会话未分组则不动 workspaces）；workspaceCreate/Clone 落归属、move-session 改归属均不动 lastActiveSessionId（记忆只随真实激活更新）。删除会话后若某工作区 lastActiveSessionId 指向它 → 置 null（悬空不落盘）。
5. **主进程拒绝制矩阵**：workspaceCreate/rename——name trim 非空（否则中文报错）、clamp 20、与现存重名拒绝；rename/delete/move/set-active 的 id 先过 `WORKSPACE_ID_RE` 再过存在性（move 的 sessionId 过 `SESSION_ID_RE` + 存在性；workspaceId 传 null 合法 = 移出）；move 到当前归属 = no-op ok（幂等，不写盘内容变化）。deleteWorkspace：目标工作区会话全部 workspaceId → null，activeWorkspaceId === id 时置 'all'，activeId 不动、零编排回调。
6. **renderer 动作语义**：store 增 `workspaces` / `activeWorkspaceId` 镜像（init 自快照）与动作 `switchWorkspace(id)`（乐观置视野 + 激活位本地级联同主进程规则，一次 IPC；失败重拉快照恢复）、`createWorkspace(name)` / `renameWorkspace` / `deleteWorkspace` / `moveSessionToWorkspace`（乐观 + 失败重拉，模式照 reorderSessions）；`addSession`/`cloneSession` 携带当前视野 workspaceId（'all' 视野传 null）。列表过滤为组件层派生（`visibleSessions`），不裁剪 store 的全量 sessions——拖拽全序、批量「关闭全部」、级联规则仍以全量为准。
7. **弹层与原生层纪律**：下拉面板自绘（`.session-panel` 内绝对定位，宽度 = 切换框宽，向下展开，`max-height` 超出滚动），不越左栏右缘；重命名与删除确认走 antd Modal 经 `ui.ts` overlayDepth 登记（SessionPanel 既有惯例）；行菜单「移动到工作区」用 antd Menu 子菜单并 `getPopupContainer` 锚回面板（既有 Dropdown 惯例）。
8. **设计文档**：`DESIGN.md` 新增「工作区切换框」条目（impeccable 定稿后写入：收起/展开/过滤/高亮/对勾/新建行/右键菜单形态、板面语系引用、「全部会话」视野未分组标记规则），「板头」条目补工作区条存在；`PRODUCT.md` 会话管理能力补工作区一句。PRD 已定稿不动（发现漏项才补）。

完成标志：上述类型/通道/payload 落入 `src/shared/sessions.ts` 与 preload 三处且 `npm run typecheck`、`npm run lint` 0 错误；阶段 6 计划 2.4 节已追加第 7 条修订记录；`grep 'workspaces:' src/` 通道字符串仅存在于 shared 常量与 preload/main 引用处。

### 步骤 2：主进程 schema v4 迁移与五通道 handler
