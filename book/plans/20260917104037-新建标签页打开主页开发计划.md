## 1. 当前基线

设置阶段三/四已交付（分支 feat/settings-stage34，未提交），与本阶段直接相关的现状，逐条对应真实文件或真实行为：

- **主页真值链已就绪**：settings.json 首键 homepageUrl（主进程守卫链规范化：scheme 白名单 http/https/file/about + 缺省补 https + 2000 上限）+ 值域三通道 + changed 全窗推送；renderer 唯一消费方 = 工具栏主页按钮 `onClick={() => navigate(homepageUrl || 'about:blank')}`（`src/renderer/src/components/browser/Toolbar.tsx:232`）。
- **新建标签页三条链路现状全部空白语义**：
  1. renderer ⌘T / Tab 栏 + 按钮 → browser store `newTab()`（`src/renderer/src/stores/browser.ts:381`）→ `browser:newTab` IPC **url 缺省分支**（`src/main/browser/ipc.ts:249-252`）→ `manager.newTab(undefined)` 并推送 focus-address；
  2. 页面聚焦态 ⌘/Ctrl+T → manager before-input-event `case 'new-tab'`（`src/main/browser/manager.ts:419-421`）→ `newTab(undefined, tab.windowId)`；
  3. 新建/克隆会话首 Tab 与零恢复集兜底 → `ensureManager` → `persistence.applyRestore` **两处空白兜底**（`src/main/browser/persistence.ts:276、288`）→ `newTab(undefined)`。
  三条链终点的 `newTab` 以 `target = url ?? BLANK_URL`（`manager.ts:342`，`BLANK_URL = 'about:blank'` 于 :23）加载空白页。
- **不受影响的两径（现状即目标）**：重启恢复——applyRestore 恢复集非空时逐条 `newTab(url)`（`persistence.ts:298-300`）；页面弹窗——`window.open` 经 `newTab(openUrl)`（`manager.ts:450`）。
- **settings 域无主进程侧同步缓存**：`loadSettings` 为异步读盘（`src/main/settings.ts:51`），而 `manager.newTab` 是同步函数——主进程内取主页值需新增内存缓存（启动填充 + setHomepage 成功后更新）。
- **ipc newTab 缺省分支推送 focus-address**（`ipc.ts:252`）——Chrome 惯例（新标签页聚焦地址栏），本阶段保留不动。
- **依赖注入风格先例**：`createTabManager(getWindow, opts)`（`manager.ts:168`）与 `createSessionBrowserRegistry(deps)`（`registry.ts:163`）均为参数注入不直接跨域 import——`getHomepageUrl` 沿用同风格经 index.ts 装配注入。
- **PRD 已修订**（2026-09-17）：3.8.2 主页条目（241 行）扩「作用于工具栏主页按钮，并作为新建标签页的默认打开地址（含新建会话的首个 Tab）。页面弹窗（window.open）按页面指定地址打开，重启恢复按各 Tab 上次地址还原，均不受主页设置影响」；验收项 27 同步。

## 2. 范围边界

### 2.1 本阶段必须完成

- **语义分流**：`newTab(undefined)` 保持「真空白」不变；manager 新增 `newUserTab()`——「用户语义的新标签页」：主页非空加载主页、否则空白。
- **三处调用点改造**：ipc.ts url 缺省分支、manager `case 'new-tab'` 分支、persistence.applyRestore 两处空白兜底，改调 `newUserTab`。
- **settings 域同步缓存**：模块级缓存 + `initHomepageCache()`（启动填充）+ `getHomepageUrl()` 同步读取；`setHomepage` 落盘成功后更新缓存（拒绝零变更）。
- **装配**：index.ts 建窗前 `await initHomepageCache()`；registry deps 与 `createTabManager` opts 增 `getHomepageUrl` 注入。
- **renderer 文案**：主页行描述改「工具栏『主页』按钮与新建标签页的默认地址」。
- **文档同步**：DESIGN.md 主页行口径、book/docs/architecture/项目骨架.md 五文件行、book/notes/summary/2026-11/legacy-process.md 条目行。
- **验收**：三命令 + 隔离 CDP 冒烟矩阵 + 验收文档 + code-review 轮。

### 2.2 本阶段明确不做

- 不改 window.open 弹窗语义与恢复集非空的逐条恢复（PRD 修订明文排除）。
- 不改主页行输入/校验/红显/changed 推送交互（阶段四已定稿）；shared 契约与 preload 暴露面零变更。
- 不做新标签页覆盖页（Chrome NTP）形态——主页即普通 URL 加载，地址栏如实显示。
- 不动 focus-address 推送（保留新标签页聚焦地址栏惯例）。
- 恢复出厂 / 主题色 / 语言归设置专项阶段五—七。

### 2.3 本阶段数据原则

- 主页真值唯一源 = settings.json（主进程守卫链规范化）；`newUserTab` 加载的地址必须来自主进程缓存（与 setHomepage 同一规范化结果），renderer 不传默认地址——不建第二套规则。
- 缓存与盘面一致：启动缓存由 loadSettings 填充（读失败回退 ''，空白语义不阻塞启动）；setHomepage 落盘成功才更新缓存。
- 一切手动验证/冒烟必须 `MSB_USER_DATA=<临时目录>` 隔离，永不触碰真实用户数据。

### 2.4 契约核对

- **IPC 通道与 payload 形状零变更**：`browser:newTab` url 缺省的语义变化（恒空白 → 主页或空白）属主进程内部语义；`shared/browser.ts` 中该通道若有「缺省空白」措辞的注释一并同步；SETTINGS_CHANNELS 不动。
- **DESIGN.md**：「设置窗口」条目主页行——描述句改为涵盖新建标签页；交互口径段补一句「新建标签页（含新建会话/克隆首 Tab 与零恢复集兜底）默认加载主页（PRD 3.8.2，2026-09-17 修订）；window.open 与重启恢复不受影响」。
- **book/docs/architecture/项目骨架.md**：manager.ts（newUserTab 语义）、ipc.ts（newTab 缺省分支）、persistence.ts（空白兜底走用户语义）、settings.ts（同步缓存）、registry.ts（getHomepageUrl 注入）五行同步。
- **PRD**：已修订完毕（前置完成，非本阶段任务）。
- 完成标志：`npm run typecheck` 0 错误；DESIGN.md 无「仅作用于工具栏主页按钮」类旧口径残留；骨架文件级表格与 src/ 实际一致。

## 3. 分步实施

### 步骤 1：主进程语义分流与依赖注入

任务：

1. `src/main/settings.ts`：增模块级 `cachedHomepageUrl` 与 `initHomepageCache(): Promise<void>`（经 loadSettings 填充，失败回退 ''）与 `getHomepageUrl(): string` 同步读取；`setHomepage` 落盘成功后同步更新缓存。
2. `src/main/browser/manager.ts`：`createTabManager` opts 增 `getHomepageUrl: () => string`；导出的 manager 公共接口（TabManager/TearOffTabManager 及 persistence.applyRestore 的参数类型）增 `newUserTab(windowId?: string): BrowserSnapshot`，实现 = `newTab(getHomepageUrl() || undefined, windowId)`；`case 'new-tab'` 改调 `newUserTab(tab.windowId)`；newTab 及分支的注释同步（「缺省空白」改「newTab 缺省恒空白，用户语义入口走 newUserTab」）。
3. `src/main/browser/ipc.ts`：`browser:newTab` url 缺省分支改 `manager.newUserTab(scope.windowId)`，focus-address 推送保留；分支注释更新。
4. `src/main/browser/persistence.ts`：applyRestore 两处空白兜底 `newTab(undefined)` → `newUserTab()`，注释注明「空白兜底 = 用户语义起始页（新建/克隆会话首 Tab、零恢复集）」。
5. `src/main/index.ts` + `src/main/browser/registry.ts`：whenReady 内建窗前 `await initHomepageCache()`；`createSessionBrowserRegistry` deps 增 `getHomepageUrl` 并在 `ensureManager` 的 `createTabManager` 调用透传。
