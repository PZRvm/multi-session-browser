# 工作区右键菜单原生化 开发计划

> 创建时间：2026-10-27 15:02:09（Asia/Shanghai）  
> 需求来源：用户 2026-10-27 交互裁决——右键工作区（分组）名称弹出的菜单改用主进程原生菜单，不用网页渲染层菜单（关联 `book/docs/requirements/stages/feature-工作区下拉切换.md`「右键列表项重命名/删除工作区」；机制先例 = 会话行菜单 2026-10-15 原生化迁移）  
> 执行模式：直通  
> 实施范围：工作区行右键菜单自渲染层 antd Dropdown 迁主进程 `Menu.popup`（复刻 popup-row-menu 先例），末位消费者 `useDeferredMenuAction` 随迁退役。不做：菜单项增删（维持重命名/删除两项）、哨兵行挂菜单、拖拽/过滤/键盘行为变化、外观入口 antd 菜单（不同交互面）  
> 目标结果：右键工作区名称弹系统原生菜单（重命名/删除工作区），OS 级绘制盖过页面 WebContentsView、点任意位置（含页面区）关闭；渲染层 Dropdown/overlay 登记/`.ant-dropdown` 豁免/延迟挂弹层机制全部退役  
> 当前进度：步骤 1—4 均未开始

## 1. 当前基线

- **渲染层菜单现状（迁移对象）**：工作区行右键菜单为 antd `Dropdown`（`WorkspaceSwitcher.tsx:359-383`，`trigger=['contextMenu']` + `placement='bottomLeft'` + portal 锁挂 `.session-panel`），菜单项 `wsMenuItems`「重命名/删除工作区」（:146-149）。配套 workaround 链：`ctxMenuId` 受控态（:55）+ 右键期间 overlay 登记收起页面视图（:116-120）+ 面板外点关闭对 `.ant-dropdown` 豁免（:129-135）+ 菜单动作经 `deferWhileMenuCloses` 延迟挂原生弹层（:143、:368）。哨兵行（全部会话/未分组）不挂菜单（:357）。
- **既有原生菜单先例（复刻模板）**：会话行菜单 2026-10-15 已迁主进程——shared 通道 `popupRowMenu`/`rowMenuAction` 与类型 `PopupRowMenuPayload {id,x,y}`/`RowMenuActionKey`/`RowMenuActionPayload`（`src/shared/sessions.ts:91-94、335-350`）；主进程 handler（`src/main/sessions.ts:811-887`）：sender 白名单（主窗）→ 载荷/id 格式/坐标守卫 → `loadSnapshot()` 存在性校验 → 坐标 clamp → `Menu` 组装（`main/i18n` 的 `t()` 取词）→ `menu.popup({window,x,y})` → 点击结论经推送通道定向回推发起 webContents；renderer 消费（`SessionRow.tsx:174-212`）：`onContextMenu` 发视口坐标 + 组件级订阅 `onRowMenuAction`（id 命中才分派，dispatchRef 防闭包旧值）+ 直接链既有编排（原生菜单无关闭动画，无需延迟机制——:178 注释明示）。
- **工作区域现状**：工作区六通道（create/rename/delete/move-session/reorder/set-active）handler 全在 `src/main/sessions.ts`（:591 起），`WORKSPACE_ID_RE` 已在该文件引用；工作区存在性可经 `loadSnapshot().workspaces` 校验（:192 同款用法）。
- **i18n 零新增**：`sessions.workspaceSwitcher.rowRename`/`rowDelete` 三语已备（`src/shared/i18n/locales/*/sessions.ts`），主进程 `t()` 已消费 workspaceSwitcher 命名空间键（`src/main/dialogs.ts:142-163` 先例）。

- **契约现状**：`SESSIONS_CHANNELS` 现 22 条（`src/shared/sessions.ts:889` 注释计数）；preload sessions 命名空间已含 `popupRowMenu`/`onRowMenuAction`（`index.ts:175-186`、`index.d.ts:130-132`）。

## 2. 范围边界

### 2.1 本阶段必须完成

- 新增两条 IPC 通道与契约类型（shared），preload 桥与 `index.d.ts` 三处对齐。
- 主进程 popup handler：复刻 popup-row-menu 全套守卫（sender 白名单/载荷/`WORKSPACE_ID_RE`/坐标 clamp/工作区存在性），`Menu` 两项（重命名/删除工作区），点击结论定向回推。
- WorkspaceSwitcher 迁移：删 antd Dropdown 及全部配套 workaround（ctxMenuId/overlay 登记/`.ant-dropdown` 豁免/延迟挂弹层），右键发视口坐标、订阅回推分派至既有 `startRename`/`confirmDelete` 编排。
- `useDeferredMenuAction.ts` 文件退役删除。
- 文档同步：DESIGN 工作区切换框条目改写（含 chromeImport 条目陈旧措辞顺带修正）、骨架五行、`book/notes/summary/2026-11/legacy-process.md`。

### 2.2 本阶段明确不做

- 不增删菜单项（维持「重命名/删除工作区」两项，与会话行菜单 2026-10-20 统一裁决无关——本菜单本就单一触发器单一变体）。
- 不给哨兵行（全部会话/未分组）与「新建工作区」行挂右键菜单（现状保持）。
- 不动拖拽排序、过滤、键盘导航、外点关闭面板等面板行为。
- 不迁移板头外观入口的 antd 菜单（设置窗/板面弹层语系，无原生层遮挡问题，另属不同交互面）。
- 零新增 i18n 字典键；零触碰会话行菜单既有链路。

### 2.3 本阶段数据原则

- 菜单只做触发转发：主进程不编排重命名/删除（既有原生 sheet/确认框链路不动），只校验与回推 `{id, key}`；守卫失败中文 warn 静默返回，不伪造成功。
- 右键坐标如实传递（视口坐标 = 窗口内容坐标），越界仅 clamp 不改语义。
- 行为口径变化如实入文档：右键期间页面视图不再收起（overlay 登记退役）、菜单存续时点页面区只关菜单不关面板——对齐会话行菜单 2026-10-15 迁移后口径。

### 2.4 契约核对

1. **`src/shared/sessions.ts` 通道扩展**：`SESSIONS_CHANNELS` 增 `workspacePopupMenu: 'workspaces:popup-menu'`（on 单向）与 `workspaceMenuAction: 'workspaces:menu-action'`（定向推送），22 → 24；新增 `PopupWorkspaceMenuPayload {id: string, x: number, y: number}`、`WorkspaceMenuActionKey = 'rename' | 'delete'`、`WorkspaceMenuActionPayload {id, key}`，紧邻既有行菜单类型落位并注明 2026-10-27 增量；头注释通道变更记录同步。需同步：骨架 3.5 `sessions.ts` 行、3.1 通道计数。
2. **preload 暴露面扩展**：sessions 命名空间增 `popupWorkspaceMenu(payload)`（send）与 `onWorkspaceMenuAction(callback)`（订阅返退订），`index.ts` 与 `index.d.ts` 必须同步（AGENTS.md 三处对齐规则）。

完成标志：`npm run typecheck` 0 错误；`grep -rn "workspacePopupMenu" src/` 在 shared/preload/main/renderer 四层各有着落。
