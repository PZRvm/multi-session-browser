# 扩展面板原生子窗口化（白屏根除）

分级M：涉及新增 IPC 通道、主进程子窗池与渲染端编排，多文件但机制照搬 omniboxSuggest 成熟先例（原生子窗口化专项已两轮审查背书），无新框架。用户实测反馈：扩展面板唤出时浏览器区域全白——即 shared/omniboxSuggest.ts 头注记载的「旧 overlayDepth 整页收起方案以页面白屏为代价（评审 L8）」，该路线在弹层类场景已退役，扩展面板是漏网登记方。

## Phase 1 影响与风险

- 白屏根因是机制性的（DOM 压不过原生层），非回归——overlayDepth 登记退役即根除，不改 overlayDepth 本体（SessionPanel Modal 仍消费，其 mask 使白屏观感弱化，属独立取舍不在本轮）。
- 子窗姿态照搬建议子窗：透明无框、懒建复用池、宿主 move/resize 跟随、closed/render-gone 级联、透明窗防护、shell 输入守卫、theme/lang query 注入。
- 与建议子窗的两处刻意分歧（各有一字注释）：**focusable:true + blur 关闭**（action popup 先例——外点含页面区点击即关，Chrome 菜单语义；建议面板是键盘驱动无需此项）、**preferred-size 自适应**（action popup 先例——面板高度随条目数变化，免度量常量配对）。
- 切换语义：mousedown 捕获「开合前状态」的 toggle（blur 先于 click 的重开竞态按 Chrome「mousedown 时已开→本次点击只关不开」语义处理）。
- learn 补写：`20261111-渲染弹层压不过原生层的三条路线.md`——overlayDepth 收起（白屏+快捷键冻结）、原生子窗（建议面板/工具栏气泡/截图反馈/编辑器先例）、原生 Menu.popup（SessionRow 先例）+ 停靠让位（FindBar 先例），先查 learn 无重复再写。
- 契约镜像真实存在性检查：所有 i18n 键（browser.extpanel.*）三语齐全，直接复用。

## Phase 2 设计

### 契约（shared/extensionsPanel.ts）

| 项 | 值 |
| --- | --- |
| 角色 | `EXTENSIONS_PANEL_WINDOW_ROLE = 'extensions-panel'` |
| 通道 | `EXTENSIONS_PANEL_CHANNELS = { show, hide, pick, setMousePassthrough, data, picked, closed }` 'extensions-panel:*' |
| show 载荷 | `{ anchor: {x,y,width,height}（按钮内容系矩形，Toolbar 点击时读取）, items: ExtensionListItem[] }` → `{ ok, canPresent }` |
| pick 载荷 | `{ kind: 'open'\|'manage'\|'close', id? }` → 主进程 requireChildOwner 白名单后转发宿主 shell 'picked' 推送 |
| 语义分域 | show/hide 仅宿主 shell（requireOwnerWindow：主窗/登记独立窗，面板子窗 sender 被拒）；pick/passthrough 仅面板子窗（requireChildOwner 池内白名单）；closed/picked/data 为主进程定向推送 |
| 语义归 shell | open→extensions.openPopup(id, anchor)+关面板；manage→extensions.manage()+关面板；close→关面板。主进程只承载（建窗/定位/转发），子窗纯渲染零自治 |
| 常量 | `EXTENSIONS_PANEL_WIDTH=360`、`EXTENSIONS_PANEL_SHADOW_MARGIN=24`（与建议面板同值；面板现有 box-shadow blur16 的 3σ≈24，环带内自然归零）、`EXTENSIONS_PANEL_MIN_HEIGHT=120`、`EXTENSIONS_PANEL_MAX_HEIGHT=600`（列表溢出走 CSS 滚动） |
| 关闭语义 | blur 关闭（action popup 先例：外点含页面区即关；`getAllWindows().some(isFocused)` 守卫防无焦点误关）+ Esc（子窗 keydown → pick close → shell 关）+ mousedown-toggle（shell 按钮防 blur 先于 click 的重开竞态） |

### 主进程子窗池（main/extensions/panel.ts，机制照搬 omniboxSuggest.ts）

- `createExtensionsPanelWindows({ getWindow, getThemeColor })` → `{ show, hide, resolveOwnerOf, setMousePassthrough }`（无 dispose 暴露面差异：含 dispose，宿主 closed 级联）
- 每宿主窗口至多一个子窗，懒创建/隐藏复用；`enablePreferredSizeMode: true`，preferred-size-changed → applySize（MIN 120×360, MAX 600, clamp）+ positionAt + 首个尺寸就绪才首次 show（action popup 具体先例，免首帧闪烁）；首个 preferred-size 到达前 show 已到 → 缓存，就绪即 flush（建议子窗 pendingData 同款时序）
- 定位：面板右缘 = 锚点右缘（anchor.x+30 域，与旧 DOM 面板几何一致），面板顶 = anchor.y+30；窗口矩形 = 面板矩形外扩 RING(24)；x 右溢出左移钳制（workArea+4），y 不做上钳制（按钮恒在工作区内），高 = preferred 高 clamp [120,600] 后再按工作区下缘收（收高走 CSS 滚动）；下方空间 < 120 → canPresent=false 拒绝展示
- 池一致性：closed → 出池摘监听 + 推 'closed'；render-process-gone → 销毁出池；宿主 move/resize → 缓存锚点重算跟随 + 空间不足只隐藏不移位；复显重置穿通态
- 透明窗防护 + shell 输入守卫 + theme/lang 建窗 query 注入；`[extensions-panel]` 日志前缀

### IPC 装配（ipc.ts 新增「扩展面板子窗域」节）

- 通道：show/hide（requireOwnerWindow 复用）+ pick/setMousePassthrough（requireChildOwner 复用）+ 载荷校验（anchor 四 finite 数 + items 数组上限 64 + id /​^[a-p]{32}$/ 校验仅在 kind=open 时）+ picked/closed 定向推送 windowForId
- index.ts 接线：`extensionsPanelWindows = createExtensionsPanelWindows(...)` 与 suggestWindows 同源 getWindow/getThemeColor；registerBrowserIpc deps 增 extensionsPanelWindows；主窗 closed 与独立窗 onWindowClosed 级联 dispose
- 管理通道不变（list/openPopup/manage 仍由 shell invoke；面板子窗不持有管理能力）

### 渲染端

- main.tsx：`?role=extensions-panel` 分支（懒加载 ExtensionsPanelWindow + 仅 init i18n 镜像）——同建议子窗形态
- ExtensionsPanelWindow.tsx：模块求值期同步订阅 data（先于主进程 ready-to-show flush，建议子窗先例）；渲染标题行+说明+插件行（icon dataURL + 名称）+管理入口；Esc keydown → pick close；mousemove 环带穿通（建议子窗同款）；close 按钮 → pick close
- useExtensionsPanelWindow.ts（Toolbar 编排）：open → extBtnRef mousedown 时捕获锚点矩形 + wasOpen 快照 → 点击翻转到 open：`extensions.list()` → show({anchor, items})；canPresent=false 保持关闭；onPicked 消费（open/manage/close 三语义，全关面板）；onClosed 消费（主进程 blur-close/销毁推送 → 收回开合态）→ presented 镜像（show 回执 canPresent 核对后置 true）
- Toolbar.tsx：删 ExtensionsPanel DOM 组件挂载与 openOverlay 链路，换 hook；按钮 aria-expanded={presented}；mousedown 快照 toggle；删除 ExtensionsPanel.tsx 文件
- ui.ts 头注：登记方清单追加「扩展面板 2026-11-11 起迁原生子窗口，不再登记」（延续既有退役记录体例）

### CSS

- `.chrome-ext-panel` 改子窗承载态：`body[data-role='extensions-panel']` 下 background transparent + 面板 div 改正常文档流（margin 24 环带、去 fixed/top/right、宽度 360 常量对账 shared 常量）；环形阴影值沿用；列表 max-height 由窗口钳制承担（overflow-y auto 已有）
- shell 侧无 CSS 改动（面板不再在 shell 里）
