# Chrome IndexedDB 导入兼容修复

**L 级**。涉及目标分区的 IndexedDB 快照识别、覆盖和失败还原。

## Step 0

当前 Electron 生成的快照也可能被拒绝。已访问过的目标站点若在浏览器仍持有旧数据库的情况下更换目录，页面可能继续读到旧值。支持的 Chrome 快照导入后应立即可读，选择保留时应保持现有数据库。校验不了的格式继续明确跳过。确认的覆盖范围为目标会话一个站点的默认 IndexedDB，其他会话、站点、命名存储桶和数据类型不受影响。复用现有导入入口、权限和结果通知。

## 当前阶段

验收。Electron 45.3.0 的目标 Chromium 为 156.0.8078.96。实际快照的后端 schema 是 5，Blink 序列化为 21，V8 序列化为 16。旧检查只读了 V8 版本。官方内部页面的非删除式 `ForceClose` 已实测关闭默认桶，随后替换目录可以即时读到新值，命名桶仍能使用。

覆盖前在目标 Session 的独立沙箱页中获取 Chromium 元数据。按默认桶和目标 LevelDB 的完整路径匹配，再等待关库。此页面只加载固定的 Chromium 内部网址、不向其他 renderer 暴露。无法确认桶、命令失败或目标格式漂移时终止覆盖。源端以 WAL 中的两个全局版本键校验，三个版本分别检查，校验范围仍限现有 LevelDB 快照。回归在真实 Electron 中生成隔离数据库，覆盖冷导入、已访问站点、Blob、命名桶、失败还原和格式拒绝，并接入 Windows CI。
