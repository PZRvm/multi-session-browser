# Release 版本校验保留零安装依赖

1.1.1 首次发布运行在版本校验处失败，尚未开始打包。`release.mjs` 静态导入附件校验器，再间接加载 `adm-zip`；prepare 任务在 `npm ci` 前运行，因此找不到该库。本地已有 node_modules，之前的验证没有覆盖这个环境。

S 级修复：仅在校验附件时动态加载校验器，版本门禁继续只依赖 Node 和 Git。用无 node_modules 的临时克隆复现失败，再替换脚本确认版本校验通过；附件命令仍须加载校验器，安装依赖后运行更新验证。工作流仍只从已合并的 dev → main PR 发布，不改触发条件与版本保护。
