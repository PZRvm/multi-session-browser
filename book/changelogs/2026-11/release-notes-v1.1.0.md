# 🚀 多会话测试浏览器 v1.1.0

本版本引入完整的 Chrome 插件体系：支持导入 CRX、从 Chrome 商店在线安装、按会话隔离加载、工具栏固定与拖拽重排；另新增地址栏历史补全与多引擎搜索、工具栏截图/录屏按钮显隐配置。

## ✨ 新功能

### 🧩 Chrome 插件体系

- **CRX 导入**：设置「插件」版面按钮导入，或直接把 `.crx` 文件拖进设置窗（全页蒙层提示「松手导入」；重复导入自动判重提示）
- **Chrome 商店在线安装**：内置商店入口，搜索后一键安装；插件页「打开 Chrome 商店」按钮直达
- **多会话隔离**：每个会话分区独立加载插件副本（路径即身份），多会话互不串味；旧会话重新激活自动自愈
- **插件管理**：卸载走原生确认框；固定 / 取消固定；工具栏扩展区胶囊，固定图标支持拖拽重排（带槽位动画）
- **原生权限确认框**：插件请求权限时按 Chrome 语义弹原生确认

### 🎥 内置双插件升级（随插件体系重制）

- **截图插件**：编辑器复用主应用截图编辑器（主题色对齐），支持滚轮清晰缩放
- **录屏插件**：录制当前标签页画面与 **Tab 音频**，MP4 落盘；popup 显示真实落盘文件名（重名自动加序号）；音频可关
- 已装 0.1.0 旧包的用户：请在设置「插件」重新导入 `extensions/dist/recorder.crx`（0.1.1）以获得保存名修复

### 🛠 配置与浏览体验

- **工具栏按钮显隐配置**：设置 → 浏览 → 「显示截图按钮」「显示录屏按钮」——装了插件的用户可隐藏内置按钮（功能保留，随时可开）
- **地址栏补全与搜索**：输入时历史行内补全、<kbd>Tab</kbd> 键九家引擎搜索（默认 Google）、统一搜索图标；地址栏编辑撤销栈等五项审查问题修复

## 🩹 稳定性

- 录制落盘链加固：dataURL 分隔符陷阱、隐藏窗后台调度饿死、收尾看门狗、无音轨自动跳过音频保活
- 扩展面板唤出白屏根除（迁原生子窗）；清单损坏自愈与写入加固
- 卸载判断反置、钉态过滤、跨面钉态联动、保存名失真等审查问题全量清账
