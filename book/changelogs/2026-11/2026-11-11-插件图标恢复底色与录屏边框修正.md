# 2026-11-11 插件底色图标与录屏边框

S 级界面细调：按用户反馈重绘带背景图标，去掉录屏重复内描边，以 Chrome 明暗渲染、PNG 核对和静态门禁验证，不改录制/编辑行为。

截图为雾蓝圆角方块与白色相机，录屏为珊瑚红圆角方块与白色摄像机及录制点；管理页和工具栏统一更新 SVG 与 PNG。录屏页面底色与内容同色，删除上轮内描边，避免和 Chrome 原生边框叠加。

用户截图顶部尖头属于 Chrome 原生 popup 的锚点箭头，不由页面绘制，不能通过扩展 CSS 取消。依据：[Chromium ExtensionPopup](https://chromium.googlesource.com/chromium/chromium/+/HEAD/chrome/browser/ui/views/extensions/extension_popup.cc) 使用 BubbleDelegateView 与 BubbleBorder::Arrow；当前插件继续使用标准 action popup，不宣称已移除原生箭头。

验证：typecheck、lint、插件构建通过；Chrome 独立 profile 15/15（`tools/plugin-preflight/out/20261111T102011/`）。核对 16/128px 图标及亮暗面板，页面描边已消除；CDP 页面截图不包括 Chrome 原生箭头，不作为其消失的证据。设计检测器仅正则降级，12px 圆角为前轮用户要求，其他提示为既有值。
