# Chrome 插件与双端工具插件

## 当前状态（2026-11-15 证据核对）

安装管理、宿主兼容、普通 Chrome 双插件和 Mac 宿主截图/录屏集成已实现并合入发布版本。Chrome 本体于 2026-11-11 获用户验收，Mac 宿主集成于 2026-11-12 获用户验收；Tab 音频于 2026-11-13 实现。功能状态与平台验收分开记录，整体任务因下方开放项保持 open。

需求单源：[PRD 3.11—3.12、4.15、验收 41—44](../../docs/requirements/PRD.md)。安装记录全局管理，运行分区保持隔离。本期不做跨会话插件设置同步、逐会话启用、账号同步或定时自动更新；显式升级保留，暂不公开上架 Chrome 商店。
