### 冒烟三轮 FAIL 排查记录（全部为测试装置产物，产品行为全程正确，如实留痕）

- **选中态读值偶发透明**：窗口被终端遮挡时 Chromium 暂停后台窗渲染，0.12s 背景过渡停在起始值——冒烟加 `Page.bringToFront` + 重读兜底后稳定；规则级诊断证实 danger 实底/琥珀反白/规则载入/变量解析全部正常

## 二、手动验收步骤（供任何人从零复验）

启动：`MSB_USER_DATA=/tmp/msb-verify-s3 npm run dev`。

1. 点板头齿轮 → 设置窗为 **700×480 双栏**：左侧分类导航（图标+文字），右侧详情；拖拽窗口边缘可在 600×420 — 900×680 间拉伸
2. 依次点击侧栏「通用/浏览/快捷键/关于/恢复出厂」五分类：右侧版面瞬切；选中分类为**琥珀反白块**，「恢复出厂」沉底红字、选中时为红色实底白字
3. 「快捷键」版面应见六行速查表（键帽样式：唤起/关闭开发者工具 F12/Esc、⌘F 查找、⌘L 地址栏、⌘T/⌘W 标签页）——**占位演示值，阶段三接真实键位**
4. 「关于」版面：居中产品名 + 「版本 —」+ 数据目录行；「通用」版面外观行随板头切换实时同步、设置内点选无效（零功能）
5. 「恢复出厂」版面点按钮 → 两步确认弹层（清单 → 输入「重置」点亮 → 确认仅关闭，无任何清理）
6. 板头外观切黑夜/白天 → 设置窗整体亮暗翻转、侧栏与键帽清晰

## 三、需人工 / 转人工项
