## 二、手动验收步骤（供任何人从零复验）

启动：仓库根目录 `MSB_USER_DATA=/tmp/msb-verify-s2 npm run dev`（隔离目录；直接真实环境亦可）。

1. 点板头齿轮打开设置窗：应见完整页面——「通用」（外观三段·当前模式选中、语言「中文（简体）」展示框）、「浏览」（主页输入框）、「关于」（版本「—」/快捷键「速查列表」/数据目录「打开」）、底部红色描边「恢复出厂设置…」按钮与说明文字
2. 板头外观切到「黑夜」→ 设置窗内外观三段选中实时跳到「黑夜」（只读镜像联动）；切回「跟随系统」恢复
3. 在设置窗内点外观其他瓣 → **选中不变**（零功能；板头也不变）
4. 主页输入框可打字，关闭重开设置窗后内容不保留（纯本地瞬态）
5. 点「恢复出厂设置…」→ 第一步后果清单 → 「下一步」→ 输入框打「重」确认钮灰着、打「重置」点亮 → 点「确认重置」**只关闭弹层**（无任何会话被删）；取消与 Esc 同样只关闭
6. 板头外观切黑夜/白天 → 设置窗整体亮暗翻转、三段与文字清晰可读
