## 二、需人工执行的验收项（GUI/OS 级，自动化环境受限，如实转人工）

> 启动方式：`npm run dev`（或 `MSB_USER_DATA=<临时目录> npm run dev` 隔离验证）。以下各项均为真实鼠标/键盘与 OS 级取证，CDP 合成事件链与 `screencapture` 区域截取在本环境不可靠（TCC 限制 + 与实机操作竞态），不伪造结果。

1. **sheet 视觉目检**：行菜单「移动到工作区…」→ macOS 呈模态卡片（本机为父窗居中、无框圆角），板面语系（抬升层底/发丝线/无阴影），亮暗两主题各看一次；zh/en 切换后标题/按钮/空态文案随语言。
2. **真实拖拽手感**：下拉面板内按住工作区行拖动——插入线跟随、放下换序立即生效；拖到「全部会话」行/面板外释放/按 Esc 均不改变顺序且无残留指示；有过滤词时行拖不起来。
3. **模态阻塞与页面可见**：sheet 存续期间点击/键盘操作主窗（会话列表、浏览器区）均无响应，页面内容全程可见不变白不重载、滚动输入状态原样；关 sheet 后交互即刻恢复。
4. **入口全链（真实点击）**：行菜单「移动到工作区…」选择目标 → 列表行归属标记变化、视野过滤正确；批量模式勾选含混合归属 → 板脚「移动到工作区」→ 徽标计数与勾选一致 → 选择后板脚反馈条「已移动 n 个到 X（跳过 m 个）」约 2.4s 淡出。
5. **失败一次性反馈**：sheet 选择后若移动失败（可临时断开主进程或构造整单拒绝），板脚 danger 反馈条持续、弹层不重现，可从入口再次发起。
6. **回归抽查**：删除会话/批量关闭/删除工作区三处原生确认框不受扰；工作区重命名（渲染层弹层）与打开测试地址（overlay 登记）不受扰；会话列表拖拽排序不受扰；恢复出厂后零工作区基线（下拉零噪音、移动入口空态句）。
7. **Windows/Linux**（如有条件）：移动模态呈系统框模态对话框、标题为「移动到工作区」、Esc/✕ 关闭即取消。

## 四、用户反馈修复轮（2026-09-21 同日闭环，分支内追加提交）

用户反馈三点：弹窗小而拥挤、当前工作区「选中效果是底部一条线」很丑、下拉框需能选未分组。定位与修复：

1. **底部一条线根因**：sheet 打开时程序化聚焦首行，全局琥珀 `:focus-visible` 描边被 `.picker-list` 滚动容器裁剪成一条横线（截图实证）。修复：行内 outline 归零，键盘焦点语言 = veil 底（与切换框键盘高亮同族）。
2. **放大疏朗**：360 宽 / 40 行高 / body 内距 16·18 / 标题 14px / 8px 主题化滚动条；度量常量单源 shared/dialog.ts 四处对账同步。
3. **当前行指示**：单条场景当前归属行不再隐藏——「当前所在」tile-ink 徽标 + 禁用态（aria-current，不参与点选/聚焦/hover）；契约 WorkspacePickerOption.current，i18n 唯一新增键 `moveModal.currentTag`。
4. **未分组视野**：下拉固定末位「未分组」行（零工作区不渲染）——WORKSPACE_VIEW_UNGROUPED 哨兵契约 + workspaceSetActive 级联（全序首个未分组，无记忆位）+ store.ts 读盘净化放行 'ungrouped'（悬空仍回退 'all'）+ 哨兵行禁拖/无右键管理；新建/克隆在该视野落未分组。
5. **执行中发现并修复**：macOS sheet 附加时系统扣减标准标题条高度（实测恒定 −28px，frame:false 亦然），窗口比公式矮 28px 致 flex 列布局压缩列表出内滚——darwin 创建期 +28 补偿 + 显窗后 getContentSize 复核重申双保险。

反馈轮验证（隔离实例 CDP + capturePage 截图目检）：sheet 单条 228 / 批量 248 高度精确、当前行 disabled +「当前所在」、聚焦行 outlineStyle=none、末位「未分组」行不可拖、切换后视野 'ungrouped' 落盘且列表过滤只剩未分组会话、combobox 标签随视野、激活位级联到未分组会话、dragover 在哨兵行不放行；三命令全绿（lint 回到存量 7 警告）。

人工项同第三节追加：未分组视野切换的实机手感、暗色主题下 sheet 新视觉。
