## A. 分隔线（PRD 3.2.2 条目一）

| # | 操作 | 预期结果 | 结论 |
| - | ---- | -------- | ---- |
| A1 | 新建会话并开 3 个 Tab（地址随意，如 example.org / about:blank / example.org），不选中中间 Tab | Tab 1 与 Tab 2 之间、Tab 2 与 Tab 3 之间各有一条竖直细线（1px、高度约为 Tab 一半、垂直居中）；线不在 Tab 两端贴边，位于间隙中央 | [ ] |
| A2 | 点击选中中间 Tab | 选中 Tab 左右两侧的分隔线**全部消失**（选中项浮起为活动态边界）；未相邻的其他分隔线不受影响 | [ ] |
| A3 | 选中第一个 Tab，再选中最后一个 Tab | 选中首 Tab：其右侧无线；选中末 Tab：其左侧无线——两态均只剩活动 Tab 远端一侧的分隔线（若有） | [ ] |
| A4 | 板头外观三段切「黑夜」，重复 A1—A3 | 暗色主题下分隔线仍清晰可见（比 tabbar 底色略亮的深灰），选中两侧无线规则一致 | [ ] |
| A5 | 悬停非活动 Tab | 悬停蒙版出现时分隔线不被遮断或异常加粗（线在间隙中，与 Tab 蒙版互不干扰） | [ ] |

## B. 栏内重排（PRD 3.2.2 条目二）

| # | 操作 | 预期结果 | 结论 |
| - | ---- | -------- | ---- |
| B1 | 在 Tab 栏内按住一个非活动 Tab **水平**拖动（位移超过约 5px 后保持水平） | 拖动 Tab 变半透明并跟手移动，其余 Tab 实时让位换位（跟手方向与光标一致）；无系统拖影 | [ ] |
| B2 | 拖到目标位置释放 | Tab 停在释放位的新顺序；点击其他 Tab 再点回，顺序保持（事实源已更新到主进程） | [ ] |
| B3 | 按住 Tab 原地微拖（不越过相邻 Tab 中点）释放 | Tab 回到原位，顺序不变；无闪烁无副作用 | [ ] |
| B4 | 按住 Tab 后立即按 Esc（拖动中） | Tab 吸附回原位、恢复不透明，顺序不变 | [ ] |
| B5 | 重排后关闭中间一个 Tab | 邻位补位正常（右侧补位），剩余顺序为重排后的相对序 | [ ] |
| B6 | 重排中观察被拖 Tab | 关闭钮隐藏（不因悬停误现）；拖动光标为抓取态 | [ ] |
| B7 | **往右连续拖动跨越 2 个及以上 Tab 位置**（实测回归项：向右第一次换位时 React 会移动被拖 Tab 自身的 DOM 节点，浏览器隐式释放指针捕获——修复前症状为「一超越一个 Tab 就直接放下」） | 向右换位连续顺畅，Tab 不中途放下、不恢复不透明；与向左拖动手感一致 | [ ] |

## C. 重排 → 拖出意图升级（与既有拖出手势的衔接）

| # | 操作 | 预期结果 | 结论 |
| - | ---- | -------- | ---- |
| C1 | 按住 Tab 水平拖动几位（发生至少一次换位）后，**继续向上/向下拖离 Tab 栏区域** | Tab 从重排模式无缝转为拖出模式：出现跟随虚影，松手在软件外空白处 → 创建独立窗口；**新窗 Tab 与源栏拖动时看到的顺序一致**（升级前位移已提交） | [ ] |
| C2 | 同会话再开一个独立窗口（或用主窗 + 独立窗），从源窗拖 Tab 对准**目标窗 Tab 栏**悬停 | 目标窗 Tab 栏整条高亮 + 插入指示竖线（既有跨窗语义），释放并入指定位 | [ ] |
| C3 | 拖 Tab 垂直向下直接拖出（未发生任何换位）拖到空白处释放 | 直接建新窗（不经过重排），原行为不变 | [ ] |
| C4 | 拖 Tab 拖离栏区后在**源窗自己**的 Tab 栏上方回落释放 | stayed 放回原位（拖出链路的源窗语义，不在飞行中转重排） | [ ] |
| C5 | 主窗激活会话 A，从独立窗口（会话 A）拖 Tab 到主窗 Tab 栏释放 | 并入主窗（同会话既有语义）；拖到会话 B 激活中的主窗 Tab 栏 → 拒绝回弹 | [ ] |
