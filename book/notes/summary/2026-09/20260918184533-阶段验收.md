## 二、GUI 手动验收（需人工执行；启动方式见下）

启动：终端（iTerm 等）于仓库根目录执行 `npm run dev`；建议 `MSB_USER_DATA=/tmp/msb-accept-dialog` 隔离目录先行（真实数据零触碰），日常自用实例可直接手验。

1. **删除会话弹原生框、右区不变白（核心诉求）**：左栏任一会话行点 ⋯ 菜单 →「删除会话」→ 预期弹出系统原生警告框（标题「删除会话」，正文含会话名与「不可恢复」，按钮 取消/删除，⚠️ 警告图标）；**弹框存续期间右侧浏览器区内容全程可见、不重载、滚动与输入状态原样（不再变白）**
2. **取消路径**：按 Esc、点「取消」、点弹框关闭钮 → 均不删除，列表与右区零变化；按 Enter → 触发默认按钮「取消」（用户裁决：安全默认，与旧版 Enter=删除 不同）
3. **确认路径**：点「删除」→ 会话删除生效（激活会话删除时级联指向按顺序首项）；删除后克隆该会话验证历史/备注随分区消亡
4. **批量关闭**：批量模式勾选 ≥2 →「关闭选中会话」→ 同验 1—3；弹框期间连点按钮仅弹一框（防重入）；确认后删除生效；确认框开启期间按 Esc 不退出批量模式（原生模态吞键）
5. **删除工作区**：切换框右键工作区项「删除」→ 有会话时正文含「将其中 N 个会话移入未分组」句、空工作区含空态句；确认后工作区删除、会话降级未分组
6. **输入类弹层回归（维持渲染层 Modal + overlay，弹框期间右区收起为已知代价）**：批量打开测试地址、移动到工作区、批量移动、会话重命名、工作区重命名均正常开关，关闭后右区页面恢复
7. **语言与主题**：设置 → 语言切 English → 三处确认框文案随英文；亮/暗/跟随系统三态下弹框明暗与应用一致（macOS 原生弹框随 nativeTheme；Windows 打包版随系统深浅色为平台约束，如实记录）
8. **按钮视觉次序**：macOS 上确认按钮（删除）与取消的左右排布按平台惯例呈现即可，语义以「取消为默认/Esc」为准绳（buttons 数组到屏幕次序存在平台差异，实现注释已注明）
