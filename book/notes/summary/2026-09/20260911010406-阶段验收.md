## 三、需人工执行项（按序操作，逐条核对预期）

以下项在真实 GUI 上操作。每项操作前保证应用已按"启动方式"启动。

### 用例 A：地址栏跳转与补 scheme（PRD 3.2.1）

1. 单击地址栏（或确认其为聚焦态），输入 `example.com`，按回车
   - 预期：页面加载 Example Domain；地址栏自动显示 `https://example.com/`；Tab 标题变为「Example Domain」；出现 favicon
2. 输入 `localhost:3000` 回车（若本地无服务，预期出现 Chromium「无法访问此网站」错误页——错误页即正确行为）
3. 输入 `not a url` 回车
   - 预期：地址栏边框短暂变红并带「无效的网址」提示（约 2.5 秒消退），不发生导航

### 用例 B：导航历史与启停（PRD 3.2.1）

1. 在 example.com 页面点击页内「Learn more」链接 → 预期跳转 iana.org，地址栏同步；后退按钮由禁用变可用
2. 点后退 → 回 example.com；点前进 → 再到 iana.org
3. 输入一个较慢的网址回车后立即观察刷新按钮 → 加载期间变为停止（X）图标，点击可停止加载
4. 点主页按钮 → 预期当前 Tab 回到「新标签页」（about:blank，地址栏清空）

### 用例 C：多 Tab 管理（PRD 3.2.2）

1. 点「+」新建 Tab → 预期新 Tab 激活、地址栏自动聚焦（可立即输入）
2. 新 Tab 打开 `example.org`，原 Tab 停在 example.com；来回点两个 Tab 切换
   - 预期：各自页面、滚动位置保留（各 Tab 在 example.com 页内输入框输入不同文字，切换后文字不丢）
3. 关闭中间一个 Tab → 预期剩余 Tab 依序保留、自动激活相邻 Tab
4. 只剩一个 Tab 时 → 预期其关闭按钮禁用（不消失）
5. 在 example.com 页面点击任意 `target="_blank"` 链接 → 预期不弹独立窗口，而是在本浏览器新开一个 Tab

### 用例 D：完整网页交互（PRD 3.2.3）

1. 打开含登录/搜索表单的站点，输入并提交 → 表单正常工作
2. 打开含 `<input type="file">` 的页面，点击选择文件 → 弹出系统文件选择器
3. 打开会 `alert()`/`confirm()` 的测试页（如浏览器控制台执行或任一含弹窗的测试站）→ 弹窗正常出现
4. 断网或输入坏域名（如 `https://nonexistent.invalid`）→ 出现 Chromium 内建错误页，无白屏崩溃

### 用例 E：快捷键（验收标准 5"与 Chrome 体验一致"）

页面聚焦态（先点一下网页内容区）：

1. Cmd/Ctrl+R 与 F5 → 刷新当前页；页面输入框内单独按 r/t/w/l → 正常键入不被拦截
2. Cmd/Ctrl+T → 新建 Tab 并聚焦地址栏；Cmd/Ctrl+W → 关闭当前 Tab（最后一个 Tab 时不关闭）
3. Cmd/Ctrl+L → 地址栏聚焦并全选，可直接输入覆盖

地址栏/shell 聚焦态：

4. Cmd/Ctrl+T/W/L 同样生效；Cmd/Ctrl+R 在 **dev 模式**下会被脚手架 optimizer 优先接管刷新应用壳（已知限制，仅 dev；生产构建由本应用处理刷新当前页）

### 用例 F：布局联动与窗口行为

1. 拖拽左右分栏分隔条 → 浏览器视图实时跟随内容区宽度变化，无拖影错位
2. 缩放窗口大小 → 视图持续铺满内容区
3. （仅 macOS）关闭窗口后点 Dock 图标重开 → 浏览器区恢复显示原 Tab 内容（收尾修复的回归项），导航可用
4. Cmd+Q 完全退出 → 重新 `npm run dev` 后：左侧会话列表完好（阶段 1 回归）；右侧回到单个「新标签页」（浏览器状态按设计不持久化）

### 用例 G：会话与浏览器零耦合（诚实性边界）

1. 依次点击/新建/删除左侧会话 → 右侧浏览器页面不发生任何变化
2. 浏览器加载页面期间观察左侧会话状态灯 → 保持「空闲」，不出现 loading 脉冲（绑定属阶段 4，不得提前出现）
3. 浏览若干页面后完全退出重启 → 左侧会话的「页面标题」仍为「未打开页面」（pageTitle 不被浏览器写入）
