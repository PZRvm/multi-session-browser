## 二、手动验收步骤（供任何人从零复验）

启动方式：仓库根目录 `MSB_USER_DATA=/tmp/msb-verify-settings npm run dev`（隔离目录防触真实数据；直接 `npm run dev` 亦可用真实环境）。

1. **板头齿轮**：主窗左栏板头右侧应见齿轮图标（外观入口、批量按钮之后，「会话」计数之前）；悬停有底色抬升，Tab 键聚焦有琥珀外框
2. **齿轮开窗**：点击齿轮 → 独立「设置」小窗打开（系统标题栏 + 标题「设置」，带红绿灯）；内容为「通用」「浏览」「关于」三组小节标题，无其他内容；**再点一次齿轮 → 不新开窗，既有窗聚焦**
3. **菜单入口（本环境无法自动化，需人工）**：macOS 屏幕顶部应用菜单「多会话测试浏览器」→「设置…」（「关于」之后），或快捷键 `⌘,` → 同一设置窗打开（与齿轮同一单例：先齿轮开窗再按 ⌘, 应聚焦不双开）
4. **互不遮挡**：设置窗开着时，主窗浏览器页面应仍可见、可点击（打开任意网页在设置窗四周操作验证）；关设置窗后页面状态无损
5. **主窗关窗级联**：设置窗开着时 macOS `⌘W` 关主窗 → 设置窗随之关闭；点 Dock 图标重开主窗后再开设置窗正常
6. **亮暗双主题**：板头外观切「黑夜」→ 设置窗即时翻暗（近黑蓝底浅色字）；切「白天」恢复
7. **外观三段阈值 390**：拖拽左栏分隔条——280px（默认）外观入口为单图标钮；拖过 390px 变三段图标 Segmented；拖回 390 以下变回单图标钮；**全程齿轮恒在**
8. **重启恢复**：设置窗开着时退出应用重开（可选）——设置窗不恢复（阶段一设计：不落盘，每次打开新建），外观选择等既有行为不受影响

## 三、需人工 / 转人工项（如实标注）

- macOS 应用菜单「设置… ⌘,」入口：OS 菜单栏无法经 CDP 自动化——菜单项代码路径与齿轮共用同一 `controller.open()`（settingsWindow.ts 单例），齿轮路径已自动化验证；菜单可见性与加速键按上文步骤 3 人工验收
- Windows 平台（齿轮唯一发现路径、菜单栏隐藏行为、窗口形态）：本环境无 Windows 机器，按历阶段惯例转人工
- 偏好文件 `settings.json`：阶段一无写路径不会生成，读取容错（ENOENT/坏 JSON/未知 version）为纯主进程逻辑，代码路径经 typecheck 与实现复核，坏文件回退行为留阶段二首个真实键入住时一并验收
