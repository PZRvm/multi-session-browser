## 三、人工验收清单（合成输入平台限制，需用户执行）

以下四项因 CDP 无法驱动（红叉按钮/系统 dock/真实键盘焦点路由/macOS 退出序列），按历阶段同口径转人工。逐项操作步骤与预期：

1. **关主窗独立窗存活（PRD 验收 16）**
   - 操作：Tab 条右键某 Tab →「移出到独立窗口」→ 独立窗出现后，点主窗口左上角红色关闭钮。
   - 预期：主窗关闭、独立窗口继续显示且可正常操作（导航、切 Tab、F12）；应用不退出（dock 图标仍在）。
2. **dock 重开主窗（PRD 验收 16 后半）**
   - 接上：点 dock 图标。
   - 预期：主窗重建，浏览器区恢复当前激活会话的 Tab 与页面（挂回原矩形）；独立窗不受影响。
3. **F12 / ESC 键盘路径（独立窗内）**
   - 操作：在独立窗内点击页面获得焦点 → 按 F12 → 按 Esc。
   - 预期：F12 唤起该 Tab 的原生 DevTools（数据与页面一致），Esc 关闭；主窗与独立窗各自的 F12 互不串台。
4. **应用退出全销毁（PRD 验收 16 末句）**
   - 操作：保持独立窗开着 → Cmd+Q 退出 → 重新启动（隔离目录）。
   - 预期：退出时全部独立窗口随之关闭；重启后无独立窗口（不恢复），主窗按落盘恢复激活会话的 main 作用域 Tab 列表（独立窗中的 Tab 过渡期不落盘，属计划内行为，阶段 10 归并收口）。

另有两项体验性核对（不阻塞）：右键菜单在主窗与独立窗内都能正确弹出定位（弹层锁定 `.browser-frame`）；独立窗与主窗的 Tab 栏/工具栏视觉一致（同一套 chrome-* 类）。
