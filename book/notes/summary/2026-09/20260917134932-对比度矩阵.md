# 主题色对比度矩阵（步骤 1 色值定稿）

> 落盘时间：2026-09-17 13:49:32（Asia/Shanghai）  
> 计算方式：Python WCAG 2.x 相对亮度公式（sRGB 线性化，(L1+0.05)/(L2+0.05)），一次性脚本实算，非工具估算。  
> 判级标准：4.5:1 = 正文文本（<18.66px 加粗）；3:1 = 大字与非文本 UI。  
> 反白行次级文字（配对 5）按合成色实算：blend(accentInk, accentBase, 0.72) 后与 accentBase 求比值。

## 二、调值记录（概念推导值 → 定稿值）

| token | 概念值（demo） | 定稿值 | 理由 |
| ---- | ---- | ---- | ---- |
| moss accentDeep / tileInk(亮) / loading(亮) | #4c7a2f | **#477329** | 配对 3 亮态 4.18 < 4.5，向深压一档至 4.60（tile）/ 5.03（bg）；色相不动、最小偏移；属 demo 页脚既注记的「概念推导值，本阶段定案」范畴 |

其余全部沿用 demo 概念值与 amber 现行值（零回归硬约束）；缺口 token（scrollbarThumb/scrollbarHover/hoverVeil/panelDivider/tileSeam/confirmCardBg/accentVeil）按琥珀系派生规则同法推导，规则见 `src/shared/themeSystems.ts` 头注释与字段注释。

## 三、豁免注记（不达标但定案保留，不伪造通过）

- **豁免 A（amber 翻牌数字 亮态 4.32）**：既有既知边距（demo 自查已注记）。零回归硬约束下不动琥珀现行值；翻牌砖为 600 字重 mono 装饰性计数、语义由容器 aria-label 承载（DESIGN「数字即翻牌」条目），且暗态 8.97 富余。
- **豁免 B（亮态 accent × bg 三系 1.57—1.73）**：立板以来的设计特征——亮态信号色对纸面底天然低对比（琥珀尤甚），选中行靠「整行反白 + 发丝线」双重边界而非纯色辨（Inversion Rule），焦点环有 2px 宽 + 2px offset 与 hover veil 辅助；暗态三系 9—10:1 富余。三套系统同规则同豁免，非本阶段引入。
- **豁免 C（滚动条 thumb 全系 1.49—1.59）**：amber 既有值同样不达标（1.59/1.49），属既有行为的等值延续；滚动条有 8px 宽度与 hover 转 controlLine 加深的二级反馈，WCAG 非文本对比对滚动条 thumb 惯例豁免。

## 四、结论

定稿后十组配对中：正文/反白/主钮/次墨/分段字形/状态点/图标全部达标；三处豁免（A/B/C）均为既有设计特征的如实延续或注记级保留，无一为本阶段新增失败。moss deep 调值后全矩阵无新增不达标项。
