# 扩展面板原生子窗口化（白屏根除）

本轮在 feature/extension-host 工作树完成，分级 M。用户实测反馈：扩展程序面板唤出时浏览器区域全白。根因是面板走 overlayDepth 整页收起路线（`openOverlay` 登记 → 零矩形收起 WebContentsView → shell 区无内容），该路线在地址栏建议原生子窗口化专项时已因「页面白屏」代价退役（shared/omniboxSuggest.ts 头注记载，评审 L8），扩展面板是漏网的最后登记方。

## 改动

参照 omniboxSuggest 成熟先例整体迁移（八个面）：

- **shared/extensionsPanel.ts**：角色/七通道契约/载荷/四度量常量（宽 360、阴影环带 24、高 clamp [120,600]）。
- **main/extensions/panel.ts**：子窗池（懒建/隐藏复用/宿主 move-resize 跟随/closed 与 render-gone 级联/透明窗防护/shell 输入守卫）。与建议子窗两处刻意分歧：focusable:true + blur 关闭（action popup 先例，外点含页面区即关，应用整体失焦不误关）；enablePreferredSizeMode 高度自适应（首尺寸到达前不显窗免闪烁）。
- **browser/ipc.ts**：扩展面板子窗域四通道（show/hide 宿主白名单 + pick/passthrough 子窗白名单，身份解析复用建议子窗域），pick 三语义（open/manage/close）定向转发宿主 shell。
- **index.ts**：建池 + 主窗/独立窗 closed 级联 dispose。
- **preload**：extensionsPanel 命名空间（show/hide/pick/passthrough + onData/onPicked/onClosed）。
- **渲染端**：`?role=extensions-panel` 角色分流（main.tsx）+ ExtensionsPanelWindow（模块求值期订阅 data 防推送先于挂载，Esc/环带穿通/关闭钮）+ useExtensionsPanelWindow hook（开面板现读锚点→list 现取→show 全量；canPresent=false 收回开合态；**mousedown-toggle 竞态处理**：面板开着时点拼图按钮，mousedown 先触发 blur 关闭，click 按快照只关不开）。
- **Toolbar.tsx**：旧 DOM 面板挂载与 openOverlay 链路删除，ExtensionsPanel.tsx 文件删除；按钮 aria-expanded 接 presented 镜像。
- **CSS**：`.chrome-ext-panel` 改子窗承载态（body[data-role] 透明 + margin 24 环带缩进，宽 360 与 shared 常量对账）。
- **stores/ui.ts**：登记方清单追加扩展面板退役记录。

页面打开期间保持可见可交互，快捷键不冻结，overlayDepth 不再被扩展面板登记。
