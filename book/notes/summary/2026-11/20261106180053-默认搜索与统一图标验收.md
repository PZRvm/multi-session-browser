# 默认搜索与统一图标验收

> 后续状态：本文记录的两项分类边界及菜单/CSS 旧遗留已全部修复，见[后续修复验收](20261106211337-地址栏审查修复验收.md)。以下保留本阶段原始结果与当时的待办。

普通文字现在无需 Tab，Enter 默认使用 Google；合法网址直接访问。默认地址栏左侧只有 SearchOutlined，九家指定引擎在同一图标后显示引擎名称。用户决定统一图形，因此没有品牌素材、远程图标或图标包装组件。所有导航仍属于当前会话当前 Tab。

实现位于 `feature/omnibox-tab-search` worktree，基线 45e42de；本轮未提交、合并或推送。按 [M 级直通计划](../../../plans/20261106172801-搜索引擎标识与默认谷歌搜索开发计划.md)执行 Step 0 和六阶段；只新增 renderer 分类文件 addressInput.ts，未改 IPC、主进程、preload、依赖或持久化。

自动后缀不决定默认搜索意图：`bai` 展示 `baidu.com` 时直接 Enter 搜索 `bai`；Tab/右方向键接受后再 Enter 访问保存的完整历史目标。完整引擎原文 Tab 优先于历史后缀。待导航原文纳入 Tab 判断、插入与撤销快照，修复前轮加载期间丢地址的问题。

## 手动验收步骤

1. 在 worktree 根目录运行 `MSB_DEV_PORT=6175 MSB_USER_DATA=/tmp/msb-omnibox-manual npm run dev`。进入主窗口，点左侧底部「新建会话」。地址栏应有搜索图标，初始为空，只显示“输入网址或搜索”占位；无“搜索 Google”前缀。零会话时输入框及图标为禁用色。
2. 在地址栏分别输入 `接口测试`、`hello`、`electron devtools`、`site:example.com electron`，直接 Enter。当前会话的当前 Tab 应打开 Google 查询，对照结果页 URL 的 q 参数应等于原文。输入 `C++ & React #1`，确认 `+`、`&`、`#` 都属于同一个查询值。清空输入 Enter，不应导航。
3. 分别输入 `example.com`、`example.test/a?env=QA`、`例子.测试`、`localhost`、`localhost:3000/a`、`jenkins:8080`、`127.0.0.1:8783/a`、`10.0.0.2`、`[::1]:3000`。Enter 应按网址访问，缺省 https；不存在的测试站点可显示 Chromium 网络错误页，但 URL 不应变为 Google。`jenkins`、`foo/bar` 应作为 Google 查询；`http://jenkins/` 应直接访问。
4. 输入 `https://`、`https://bad host`、`example.com:99999`、`256.256.256.256`、`javascript:alert(1)`、`data:text/html,x`、`vbscript:x`、`ftp://example.com/`、`mailto:a@example.com`，分别 Enter。应保留原文并出现短暂行内无效状态，不打开 Google。合法 `file:///…` 和 `about:blank` 可继续走原导航。
5. 在普通模式输入 `hello` 后按 Tab，焦点应留在地址栏并插入真实制表符；再 Enter 搜索 hello（首尾空白 trim）。输入 `接口`、Tab、`测试`、Enter，查询应保留中间制表符并编码。输入 `example.com/a`、Tab、`b`、Enter，应行内拒绝；将中间字符改为 `%09` 后应可导航。选中 `abcdef` 的 cd 按 Tab，应得到 `ab\tef`，光标在制表符后；Cmd/Ctrl+Z 和重做应恢复文本与选区。
6. 依次输入 `baidu.com`、`bing.com`、`google.com`、`duckduckgo.com`、`search.brave.com`、`ecosia.org`、`yahoo.com`、`sogou.com`、`so.com` 后按 Tab。每家都应显示同一个图标和对应搜索文字，input 只含关键词。输入 `a&b+c#d%中文` 后 Enter，应使用所选引擎、参数只编码一次。空关键词 Enter 不提交；空词 Backspace 或 Esc 恢复入口原文。模式内 Tab 仍插字符；Shift+Tab 离开输入框并清模式。
7. 先访问一个百度/必应路径建立当前会话历史，再输入完整 `bing.com`；即便自动后缀带历史路径，Tab 仍须立即进入必应搜索。另建立百度根地址历史，输入 `bai`，直接 Enter 应搜索 bai；重新输入并先 Tab/右方向键接受，再 Enter 应访问原历史完整目标。方向键高亮可见建议再 Enter，应访问该条目。
8. 用可延迟响应的本地测试页，从空白页和已有旧页分别发起导航。在响应前保持地址栏聚焦，把光标放到末尾按 Tab；已显示的待导航 URL 应保留，只增加制表符。撤销恢复完整地址，继续输入不回到旧 URL。加载期间切会话/Tab，不能残留旧草稿、模式或 pending；原会话网页继续自己的导航。
9. 在主窗口把 Tab 拖到窗外形成独立窗口，重复步骤 2、5、6，确认图标、Google 分流和必应模式行为一致。独立窗缩窄时长名称可省略，关键词仍能编辑。通过工具栏合并按钮合回主窗，历史下拉仍与地址栏融合。
10. 在设置切换简中、繁中、英文和亮暗/三主题，检查默认只有图标、指定模式为图标加文字、读屏名称表达默认 Google 或指定引擎。使用系统中文输入法选词期间按 Enter/Tab，不能提前导航或改写组合文本；此项及 Windows、高 DPI 需人工确认，CDP 结果只覆盖组合事件。
