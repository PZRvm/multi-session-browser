## 人工验收步骤

### 启动与准备

在真实终端（例如 iTerm）运行，应用用新的临时 userData，避免改动工作数据：

```bash
cd /Users/pangzerui/foreunit/multi-session-browser-wt/feature-omnibox-tab-search
MSB_DEV_PORT=6175 MSB_USER_DATA="$(mktemp -d /tmp/msb-omnibox-manual.XXXXXX)" npm run dev
```

若 6175 已有本 worktree 的 dev，使用现有实例或先正常关闭其开发进程；不要改 strictPort 或占用其他项目端口。

用第二个终端准备一个无账号的本地页面：

```bash
probe_dir=$(mktemp -d /tmp/msb-omnibox-page.XXXXXX)
printf '<title>Address test</title><input placeholder="page field">' > "$probe_dir/index.html"
python3 -m http.server 8765 --bind 127.0.0.1 --directory "$probe_dir"
```

### 主路径与边界

1. 主窗左侧点击“新建会话”。地址栏访问 `http://127.0.0.1:8765/index.html?env=QA&x=%2F`，等本地页面出现。在当前会话新建标签页，再聚焦地址栏，逐键输入 `127`。应出现选中的历史后缀；仅输入一个字符时不补全。
2. 按 Tab：后缀被接受，光标折叠到末尾，页面不导航。按 Enter：访问原完整 http URL，路径、大小写、query 和 `%2F` 不丢。重试，Backspace 首次去自动后缀、再次删除用户字符；直接粘贴 `127` 不自动追加。
3. 全选后输入 `baidu.com`，按 Tab：同一框中出现“搜索 百度”，关键词为空。输入“接口测试”再 Enter：当前会话当前 Tab 打开含该关键词的百度结果页；验证码或网络失败如实记录，不判成本地搜索成功。先在会话里访问百度根页并积累历史后，输入 `bai` 时应首 Tab 补全，次 Tab 进入搜索。
4. 对 `bing.com`、`google.com`、`duckduckgo.com`、`search.brave.com`、`ecosia.org`、`yahoo.com`、`sogou.com`、`so.com` 分别重复。搜索 `a&b+c#d%中文`，查看实际地址栏参数应还原为同一个查询值，不能拆成其他参数。
5. 引擎模式空输入按 Enter 应不导航；空输入 Backspace 或 Esc 应退出并恢复进入前地址。关键词非空 Esc 也先退出模式。再次 Esc 按现有规则回真实 URL。
6. 输入 `abc` 后 Tab 应得到 `abc` 加一个实际制表符，焦点不离开。用左右键/选区选择其中字符再 Tab，应只替换选区；连续 Tab 可重复插入。选中已有 Tab 再 Tab，即使文本不变，光标也应移到插入位置。
7. 用 Cmd/Ctrl+Z 及重做测试字符插入和接受后缀；然后分别点击原生“编辑 → 撤销/重做”。后者当前已知未接入，按审查中-1 复现并在修复后重验。实体快捷键也必须手验，不以 CDP 结果代替。
8. 输入中间含真实 Tab 的普通网址后 Enter，应红框/无效提示且不导航。首尾 Tab 可 trim；地址显式 `%09` 不按真实 Tab 拦截。引擎关键词中的 Tab 应编码为查询参数。
9. 对 `baidu.com.evil.test`、`example.test/?next=baidu.com`、`https://baidu.com/s?wd=x`、`https://user@baidu.com/` 按 Tab，不进入搜索模式；无待接受历史补全时只插字符。
10. macOS 中文输入法与 Windows 微软拼音分别组合输入 `bai`，操作候选、Tab、Enter；确认组合期不抢候选、不导航、不跳其他组件，组合完成后正常输入再能补全。此项待原生手验。
11. 新建 B 会话，输入 A 的本地页面前缀，A 的历史不得出现；在 A 地址栏保留补全/搜索词时切 B 或切同名新标签页，输入瞬态不得残留。加载中切换后也不出现旧 pending 文本。
12. 在 Tab 栏将本地测试页面拖出为独立窗口，重复步骤 1—10 的地址栏操作。到网页 input 按 Tab 仍执行网页自身焦点规则，应用不得全局拦截。
13. 设置中切换简中、繁中、英文，分别选择白天/黑夜和三主题；缩窄窗口观察标签省略而关键词可编辑。按 Shift+Tab 可退出地址栏；Ctrl+Tab 等原有快捷键仍可用。
14. 展开历史面板，验证鼠标点选、上下键高亮与 Enter；拖动、缩放窗口以及屏幕底部空间不足时，面板仍紧贴完整地址栏、不遮白页面。多显示器缩放、Windows 原生外观、真实屏幕底部空间不足项待人工补齐。
