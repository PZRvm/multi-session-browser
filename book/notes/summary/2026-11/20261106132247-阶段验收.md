## 2. 从零开始手动验收

1. 根目录运行 `npm install`（已安装依赖则跳过），再运行 `MSB_USER_DATA=/tmp/msb-merge-manual MSB_DEV_PORT=6189 npm run dev`。Windows PowerShell 先执行 `$env:MSB_USER_DATA="$env:TEMP\msb-merge-manual"`、`$env:MSB_DEV_PORT="6189"`，再 `npm run dev`。所有人工操作只在该隔离实例中进行。
2. 在左侧创建「合并验收A」。主窗开两个 Tab，地址分别为可用测试站点的页面A与页面B。将页面B的 Tab 拖离 Tab 栏释放，出现独立窗口。
3. 在该独立窗口点 Tab 栏「＋」再开两页，得到 B、C、D，点击 C 使其激活。在 C 的测试表单中输入「保留输入」，滚动页面，按 F12 打开该页 DevTools；记录其请求/页面状态。使用自己的可登录测试站点时同时保持登录。
4. 悬停独立窗口工具栏最右侧的两窗箭头钮，预期显示「合并回主窗口」。主窗口工具栏不出现此按钮。鼠标点击后，预期源窗关闭，主窗聚焦，原主窗 Tab 在先、B/C/D 按源顺序追加，C 激活；输入、滚动、登录与 DevTools 所属页保持不变，页面没有重新加载。
5. 再拖出一个独立窗口。主窗口切换到新建的「合并验收B」，保留该会话页面表单，再最小化主窗口。从独立窗口点击合并，预期主窗还原、选中「合并验收A」并显示合回的激活页。切回「合并验收B」，其页面仍保留。
6. 为 A 指定工作区「来源」，再从 A 拖出独立窗口；主窗切到一个不含 A 的工作区。独立窗口点击合并，预期主窗切回「来源」并选中 A，列表与浏览区一致。把 A 移到未分组并重复，预期切回未分组视野；原视野是「全部会话」时保持全部会话。
7. 同一会话拖出两个独立窗口。合并其中一个，预期另一个保持打开，Tab 顺序、激活页和页面输入不变。只有点击的窗口合回并关闭。
8. macOS：从主窗拖出一页，关闭主窗口但保持独立窗口；点击独立窗口合并，预期主窗口重建并显示原页面，无重复独立窗、无重新登录。Windows 只验证应用仍在运行且有独立窗口时的主窗重建分支。
9. 独立窗口新建多个 Tab，快速双击合并按钮，预期全部页面只出现一份、源窗仅关闭一次。把主窗所有 Tab 移到独立窗口、使主窗暂时无 Tab，再合并，预期也能恢复完整 Tab 列表。
10. 设置分别切换简体中文、繁体中文、English，以及白天/黑夜；把独立窗口缩至最小 480px 宽。预期按钮不被裁剪、地址栏可输入；悬停提示与无障碍名称随语言变化。通过 Tab 键聚焦新按钮并按 Enter/Space，预期可触发合并且焦点样式清晰。
11. 在独立窗口录制当前 Tab 一小段测试操作后点击合并，预期已录内容自动停止并保存，原生信息框如实反馈位置，文件可播放；不继续录制另一个会话。这项为真实录屏人工验收，自动检查仅验证 tab-moved 信号。
12. 重启隔离实例，预期各会话 Tab 按既有恢复规则回主窗口，不恢复独立窗口；此次合并后活跃会话与工作区偏好仍一致。
