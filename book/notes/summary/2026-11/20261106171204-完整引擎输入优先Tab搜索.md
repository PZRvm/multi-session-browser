# 完整引擎输入优先进入搜索

> 时间：2026-11-06 17:12:04（Asia/Shanghai）
> 分支：feature/omnibox-tab-search；worktree 端口 6175
> 分级：M，原地址栏计划内的反馈轮；不扩大 IPC、持久化或视觉范围

## 需求与修复

用户明确输入 `bing.com` 后，即使历史建议自动显示 `bing.com/search?q=old`，Tab 也应直接进入必应搜索；其他引擎遵循相同规则。

修改前在隔离实例复现：输入框显示 `bing.com/search?q=old`，选区 8—21；Tab 后仍为该历史地址，没有搜索标签。原因是 Toolbar 先处理 completion，再判断原始 draft 是否命中引擎。

本轮只调整 Toolbar 的分支顺序：先用用户原始 draft 调用既有 matchSearchEngine，精确命中即进入搜索；未命中再接受行内补全；最后插制表符。没有从自动追加的历史 URL 识别引擎。输入 `bi` 时仍接受历史补全，原始 `bing.com.evil.test` 或带 query 的结果页不会变成引擎入口。

PRD、PRODUCT、DESIGN、调研与计划的优先级描述已同步。前轮原生撤销菜单与无关 CSS 换行审查仍未处理，未将整个计划标为完成。
