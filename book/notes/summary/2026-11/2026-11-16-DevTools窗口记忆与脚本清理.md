# DevTools 窗口记忆与脚本清理

沿用 `fix/devtools-undocked-device-mode`，版本保持 1.1.5。用户要求关闭窗口几何记忆待办，并删除已验收的历史图标与 DevTools 两份回归脚本。

## 改动

窗口按来源 Session 保存正常位置/尺寸，存为其分区下的独立 `DevTools Window.json`，不改会话业务 schema。使用 getNormalBounds，恢复时按匹配显示器工作区约束位置和大小；无持久目录时只记内存。坏文件或写失败回退，保存合并为异步原子写。退出、克隆关闭会等待写入，删除会话先封笔并等完在途写，避免删除后目录被重新创建。

实际删除夹具时还复现了回收中断：工具先销毁后，WebContentsView.webContents 不再返回对象，旧清理代码再次读取会出错。现在宿主缓存工具和设备子页的 webContents 引用，按 isDestroyed 判断并完成原生窗口回收，迟到消息也作废。

删除 `scripts/history-icons-regression.mjs` 与 `scripts/devtools-regression.mjs`。它们分别检查历史图标缓存/隔离/失败回退，以及 DevTools 布局/链接归属/销毁边界，都属于开发验证代码，不是应用运行或打包依赖。历史图标脚本原已接入 dev 的 build，DevTools 脚本由本分支初轮接入，目的都是在回归失败时阻止构建。按用户验收决定，build 现恢复为 `npm run typecheck && electron-vite build`；没有删除其他脚本。旧报告中的测试证据保留为历史记录。

## 验证

- macOS / Electron 45.3.0，隔离 `MSB_USER_DATA=/tmp/msb-devtools-window-state-20261116`。窗口设置 `{x:50,y:50,width:777,height:555}` 后，关闭重开、切换会话返回、正常退出并启动新进程，均恢复该矩形；B 会话仍使用独立默认矩形。
- 删除前先移动窗口以触发写入，随后删除会话返回 ok；设备页和工具视图为 0，仅主窗保留，窗口偏好文件没有被重新创建。修复前同场景出现空浮动窗并导致删除调用超时。
- 12 项临时几何检查通过，覆盖重启读取、会话隔离、无磁盘 Session、坏格式/版本/大小、显示器移除、负坐标、小工作区、并发最后值、删除与写失败。显示器变化使用模拟工作区，未声称实际拔插验收。初轮 12 项宿主检查在临时副本适配后仍通过；这些检查不回存仓库。
- `npm run typecheck`、`npm run lint`、正常 `npm run build` 均通过；build 不再执行两份回归脚本。

按十一项清单审查：写入归属、并发、删除封笔、矩形校验、无权限扩展、原生反馈与任务范围均已检查，无新增待办。原[窗口记忆问题](../../issue/2026-11/2026-11-16-DevTools宿主修复审查.md)关闭。Windows/Linux、物理 F12、第三方插件与实际多显示器拔插仍未验收，R3 跟随策略不在本轮改变。
