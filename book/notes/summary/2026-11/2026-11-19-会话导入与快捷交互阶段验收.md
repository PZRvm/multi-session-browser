# 会话导入与快捷交互验收

- 导入已选中会话后，主进程等该会话恢复挂载再报告结果。主窗口重拉仍属于目标会话的历史。用延迟 Cookie 写入和另一会话代理准备的对照，确认导入结束后不会覆盖用户的新选择。
- localStorage 现在通过目标会话的 Chromium 原生存储写入。已打开过同源的页面会在导入完成后重新挂载并读到新值。合并保留目标专有键，带顶层站点隔离的键按不支持计数。
- 主窗与独立窗口均已验证行内 URL 补全一次回车直达。高亮建议优先，Esc 可以撤销后缀，Tab 和右方向键仍接受补全，指定搜索引擎空词及输入法候选确认均不导航。
- 双击已选或未选会话行进入原位重命名，Enter 和失焦均可保存，Esc 取消。右键入口仍可重命名，双击行菜单图标和备注输入框不触发。重新启动同一测试 profile 后读回保存名称。

macOS 的真实 Electron 测试使用隔离数据与本地测试站点。Chrome 菜单由实际会话行右键触发，自动化接管系统菜单的项目选择与结果框确认，后续选择和冲突处理在应用 sheet 中操作。九个交互用例通过。直接 IPC 定向回归覆盖确认后目标漂移、对第二个源注入写入异常后精确恢复两个源、并发切换，以及重启后读取已导入的值。Chromium 156 的 IndexedDB schema 16 样本被现有版本门禁拒绝，其他分项继续完成。兼容 schema 的 IndexedDB 导入和 Windows 本轮未测。

类型检查、lint、生产构建通过。旧版现象见[复现与修复记录](../../issue/2026-11/2026-11-19-Chrome导入后活跃localStorage未更新.md)。实施步骤见[开发计划](../../../plans/2026-11-19-会话导入与快捷交互.md)。
