# 浮动 DevTools 修复

分支 `fix/devtools-undocked-device-mode`，基于 dev `6c45905`，应用版本保持 1.1.5。用户确认允许宿主兼容适配，官方面板保持原样。原始故障见[排查报告](2026-11-16-浮动DevTools排查.md)，决定见 [ADR-010](../../../docs/decisions/ADR-010-devtools-host-compatibility.md)。

## 修复结果

`browser/devtools.ts` 使用公开自定义宿主接口加载官方前端。停靠时工具与网页组合在浏览区；浮动时工具位于原生 BaseWindow，设备辅助页留在网页所在浏览区。安全 preload 只转发原生布局和窗口消息，不导入私有前端模块、不重写面板。辅助页必须认领 Chromium 创建的原 webContents，并保留 opener。首帧 1×1 临时布局不应用到真实网页，避免移动端缩放被误设为 4 倍。

链接通过 `devtools-open-url` 接入来源 manager 与来源 Tab 的当前窗口。后台 A 打开的资源仍归 A，不能盖住当前 B 的页面。窗口转移后按最新归属打开；registry 同步既有 Tab 切换生命周期通知。会话 Session、原页面实例和固定调试目标保持不变。

关闭、所属页面销毁、窗口级联、初始化失败及迟到子页创建均回收附属视图和浮动窗口。失败恢复页面完整矩形，用原生对话框反馈。

## 本机验证

macOS / Electron 45.3.0 / Chromium 156.0.8078.96。`npm run dev:agent` 使用隔离目录 `/tmp/msb-devtools-fix-20261116`，前端 6191、独立本地夹具 6192，未操作真实用户数据。关键合成/输入检查临时使用 `showInactive()` 让原生视图完成绘制，保持不激活；结束后隐藏并清理。隐藏窗口的迟到布局不作失败或通过依据。

|---|---|

| 鼠标命中 | 缩放比例 0.77 下按原生坐标点击，按钮计数从 0 变为 1 |

| Dock side | 右/左/底/浮动均可组合布局；稳定后网页与原生设备模型尺寸一致。响应式模式在可用空间变化时可能调整高度，以工具栏实际尺寸为准 |
| 页面连续性 | 停靠往返、切会话、拖出与合并后，原启动标识、输入和按钮计数保留，无重新加载 |

| 跨窗口链接 | 原 Tab 拖至独立窗后，链接在该窗新增；合并回主窗保留原 webContents 和工具绑定 |

| 原生关闭 | 实际调用浮动窗口 close 后，快照变 false，工具视图清零，仅主窗保留，网页仍活着 |
| 关闭目标 Tab | 原网页、工具、设备辅助页和浮动窗口均回收 |

`scripts/devtools-regression.mjs` 的 12 组回归覆盖链接归属、拒绝路径、后台视图、布局坐标、主 frame 鉴权、opener 认领、开关与销毁、F12 处理器、初始化失败和迟到创建。它已接入 `npm run build`。在旧基线 `6c45905` 上只运行五组链接行为对照，三组关键用例失败；新代码全部通过，没有削弱断言。

`npm run typecheck`、`npm run lint`、`npm run build` 均通过；构建另带既有历史图标回归。临时截图和 JSON 位于 `/tmp/msb-devtools-fixed-evidence/`，其中探索过程的中间尺寸不代表最终通过数据。

## 剩余事项

审查按十一项清单完成，发现浮动窗重开不记忆位置/大小，已[登记](../../issue/2026-11/2026-11-16-DevTools宿主修复审查.md)，本轮未修。R3 是否自动跟随激活会话仍是独立产品策略，继续保留固定目标。

Windows/Linux、物理键盘 F12、第三方 DevTools 插件、多显示器和录屏共存未作实机验收。该兼容桥绑定内部宿主消息，升级 Electron 时须重跑真实尺寸、缩放和生命周期，不能只看脚本通过。本轮不合并、不推送、不发布。
