# 地址栏审查修复验收

本轮修复了地址栏累计五项问题：未支持 URI 误送 Google、显式下划线主机被拒、Unicode 空白查询误判、原生菜单未接局部撤销栈，以及无关 CSS 压行。默认 Google 和统一 SearchOutlined 的前轮未提交增量一并纳入本次提交。工作在 feature/omnibox-tab-search，起点 45e42de；不合并或推送。

原生菜单需要一条共享推送契约，因此编码前由 M 评估升级 L，完成 Step 0、分析、设计及 [ADR-002](../../../docs/decisions/ADR-002-omnibox-native-editing.md)。[计划](../../../plans/20261106190232-地址栏审查问题修复与提交.md)按直通模式执行。新桥只携带 undo/redo，从主进程发给当前聚焦的可信浏览器壳；renderer 只能订阅。地址栏菜单和键盘共用局部快照，其余壳输入、设置窗、网页表单走原生编辑，不改变分区、代理或数据存储。

## 修复与证据

| 问题 | 修复与结果 |
| --- | --- |
| 未支持 URI | 明确 scheme 除搜索运算符和合法主机端口例外外，进入无效分支；blob/view-source/magnet/自定义 URI 无外部导航调用。 |
| 下划线主机 | 显式 HTTP(S) URL 按 URL 语法放行，不再套无协议 DNS 标签限制；两条审查反例通过。 |
| Unicode 空白 | 查询识别 U+3000/U+00A0/U+2003，q 参数保留原文；网址中间 Tab 继续拒绝。 |
| 原生菜单 | 新 native-editing:command 单向闭集推送；菜单与键盘共用 applyEditCommand。空框 Tab、连续操作、选区、完整历史目标和独立窗回归通过。 |
| CSS 格式 | .chrome-tab.active::before 与 5d8aa18 的原始多行声明逐字一致，值不变。 |

测试又发现 renderer 原生 URL 会接受 `https://bad host` 并得到 `bad%20host`，Node 则拒绝。Phase 4 补充了序列化主机检查，同时验证 `https://%65xample.com/a` 和合法路径空格仍能导航，未将主机检查扩散到路径或用户信息。

## 手动验收步骤

1. 在 worktree 根运行 `MSB_DEV_PORT=6175 MSB_USER_DATA=/tmp/msb-review-fixes-manual npm run dev`；6175 占用时临时换 6176。点击「新建会话」。默认地址栏应只有搜索图标，无固定 Google 文字。
2. 普通地址栏依次输入 `blob:https://example.test/id`、`view-source:https://example.test/admin`、`magnet:?xt=urn:test`、`web+demo:private` 并 Enter。应保留原文、显示短暂行内无效，不打开 Google。`site:example.com electron` 则应 Google 搜索；`jenkins:8080` 应直接导航。
3. 输入 `http://test_env.internal/`、`https://foo_bar.example/a`，Enter 应按网址导航；没有对应环境时可显示网络错误页，但不能被地址栏当作格式无效或转 Google。`https://bad host`、`https://bad%20host` 应行内拒绝；`https://%65xample.com/a` 应正常规范化到 example.com。
4. 粘贴 `接口　测试v1.0`（中间 U+3000）和 `hello world.com`（U+00A0），Enter 应使用 Google，解码 q 后与原文一致。输入 `example.com/a`、Tab、`b` 再 Enter，仍须拒绝；普通中文词中插 Tab 则作为查询空白编码。
5. 地址栏输入 abc、Tab，点击系统「编辑 → 撤销」应只撤 Tab；点击「重做」应恢复。清空后单独 Tab，也能菜单撤销/重做。选中 abcdef 的 cd 后 Tab，撤销恢复原文及选区，重做恢复制表符及光标。
6. 先建立一条根地址历史，输入其前缀并按 Tab 接受补全。菜单撤销恢复前缀，重做恢复显示串，Enter 仍访问保存的完整协议/路径。指定必应搜索模式中插 Tab，也能菜单撤销/重做；空词不提交，Esc 恢复入口。快捷键 Mac 用 ⌘Z/⌘⇧Z，Windows 用 Ctrl+Z/Ctrl+Y。
7. 将 Tab 拖出成为独立窗，重复步骤 5；主窗不得收到独立窗命令。新建/切换会话或 Tab 后，撤销不能恢复旧作用域草稿。合回主窗后继续正常编辑。
8. 设置窗进入「浏览」，在主页文本框编辑并撤销/重做，保持原生行为。网页表单可在另一个终端运行下面本地服务，再访问 `http://127.0.0.1:8786/`，在字段中输入文本并通过实体菜单撤销/重做；地址栏值不应被改变。结束后在该终端 Ctrl+C 停止服务。

```bash
node -e "require('http').createServer((q,s)=>s.end('<input autofocus placeholder=edit-test>')).listen(8786,'127.0.0.1')"
```

历史审查中的 document.execCommand('undo') 代理测试已不再代表新的菜单入口；应以实体菜单或实际 MenuItem 回调验证。原始失败证据保留，当前状态见关联清单顶部的后续修复说明。
