# 会话插件代理接入

原来 SwitchyOmega 设置代理虽然回调成功，请求仍直连。现在设置经原生身份校验进入会话代理引擎，配置、控制权与落盘共用事务；内置手动代理优先，清除后插件接管。

固定原版 SwitchyOmega 2.5.20 已验证配置选择、直连、固定代理、自动切换；HTTP、HTTPS CONNECT、SOCKS4/5、内联/URL mandatory PAC 都由真实请求验证。坏脚本回滚、运行时异常阻断、407、会话隔离、关闭重开、进程重启、临时重载和卸载均有定向回归。原始 JSON 在 tools/extension-backlog/evidence/。

同时补齐 MV2 背景桥与同会话选项页入口，关闭会话先暂停排空再卸载，激活时恢复。全局卸载清理未加载会话的持久控制记录。永久删除回收另已提交 216a444。

Windows 实机、多款第三方插件全平台矩阵和代理认证成功路径仍需设备/样本验收。本轮没有发布新版本，不将旧插件 contextMenus/CSP 警告写成全面兼容通过。
