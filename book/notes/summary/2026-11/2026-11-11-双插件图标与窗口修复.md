# 双插件图标与窗口修复

后续状态：用户于2026-11-11确认 Chrome 插件本体验收通过。PiP/浮动已删除，最终为直接 popup 编辑、带底色相机/摄像机图标；下文保留较早修复轮记录。现状以[插件 README](../../../../extensions/README.md)与[计划交接状态](../../../plans/20261110-截图与录屏插件开发计划.md)为准。

用户反馈截图编辑预览模糊、窗口顶部区域不合适、录屏提示撑大弹窗，并要求两个插件各有两张图标。本轮在 `feature-screenshot-recorder-plugins` worktree 内完成修复。

- 两个插件各有彩色标识和工具栏线形图标，共四张 SVG，PNG 导数已接入 manifest。截图为雾蓝取景框，录屏为珊瑚红显示器与录制点；源稿在 `extensions/{screenshot,recorder}/icons/`。
- 截图初始比例按来源 Tab 的 CSS 宽度计算，保留文字实际大小；Ctrl/⌘+滚轮驱动 Konva 重绘，移除 CSS zoom。DPR=2 时显示宽 1200px 对应画布 2400px，放大 1.1 倍后为 1320px/2640px。复制、下载仍按原图像素产出。
- 普通编辑 popup 无 Tab 栏，移除 Electron 灯位让空。PiP 的三灯移到工具区上方独立行，并显式传 captureId/scale，避免误读其他截图或丢失比例。
- 录屏提示由浏览器原生 title 承载，显隐不改变面板布局；位置和延迟由浏览器决定。

验证：`npm run typecheck`、`npm run lint`、`npm run build`、`node extensions/build.mjs` 通过。最终 Chrome for Testing 独立 profile 15/15：图标映射与尺寸、编辑窗/三灯位置、缩放重绘与上下限、放大后标注/文字/裁剪/撤销重做、复制/下载像素、快照独立、过期拒绝、296/360px 明暗录屏面板、MP4 H.264/AAC、暂停排除、440Hz 音轨与无音轨开关、目标关闭收尾。

证据：`tools/plugin-preflight/out/20261111T091715/`（本地忽略目录），含 `results.json`、`editor-layout.json`、编辑器与录屏明暗 PNG、导出 PNG 和 MP4。此前一轮已 15/15；补充像素断言后遇到 popup 脚本尚未挂监听的空点击，修正驱动等待加载完成，最终再过 15/15。未削弱断言。

[审查记录](../../issue/2026-11/20261111171845-双插件界面修复审查.md)未发现新增阻塞项。设计检测器因解析依赖缺失仅做正则降级扫描，11 条已有配色/圆角 advisory 不计为完整视觉审计。未采集系统原生 tooltip 跨窗截图，Windows 与宿主端到端仍待原功能计划后续验证；本轮不代表双端插件整体交付完成。
