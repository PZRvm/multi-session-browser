# 两处错误已修复，原录屏产物另有既有问题

用户选择“两项都处理”后，本分支将根 Electron 从39.8.10升级为42.11.7，并从固定原版 React DevTools8.0.0构建独立的8.0.0.1图标修复版。原版下载包和解包样本保持原样；没有关闭sandbox或contextIsolation。正式产品的插件管理入口仍未开发。

sandbox问题采用上游引擎修复。兼容库preload仅运行于扩展顶层页与service-worker，DevTools子frame使用原生API，避免冻结chrome对象后无法创建devtools属性。

SVG问题来自ButtonIcon把React图形对象当作path.d字符串。构建器用AST只替换该函数中的一个分支：React元素直接渲染，字符串路径保持原逻辑。原包哈希、结构或匹配数变化立即拒绝；生成包保留来源、哈希和MIT许可。独立名称为React Developer Tools (MSB SVG Fix)，ID为lfengibanknmddpjebedlhkpicjdfani，关闭原商店自动更新。此结果不代表商店原版的SVG错误已修复。
