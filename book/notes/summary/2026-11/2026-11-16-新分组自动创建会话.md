# 新分组自动创建会话

此前创建分组只切入空视野，用户需要再点新建会话。现在创建并切换成功后，自动在新分组中创建一个默认会话并选中，右侧立即有默认标签页。调用现有 addSession 并显式传入新分组 ID，复用会话激活、激活记忆与首个 Tab 的既有流程。

## 验证

使用 npm run dev:agent，独立数据目录 /tmp/msb-new-workspace.nDvxas、端口 6187，通过 Electron DevTools 操作隐藏窗口，未使用日常数据。

- 键盘输入名称回车创建与鼠标点击创建：均各创建一个会话，列表选中，主进程 activeId、分组归属、lastActiveSessionId 与 browser.sessionId 一致；默认一个 about:blank Tab 已激活。
- 切换已有分组不增建会话；切换旧空分组保持空态。
- 空名与重名创建拒绝，会话数量不变。
- 注入 switchWorkspace 返回 false，界面创建分组后不继续创建会话，原视野与激活会话不变。
- SIGTERM 正常退出并用同目录重启：两个会话、当前分组、激活会话与标签页恢复。
- 截图确认新分组内会话反白选中、标签页可见、导航控件可用。
