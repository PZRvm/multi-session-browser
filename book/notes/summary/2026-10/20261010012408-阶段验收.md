## 一、启动方式

```bash
cd ~/foreunit/multi-session-browser-wt/feature-recording
MSB_DEV_PORT=6176 MSB_USER_DATA=<临时目录> npm run dev
```

MSB_USER_DATA 隔离验证（勿用真实数据）；如需 CDP 自动化加 `-- --remote-debugging-port=9223`（`npm run dev --` 透传）。

## 二、手动验收步骤（照此从零复验）

1. **录制全链**：左栏新建会话「演示」→ 地址栏输入任一含动画页面（或 file:/// 本地页）→ 工具栏点录屏钮（相机旁摄像机图标）→ 按钮变红点胶囊＋mm:ss 计时递增 → 等 ~10s → 再点胶囊（=停止）→ 弹原生信息框「录屏已保存：<路径>」→ 打开 ~/Downloads/演示_<时间戳>.webm 可播放、画面为该 Tab、时长≈录制时长。
2. **暂停/恢复**：录制中悬停胶囊弹 popover（状态行含「录制中 · mm:ss」）→ 点「暂停」→ 红点停脉、时长冻结、popover 显「已暂停」→ 点「继续」→ 计时续走（恢复后不跳变）→ 停止后文件时长 = 总时长 − 暂停时长（暂停段不落帧）。
3. **自动停止（切会话）**：录制中点击左侧另一会话 → 自动弹「已离开被录会话，录屏自动停止并保存：<路径>」→ 文件含已录内容。
4. **自动停止（关 Tab）**：录制中关闭被录 Tab → 弹「被录标签页已关闭…」→ 文件含已录内容。
5. **独占**：录制中在另一独立窗口点录屏钮 → 按钮 title 短暂显「已有录制正在进行」（accepted=false 轻量反馈）。
6. **busy 文案**：见 5（2.5s 自动消退）。
7. **三语言**：设置切 繁體中文/English → 胶囊计时不变（数字）、popover 状态与按钮文案随切（錄製中/暫停、Recording/Paused）、原生结果框文案随切。
8. **亮暗**：外观切黑夜 → 胶囊红点转暗红（#f28b82）、popover 底面随 chrome-surface 暗值、时长清晰。
9. **回归抽查**：F12 DevTools、Cmd+F 查找、克隆会话、导入 Chrome 数据各一遍行为不变。

## 四、转人工验收项（无法自动化，如实标注）

1. **独立窗口中的 Tab 录制**：拖出 Tab 成独立窗后在该窗点录屏——CDP 无法稳定构造拖拽手势；机制同 persistpair 已证的同分区跨 view 授予，风险低，需人工点验一遍。
2. **暂停期间悬停 popover 是否冻帧**（审查低-5）：popover 开启经 overlay 收起页面视图至 0x0，spike 只证 1x1 出帧——录制中悬停 popover 约 1-2s 观察产物是否缺该段。若确认冻帧，后续裁决（popover 改板内方向或录制态豁免收起）。
3. **三语言 × 亮暗全组合目检**：自动验收覆盖了 zh-CN 亮态；zh-TW/en-US × 暗态组合需人工过一遍（步骤二 7/8）。
