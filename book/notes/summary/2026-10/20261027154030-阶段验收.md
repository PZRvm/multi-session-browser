# 工作区右键菜单原生化——阶段验收

> 计划：`book/plans/20261027150209-工作区右键菜单原生化开发计划.md`（直通 4 步，步骤 1—4 全部完成）  
> 需求来源：用户 2026-10-27 交互裁决——右键工作区（分组）名称弹出的菜单改用主进程原生菜单，不用网页渲染层菜单  
> 分支：`feature/workspace-native-menu`（基 main@95b1e03）  
> 验收方式：静态断言 + 隔离实例 CDP 冒烟（DOM 事件驱动，环境注记见第三节）；原生菜单项点击与 sheet/确认框闭环为 OS 级交互，转人工清单（第四节，对齐 20261020171932 会话行菜单原生化先例）

## 一、交付摘要

右键工作区名称弹**主进程系统原生菜单**（重命名 / 删除工作区两项）：主进程 `Menu.popup` OS 级绘制盖过页面 WebContentsView 原生层、点任意位置（含页面区）关闭；点击结论经 `workspaces:menu-action` 定向推回 renderer 既有编排（重命名原生 sheet / 删除原生确认框三选）。随迁退役的渲染层机制：antd Dropdown 包装、`ctxMenuId` 受控态、右键期间 overlay 登记（页面视图不再收起）、面板外点关闭对 `.ant-dropdown` 的豁免、`useDeferredMenuAction` 延迟挂弹层（末位消费者消失，hook 文件删除）。

## 四、人工验收清单（OS 级交互，需真人执行）

启动方式：正式终端（iTerm 等）`npm run dev`（或打包产物）；建议先新建 ≥2 个工作区（左栏工作区切换框内输入名称回车即建），其中一个工作区内放 ≥1 个会话、另一个保持为空。

1. **右键菜单形态**：右键工作区名称行 → 应弹**系统原生菜单**（macOS 系统菜单样式，非页面内浮层），含「重命名 / 删除工作区」两项；右键「全部会话」「未分组」哨兵行与「＋ 新建工作区『关键词』」行应无菜单。
2. **全区域关闭**：菜单弹出后分别点击右侧页面区、左栏空白处、桌面 → 每次菜单都应关闭；点页面区时**面板保持展开**（新口径：只关菜单不关面板）。
3. **重命名闭环**：右键 → 重命名 → 原生 sheet 弹出且预填现名、挂载即聚焦全选；Enter 提交后列表与当前视野名即时更新；Esc/取消零副作用；重名/超长提交被拒且行内反馈。
4. **删除闭环（含会话）**：右键含会话的工作区 → 删除工作区 → 原生确认框呈「取消 / 保留会话 / 删除全部会话」三键：保留会话 → 工作区消失、其会话移入未分组；删除全部会话 → 工作区与会话均消失；取消 → 零副作用。
5. **删除闭环（空工作区）**：右键空工作区 → 确认框维持「取消 / 删除」两键。
6. **面板行为不回归**：过滤输入子串过滤、↑↓ 键盘导航、Enter 选中、Esc 关闭、点面板外关闭、面板内拖动工作区换序（drop 后顺序持久化）逐项复验。
7. **三语言抽查**：设置 → 语言切英文（或繁中）→ 再右键工作区行 → 菜单项文案随语言（Rename / Delete）。
8. **Windows 抽查**（有环境时）：同 1—4 在 Windows 复验（原生菜单为系统样式，理论无平台分支）。
