## 3. 高危功能错误（单列）

- [ ] **[高] removeInstall 存在性判断反置：安装数 ≥2 时卸载任何插件恒返 NOT_FOUND**
  - 位置：`src/main/extensions/install/manifest-store.ts:305`
  - 证据：本轮 diff 将 `some((v) => v.id === id)` 误改为 `some((v) => v.id !== id)`——语义从「不存在该 ID 才 false」反转为「存在任一不同 ID 即 false」；安装 ≥2 个插件时卸载任意一个都命中 false → uninstall 返回 NOT_FOUND，且 pins 清理随 return 跳过。设置页卸载按钮（本应用卸载主 UI）在装 2 个及以上插件时全部失效；仅剩最后 1 个插件时可卸载。基线对比：dfc9778 版本为 `===`（正确）
  - 建议：恢复 `v.id === id`；补一条「卸载事务在多插件清单下的回归」用例
