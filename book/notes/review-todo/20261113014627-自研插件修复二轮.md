### 2.5 通知遗漏

结论：发现 1 个问题

- [ ] **[中] popup 保存提示名与实际落盘名不一致**
  - 位置：`extensions/recorder/background.js:137`（filename 由扩展自行拼接）vs shims.ts writeDownloadFile（重名自动加序号落盘）
  - 证据：真机实测——popup 显示「已保存 recording-2.mp4」，磁盘实际为 recording-2-1.mp4（重名序号场景）；用户按提示名找文件会找不到
  - 建议：下载 shim 返回的 path 已含真实落盘名，扩展侧以返回 path 的 basename 展示

### 2.6 边界遗漏

结论：发现 5 个问题

- [ ] **[中] 录制期间被录 tab 本地播放被静音（enableLocalEcho 默认 false）**
  - 位置：`src/main/extensions/shims.ts:222`（授流 callback 未传 enableLocalEcho）
  - 证据：d.ts 25028-25032——audio 为 WebFrameMain 时默认 `false` = **录制期间被录页面的本地播放静音**，用户边看抖音边录会"视频没声了"；Chrome tab 采集语义是用户仍能听到
  - 建议：授流加 `enableLocalEcho: true`（捕获的是 webContents 音频非麦克风，无回声风险）
  
- [ ] **[低] readBlobAsDataUrl 标记缺失防御**：`dataUrl.indexOf(';base64,')` 为 -1 时 slice(7) 截出垃圾——上游恒含标记，仅防御性
  - 位置：`src/main/extensions/shims.ts`（writeDownloadFile 调用链）
  - 建议：显式校验含标记否则 throw UNSUPPORTED_URL
  
- [ ] **[低] agent 调试端口 9222 固定**：端口被占时 CDP 静默失效
  - 位置：`src/main/index.ts`（isAgentDebug 分支）
  - 建议：占用时回退或允许环境变量覆盖
  
- [ ] **[低] disable-renderer-backgrounding 应用级全局生效**：所有隐藏渲染器（含后台会话页）不再降级，资源占用上升为已知权衡（注释已写明理由）
  - 位置：`src/main/index.ts`（appendSwitch 处）
  - 建议：持续观察多会话场景 CPU/内存；必要时收敛为采集窗粒度
  
- [ ] **[低] 收尾看门狗依赖 SW 存活**：挂起期间 SW 被杀则 15s 定时器失效，楔死仍可能
  - 位置：`extensions/recorder/background.js`（setTimeout 15s）
  - 建议：记录为已知边界；更彻底方案是 popup 侧兜底计时
