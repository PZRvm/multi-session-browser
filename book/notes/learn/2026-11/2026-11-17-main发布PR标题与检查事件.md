# main发布PR标题同样受Clean Commit约束

`.github/workflows/git-policy.yml`对目标main的PR执行`check-commit-message.mjs "$PR_TITLE"`，而目标dev检查提交列表。因此发布PR标题也要使用`🚀 release: 发布1.1.9商店安装与插件名称本地化`这种中文格式，不能只写版本与产品名。

PR #19最初因标题缺少emoji/type失败；远程push与PR的检查构建均通过。标题已修正。当前工作流没有订阅pull_request.edited，仅修改标题不会生成新检查；需要后续synchronize事件。重跑旧job会继续消费旧事件中的标题，不能据此判断修正无效。

应用：创建发布PR前先用同一脚本校验标题；检查失败后先区分产品代码、元数据与工作流事件，再处理。PR实时结果见[PR #19](https://github.com/PZRvm/multi-session-browser/pull/19)。
