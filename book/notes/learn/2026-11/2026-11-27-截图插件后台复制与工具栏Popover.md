# 先验证系统里的 PNG，再打开截图 Popover

普通 Chrome 158 的扩展 Service Worker 和 Electron 45.3 的主进程，都在创建结果界面之前写入了 macOS 系统剪贴板。用 NSPasteboard 读取 PNG 并核对宽高和九个采样点。Chrome 无头实例的验证未得到系统位图，有窗口的隔离实例通过。

Chrome 157 起提供扩展 Worker 剪贴板写入。Electron 由主进程凭工具栏点击的一次性授权采集当时的标签，并沿同一条链写入 PNG。普通 Chrome 的原生扩展 Popover 只能在活跃的浏览器窗口打开，CDP 激活标签不保证浏览器窗口已取得前台。手动验收时先激活专用 Chrome 窗，再点击截图插件。 [Chrome 剪贴板迁移说明](https://developer.chrome.com/docs/extensions/develop/migrate/to-service-workers) · [Chrome Action API](https://developer.chrome.com/docs/extensions/reference/api/action)

截图回归单独使用 \`node tools/plugin-preflight/check-plugins.mjs --screenshot-only\`，只加载截图插件和无音频测试页。验证复制前后读取的是当前截图，下载用任务 ID 排除上一张已经完成的原图下载。
