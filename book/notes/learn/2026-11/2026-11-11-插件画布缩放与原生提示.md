# 截图预览放大要重绘画布，不能只放大 CSS

截图导出清晰而预览模糊时，分别查原图尺寸、Stage 显示比例、canvas backing 尺寸与 CSS zoom。CSS zoom 放大的仍是已缩小的位图；修改 Konva Stage 的 scale 与尺寸才能重新绘制图像和标注。DPR=2 的本轮实测：显示宽 1200px、canvas 宽 2400px；放大 1.1 倍后变为 1320px/2640px，密度仍为 2。导出继续按 `pixelRatio=1/scale` 还原图像坐标，不跟随显示大小降低输出分辨率。机制参考 [Konva Canvas API](https://konvajs.org/api/Konva.Canvas.html)。

Document PiP 的 location 不继承 opener 的 query。编辑器自举时必须显式携带 captureId 与初始比例，否则会误读全局最新快照，并以比例 1 显示。PiP 文档有独立焦点；自动化复制前要聚焦 PiP，并从其 navigator 读取真实剪贴板，不能只给最小化 opener 开焦点模拟。

Chrome action popup 会根据可滚动范围自动计算尺寸。绝对定位 tooltip 即使不在普通文档流，仍可能扩大 scroll extent；z-index 也不能越过原生窗口边界。简单按钮说明使用浏览器原生 title，避免留白和裁切。位置与延迟由浏览器控制，不保证固定在某个方向。

插件 popup 的 DOM 就绪早于外部脚本完成。真机检查点击前等待 `document.readyState === 'complete'` 和按钮可用，避免监听器尚未注册时空点击。
