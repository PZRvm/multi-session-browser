# 插件界面验证要等待真实状态并读取正确的DOM值

Cookie-Editor1.13切页动画约300ms，保存回调使用document.querySelector('form')。200ms就填新表单并保存，可能取到旧表单；仅加等待写入也不能纠正目标。等待旧表单移除、只剩create表单后保存，原版包新增/修改/删除均成功，另一同源分区不受影响。不要由此类失败直接推断cookies.set不兼容。

React DevTools8在Electron39中可注册Components/Profiler；可见tab列表受窗口宽度/折叠影响，不能代替完整注册表。实际选择Fixture后，属性名session和值"A"在input.value中，不在body.innerText里。应读相邻属性输入，再真实开始/结束Profiler并检查提交数据。

原生sandbox和SVG日志仍存在，但与上述功能通过可以同时发生。结论必须分开写：功能实证通过，不代表日志已修复。当前DevTools前端模块仅用于固定版本实验驱动，不能成为生产插件接口。
