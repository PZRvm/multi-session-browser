# 更新封锁不能静默阻止在途内部恢复

preparing=true 后再等待激活完成，会令 manager.newTab 的统一守卫同时拒绝内部 applyRestore；严格保存随后得到合法空数组，不能识别它实际上丢失了原网址。

应从一开始拒绝外部新意图，允许已接受任务在排空期间完成同步内部恢复，排空结束再冻结。内部许可必须窄到同步调用栈并 finally 清除，不能通过异步上下文向网页事件泄漏；异步补载也必须登记等待。回归应连真实 registry / manager / persistence / store，不能只分别测试守卫和文件写入。
