# ZIP下载就绪不代表macOS已接受安装

在autoInstallOnAppQuit=false时，electron-updater先缓存ZIP并发update-downloaded；quitAndInstall才让原生Squirrel取包并验签。隔离临时签名包复现了SQRLCodeSignatureErrorDomain及Code signature did not pass validation，约一秒内失败，应用仍存活。

安装命令调用quitAndInstall后已返回，随后出现的原生错误不会经过原命令等待结果后的提示代码。只更新快照会让用户看到重启图标仍在，以为卡住。晚到错误及交接超时必须独立收敛并显示原生说明，同时按revision去重，不能与同步失败各弹一次。

本次仅验证临时签名失败及反馈链路，未使用正式签名材料，不据此证明真实升级或用户同一次操作的完整日志。

`Cannot download differentially, fallback to full download`表示差量下载失败后改下整包。当前本地测试源`scripts/update-test.mjs`不处理Range：对ZIP发`Range: bytes=0-0`实测返回200、整包长度140717516，无Accept-Ranges和Content-Range。若后续已有`New version ... has been downloaded`及代理监听日志，说明整包已缓存并准备交给Squirrel，尚不能判断安装结果。排查时应继续找安装动作之后的原生错误或交接超时，不能将差量回退当作最终失败原因。
