# 地址栏草稿与焦点分开管理

Toolbar 曾用 draft 是否为 null 同时判断编辑内容和焦点，onBlur 清 draft，onFocus 用页面 URL 覆写，导致未提交输入消失。保留草稿后，建议列表必须额外受 focused 控制，失焦只关闭建议并移除未接受后缀，不能连带丢失已接受目标或搜索引擎。

若草稿与当前展示 URL 相同且无搜索模式或接受目标，失焦后释放草稿，让网页后续导航继续回填真实地址。作用域切换仍清空全部瞬态，防止把旧标签页输入带入新标签页。本轮隔离 dev:agent 已验证普通网址、空输入、补全、搜索、Esc、真实回车导航和作用域切换。

本条更新旧地址栏经验中“失焦清草稿/退出搜索模式”的行为；旧记录保留为历史证据。
