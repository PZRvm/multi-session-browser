# 插件加载成功不能作为主要功能兼容的验收

场景：Electron39.8.10 / Chromium142，候选 electron-chrome-extensions4.10.0。原版插件 loadExtension 和 popup 成功后，仍可能在写Cookie或完整DevTools交互失败。React hook检出也不证明 Components/Profiler 可用。下次先固定原版包和Chrome主操作对照，再检查真实页面效果/数据，保留失败，不改第三方最低版本或关闭sandbox凑通过。

本轮 macOS 的 Chrome157 与 Electron39 都实际生成 H264/AAC 带Tab音频MP4。Chrome使用tabCapture/offscreen，Electron指定目标WebFrameMain并启用本地播放；两端共用MediaRecorder。应检查成品音轨、暂停后的有效时长和完整解码；MIME支持或纯视频编码成功不够。两个Tab分别输出440/733Hz可用于有限窗口的混音排查，不能替代全片检查和音画同步测量。

Chrome调试协议的 Extensions.triggerAction 需要tab目标；页面Runtime操作则使用page目标。自有MV3刚loadUnpacked时须等待service worker完成监听注册，否则触发action可能无响应。全部实验使用专用profile，不能拿日常Chromeprofile开远程调试。

本轮最终结论仍为未通过，细节见 [验证记录](../../summary/2026-11/20261109191500-Chrome插件前置验证记录.md)。Windows未执行，不能外推。
