# 页面 IPC 不能回退到自报扩展 ID

UA 与 Worker 隔离的 Phase 4 中，在独立网页 preload 里仅开放一个诊断 IPC，再自报同会话已加载扩展 ID。网站请求 contexts 返回 ok:true；原鉴权在 frame 不是扩展时继续采用 payload.extId。

原生过滤会阻止网站获得生产桥，但不能替代 IPC 自身鉴权。页面事件必须核对 senderFrame 是主 frame、来源为已加载扩展且 Session 一致；SW 事件直接核对 serviceWorker.scope、event.session 和已加载记录。不要把普通页面身份判定失败当成 Worker 分支入口。

本次在验证阶段修正，保留同会话、跨会话反例以及合法 popup/Worker 的录屏与下载回归。诊断代码与数据只存在 MSB_USER_DATA 指定的 /tmp/msb-env-* 目录。
