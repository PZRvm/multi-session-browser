# 地址栏路由使用编辑原文，接受补全后才使用历史目标

普通文字新增默认 Google 搜索后，不能再把 `completion.displayText` 当作提交意图。输入 `bai` 自动展示 `baidu.com` 时，Enter 应搜索 `bai`；Tab/右方向键接受后，才可通过保存的完整目标访问历史 URL，避免丢掉 HTTP 协议或原始参数。

导航刚发起时主进程快照可能仍是旧 URL。此时输入框显示 pending，Tab 判断和编辑快照也必须按 `draft ?? pendingShown ?? mainUrl` 取值。仅统一展示值会造成“看见完整地址，按 Tab 却只剩制表符”。本轮用真实本地慢响应分别从空白页和旧页面复验，Tab、撤销和后续输入都保留待导航文本。

分类器用本地语法区分网址、查询与无效网址；`new URL('https://hello')` 成功不能证明用户想访问 hello。另需区分测试层：`input[type=text]` 在 React 收到值之前移除 CR/LF，这类原文防护可直接验证纯函数，不能通过 `fill()` 后假定输入框保留换行。IME 的 CDP 事件验证也不能代替真实系统候选菜单验收。
