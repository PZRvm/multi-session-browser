# 更新前保存与 Mac 交接

应用更新使用 electron-updater 6.8.9。普通退出的 flush 吞错、sealed 不可恢复；更新专用 prepare 必须严格上抛，恢复集包括无待写 timer 的全部存活会话。store 读取失败也不能回退空快照继续安装，所以严格路径同时启用严格读盘。保存超时不等于底层写入已取消，互斥保留到队列落定再恢复。

MacUpdater 在 autoInstallOnAppQuit=false 时，下载 ZIP 后先发 update-downloaded，但尚未交给原生 Squirrel；quitAndInstall 才开始原生下载及验签。该方法会注册原生 update-downloaded 回调，错误后重试若不移除旧回调，可能越过新的保存窗口。适配层记录本次新增监听，在错误或交接超时时移除；不移除库自己的状态监听。

自研录屏 offscreen 窗长期存活，存在不代表忙碌。更新前从采集窗读取 chrome.storage.local.rec.state，starting、recording、paused、finalizing 都拒绝；未知状态或查询超时保守拒绝。准备期间授流 handler 返回空结果，挡住先前已发 token 的迟到开录。其他第三方插件未全面覆盖，不声称所有录屏可观察。

本机生成 90.0.1/90.0.2 arm64 临时签名包，已跑通本地清单发现、真实 ZIP 下载及校验。正式签名/公证与应用替换尚未验证，不能用 ready 状态当作完整升级通过。
