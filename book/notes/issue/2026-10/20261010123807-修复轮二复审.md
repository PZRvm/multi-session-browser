## 2. 八项必查结论

### 2.1 重复代码

结论：已查，未发现问题。

四处 span 的 onMouseEnter/onFocus 参数相同（同 label/keyText/kind）属 JSX 声明式接线的固有形态而非逻辑重复（两组事件语义不同：hover 与 focus 各自触发）；抽 handler 工厂反而遮蔽逐钮差异（胶囊钮文案动态取）。

### 2.2 权限漏洞

### 2.3 竞态条件

结论：已查，未发现问题。

- resize 即隐 effect：仅触 ref（稳定）与 setState setter（稳定），空依赖数组无陈旧闭包问题；组件卸载 removeEventListener 清理；resize 连发期间 hide 幂等（置 null 无条件跳过已 null 态）
- 300ms 延迟计时器与 focus/hover 的交错：onFocus 在已悬停时重复调 showToolsPop 仅重置同一计时器（同内容同锚点，无可见抖动）；onBlur 与 onMouseLeave 双路隐藏收敛于同一 hideToolsPop（幂等）

### 2.6 边界遗漏（入参范围 / 空值 / 极值）

结论：已查，未发现问题。

复审核过的交互边界：

- disabled 钮（截图钮无激活 Tab、录屏钮无激活 Tab）：不派发鼠标事件且**不可聚焦**（原生 button disabled 语义）→ hover 经 span 承接、focus 恒不触发——与修复前行为一致，无新路径
- 点击聚焦时序：mousedown 聚焦 → onFocus 触发（e.currentTarget = span，rect 等值）→ onClick 动作；录制钮/胶囊 onClick 显式 hideToolsPop 后组件随录制态重排（idle span 卸载，React 卸载不派发 blur——气泡已被 onClick 清空，无悬挂）
- 锚点等值性：span 为 .chrome-tools（flex 容器）的 flex 项，fit-content 紧包 28×28 按钮，rect 与按钮 rect 等值——消 querySelector 后气泡几何不变
- 键盘 Tab：地址栏 → 四钮依次可达，聚焦即显泡、Tab 离开即隐（onBlur），焦点环不受 span 干扰（span 无 tabindex）
