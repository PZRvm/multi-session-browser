### 6. 边界遗漏

- **[中-1] 显式 URL 的下划线主机被额外域名规则拒绝**
  - 位置：`src/renderer/src/components/browser/addressInput.ts:68`。
  - 现象：`http://test_env.internal/`、`https://foo_bar.example/a` 经 `new URL()` 合法，现有主进程 normalizeInput 也会放行；新分类器仍对显式 URL 应用仅字母/数字/连字符的主机标签规则，返回 invalid。与计划“合法显式网址继续走原导航链”不符，影响使用此类主机名的测试环境。
  - 复现：普通地址栏粘贴上述任一地址并 Enter，出现行内无效；探针记录 `parsed` 为完整 URL，`result.kind=invalid`、`aria-invalid=true`。
  - 建议：区分显式 URL 的 URL 语法有效性与无协议域名的意图推断；保留危险协议、IP/端口及控制字符防护，补充显式下划线主机回归。
- **[中-2] Unicode 空白查询带点号时被当作无效网址**
  - 位置：`src/renderer/src/components/browser/addressInput.ts:39`。
  - 现象：空白分流只匹配 ASCII 空格。`接口　测试v1.0`（U+3000）和 `hello world.com`（U+00A0）有点号，因 hostIntent 进入网址分支，URL 解析失败后显示无效，没有按普通非网址文字使用 Google。
  - 复现：在普通地址栏粘贴上述字符串并 Enter，`result.kind=invalid`、`aria-invalid=true`；显式搜索模式可绕过。与普通非网址文本自动搜索规则不符。
  - 建议：明确查询空白的 Unicode 范围，同时保留真实 Tab 出现在网址中间时的拒绝语义；不要直接用全部空白把既定 URL Tab 防护改为外发查询。

证据：`/tmp/msb-default-search-review.cjs`、`/tmp/msb-default-search-review-probes.json`。纯函数与真实 input Enter 均复现，未修改源码。
