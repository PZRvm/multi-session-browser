# DevTools 宿主修复审查

2026-11-16，分支 `fix/devtools-undocked-device-mode`，L 级任务的 Phase 5。实现与本机测试见[修复报告](../../summary/2026-11/2026-11-16-浮动DevTools修复.md)。按项目规则，本阶段只记录，不修改实现。

## 新问题：浮动窗口未记忆位置和尺寸（低，open）

复现：打开浮动 DevTools，把窗口设置为 `{ x:50, y:50, width:777, height:555 }`，关闭后立即重开。实际恢复为 `{ x:830, y:370, width:900, height:700 }`，同一进程也未记忆。

原因：兼容宿主每次建立新的 BaseWindow，使用默认尺寸；不再走 Electron 受管 DevTools 的窗口矩形保存路径。Dock side 的官方偏好仍保留，设备模拟和目标绑定不受影响。

后续方向：明确运行期与跨重启的位置记忆范围，复用屏幕工作区裁剪规则，覆盖显示器移除、最小化与多窗口。若引入新的落盘 UI 状态，需要重新设计归属和损坏回退；本轮排除了持久化格式变更，未顺手补入。

## 十一项审查

| 检查 | 结论 |
|---|---|
| 重复代码 | 挂摘集中在宿主，registry 不再反查裸页面视图 |
| 权限 | 专用 bridge 校验工具主 frame 和内置 URL；网页不获新增桥，辅助页严格匹配并禁止再开窗口 |
| 竞态 | 开关幂等，迟到子页立即关闭，销毁监听与计时器清理有回归 |
| 事务边界 | 无会话 schema 或分区数据迁移，链接留在来源会话 |
| 通知 | 新链接 Tab 发送既有生命周期通知，失败走原生对话框 |
| 边界 | 非法 URL、矩形、子 frame、更新准备、注销、失效来源与窗口均覆盖 |
| 复杂度 | 引入版本绑定的内部宿主消息桥；代价已由用户确认并记 ADR-010 |
| 无需求支撑部分 | 没有重写面板、引擎升级或 renderer 改版 |
| 体验 | 设备尺寸、UA、触摸、缩放鼠标命中与关闭已实测；窗口几何记忆缺口见上文 |
| 范围 | R1/R2 修复；R3 浮动窗跟随策略保留原行为 |
| 分级 | 生命周期与专用桥按 L 执行，未降级 |

Windows/Linux、物理键盘 F12、第三方 DevTools 插件和多显示器恢复未作实机验收；F12 仅验证了实际监听已安装及回归夹具中的关闭路径，不能标为物理键验收通过。
