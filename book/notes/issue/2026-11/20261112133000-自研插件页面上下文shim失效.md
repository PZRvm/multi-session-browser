# 自研插件页面上下文 shim 失效

2026-11-12 排查定性（详见 learn/2026-11/20261112133000-自研插件CRX失效三因排查.md），基线 feature/chrome-extension-preflight 工作树当前态。

## 位置与机制

- `src/main/extensions/runtime/preload-guard.ts`：生成的守卫 preload 把 shim 赋值写在 preload 隔离上下文的 globalThis.chrome 上。
- `node_modules/electron-chrome-extensions/dist/chrome-extension-api.preload.js`：库在 contextIsolation 下经 contextBridge.executeInMainWorld 注入主世界 chrome 并 Object.freeze。
- 结果：扩展页面（popup/editor/offscreen 页）主世界拿不到 shim。SW 上下文无隔离，shim 有效。

- 实证：录屏 popup 主世界 tabCapture=undefined，popup.js:60 点「开始录制」抛 Cannot read properties of undefined (reading 'getMediaStreamId')；截图编辑器 chrome.downloads.download 是库 noop 桩（下载静默无效）；getUserMedia tab 源改写在页面上下文同样不生效，M2 offscreen 链断在同一机制。
- `src/main/extensions/management.ts`：popup-less 插件（截图）点击 → openPopup → NO_POPUP 直接返回，未派发 chrome.action.onClicked（引擎 activateBrowserAction 有派发路径，宿主自建 popup 链未接）。
- `src/main/extensions/install/manifest-store.ts`：validateInstallRecord 返回对象不含 name，读盘校验往返持续剥离 name（应用内 list 自愈回填，面板不受影响）。

## 处置约定

1. shim 修复为主修项：改经 contextBridge.executeInMainWorld 在主世界注入（注意库 Object.freeze 时序——须在库注入前挂好，或以 defineProperty configurable 方式在冻结后无法挂，需实测冻结前的注入窗口）。
2. popup-less 点击派发 onClicked 作为独立小项接上（readPopupPath 无 popup 时走引擎派发而非返回 NO_POPUP）。
3. validateInstallRecord 补 name 字段（一行改动级）。
4. CRX 过时已修：dist 包已用当前源码+原 pem 重打包（同 ID），复测 icon 渲染恢复；重打包命令见 learn 条目。

## 验收回归（2026-11-12 晚·分区隔离修复轮，多分区+重启恢复全绿）

用户验收发现「旧会话失效、新会话可用但编辑器空白」。定性：**Electron 扩展运行时按扩展 ID 全局路由（消息/存储/事件不按分区隔离）**，任意多会话场景下消息投给"当前存活"分区的 SW、storage 跨分区读写错位——与新旧无关。修复 = 分区副本目录（路径即身份，manifest 去 key → ID 路径派生分区稳定），native 隔离天然成立；恢复场景接线时对存活 SW 补挂（getAllRunning 枚举）。机制详见 learn 条目「分区隔离修复轮」。

- 复现证据：单分区全绿；appdata9（14 会话）修复前 B 会话编辑器报「截图不存在」、修复后 A/B 双侧编辑器 root 正常渲染、录屏双侧开停互不干扰（分区 ID cnodlhpl…/bdjollbo… 独立）；重启恢复会话截图+录屏全绿。
- 附带修正：驱动直调 openPopup 前必须先 list()（真实用户流程先开面板天然满足）。

## 正式环境验收轮（2026-11-12 晚）

用户正式环境（22 会话）验收仍报「旧会话所有插件失效」。定性：partition-copy **标记从未落盘**（读了标记但无写入代码）——每次会话重激活都 rm+cp 运行中扩展的加载目录，且加载器因「已加载」跳过重载 → 坏一次永久坏。修复：标记落盘 + staging→rename 换装 + 换装下已加载实例自愈重载。真机验证：旧会话×2 + 重激活路径截图/录屏全绿，22 会话数据零变动，标记 16 个落盘。

## 修复与验证（2026-11-12 修复轮，端到端全绿）

- preload-guard：桥经 contextBridge 在库 freeze 前注入主世界（页面+SW 统一），extId 调用时惰性读取。
- shims：ipcMain（页面）+ ServiceWorkerMain.ipc（SW，running-status-changed→sw.ipc.handle 逐实例注册，extId 取自 sw.scope 平台权威）双路接线；SW 重启必须重挂；downloads 实装支持 blob:（回调 offscreen 窗 fetch 转 dataURL）；capturePage 重试+stayHidden/stayAwake。
- management：popup-less 点击派发 chrome.action.onClicked（tabDetails 供 SW 用）。
- runtime：mount 时对每会话调用 registerSessionShimIpc。
- dev-entry：宿主补 impl.createWindow（库缺省抛 not implemented；编辑器窗依赖）。
- offscreen.js：无音轨时跳过 AudioContext（宿主音频如实降级），纯视频录制照常。
- 验证（隔离 userData + CDP 驱动，真机）：插件列表 icon 渲染✓；截图点击→编辑器窗打开✓→dataURL 下载真实落盘✓；录屏 popup→开始→「录制中」→停止→「已保存 recording-*.mp4」真实落盘✓→取消不落盘✓。
