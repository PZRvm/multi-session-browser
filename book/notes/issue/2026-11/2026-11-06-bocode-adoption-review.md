## 发现：B1，中，Git 未记录提交钩子的执行位

位置：.githooks/commit-msg:1（Git 文件模式）。

工作区文件已经 chmod 755，但本仓库 core.fileMode=false；`git ls-files --stage .githooks/commit-msg` 显示 100644。当前机器能执行，正常新克隆得到的文件却没有执行位，设置 hooksPath 后 Git 会忽略非可执行钩子，提交校验不能按安装说明生效。

复现：在采用 Git 文件模式的系统新克隆本提交，运行 `git config core.hooksPath .githooks`，查看 `git ls-files --stage .githooks/commit-msg` 与文件权限，尝试不合规范的提交。

建议：单独修复轮显式将 Git 索引模式记录为 100755，再从索引导出或新克隆验证实际 Git commit 的拒绝/通过路径。不修改全局 core.fileMode。
