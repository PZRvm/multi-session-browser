  - 描述：`wc.setWindowOpenHandler(({ url: openUrl }) => { if (openUrl) newTab(openUrl); return { action: 'deny' } })` —— openUrl 是页面完全可控的任意字符串，直达 `wc.loadURL(target)`，未走地址栏同规的 `normalizeInput` scheme 白名单（http/https/file/about）。后果：① 恶意页面可 `window.open('file:///...')` 在浏览 Tab 中打开本地文件（web 页面无法跨源读取该 Tab 内容，泄露面有限，但测试浏览器常访问不可信站点，spray file:// 标签页属真实可触发）；② `mailto:` 等非导航 scheme 会让 loadURL reject 被吞，留一个永远空白的 Tab，用户无解释。地址栏路径（ipc.ts navigate）已过白名单，两路不一致。
  - 证据：`manager.ts:242` `if (openUrl) newTab(openUrl)`；对照 `ipc.ts:128-131` navigate 先 `normalizeInput` 再 loadURL。
  - 建议方向：openUrl 走与地址栏一致的规范化（或至少 scheme 白名单过滤，非白名单 scheme 直接 deny 不建 Tab）。
