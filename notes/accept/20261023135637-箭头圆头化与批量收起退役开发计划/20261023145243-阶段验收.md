## 手动验收清单（需人工执行，`npm run dev` 启动）

1. **工具栏箭头**：右侧浏览器区工具栏，后退/前进两钮呈圆头描边 chevron（线条端点与转折圆角，Chrome 风格）；亮/暗主题下均清晰；无历史时前进钮呈灰色禁用；悬停有圆形蒙版；把某 Tab 拖出为独立窗口，独立窗工具栏同款。
2. **板头瘦身**：左侧板头右侧仅剩「外观入口 + 设置齿轮 + 会话 04 计数」三件，无批量钮、无收起钮；板头不再拥挤。
3. **批量零残留**：会话行点击即选中（无勾选框）；板脚恒为「新建会话」按钮；Esc、双击等不再有批量模式反应；「打开测试地址」弹层不存在。
4. **收起零残留**：板头无收起钮；分隔条恒可拖、左栏宽度 220—420；macOS 原生三灯恒显（左上角红黄绿）；重启后左栏仍为展开态。
