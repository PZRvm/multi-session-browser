## 二、手动验收指引（`npm run dev`，务必设 `MSB_USER_DATA=<空目录>` 隔离）

### 启动

```bash
MSB_USER_DATA=/tmp/msb-ws-manual npm run dev
```

### A. 切换与聚焦（PRD 3.1.5 / 验收 21）

1. 连续点板脚「新建会话」3 次，出现 3 个会话行，右侧依次切换；
2. 点板头下工作区切换框 → 下拉展开：顶部搜索框自动聚焦，列表含「全部会话」；
3. 在搜索框输入任意词（如「电」）→ 列表即时过滤；输入一个不存在名称（如「回归专项」）→ 尾行出现「＋ 新建工作区『回归专项』」；
4. 按 Enter → 进入该新工作区：左侧列表显示「该工作区尚无会话」，板脚「新建会话」仍可点；
5. 再建一个工作区「电商」，在全部视野用某会话行 `...` 菜单 →「移动到工作区…」→ 选「电商」；再移 1—2 个会话进去；
6. 在某会话页面输入文字/滚动后，切换到「电商」再切回「全部会话」再切回该会话所在工作区 → 右侧页面输入与滚动位置原样（不重载）；
7. 预期：工作区视野内只显示该工作区会话；翻牌计数 = 当前视野数；全部视野每行第二行行首有归属小标记（工作区名或「未分组」）。

### B. 过滤与键盘

1. 点开切换框 → 输入工作区名片段 → ↑↓ 移动高亮 → Enter 选中 → Esc 或点击面板外关闭；
2. 预期：键盘导航环形循环；Enter 命中高亮行（过滤无命中时 Enter 命中「新建工作区」行）。

### C. 工作区管理（右键）

1. 展开下拉 → 右键某工作区项 → 行内出现「重命名 / 删除」操作条；
2. 重命名 → 弹窗输入新名（≤20 字）→ 保存 → 列表与标记即时更新；
3. 删除（先移入 1 个会话）→ 确认弹窗明示「其中 N 个会话将移入『未分组』」→ 确定 → 会话仍在（全部视野可见、标记变「未分组」）、右侧浏览器不动；
4. 预期：同名工作区拒绝创建/改名（中文报错）；删除当前视野的工作区后回落「全部会话」。

### D. 重启恢复（验收 22）

1. 停在某工作区视野（该工作区内点过某个会话），退出应用重启；
2. 预期：组合框显示上次工作区、列表过滤一致、右侧为该工作区内上次激活的会话、列表顺序与归属不变。

### E. 零噪音基线（验收 20 前半）

1. 用全新 `MSB_USER_DATA` 目录启动（不建任何工作区）；
2. 预期：切换框收起态显示「全部会话」；会话行无归属标记；新建/批量/拖拽行为与既有版本一致。

### F. 批量作用域

1. 切到某工作区视野 → 进批量模式 → 勾选/全选/打开测试地址/关闭选中；
2. 预期：作用对象仅为当前视野内会话；跨工作区批量需切「全部会话」视野。
