## 3. GUI 手动验收项（需人工执行，编号操作路径）

启动：`npm run dev`（或 `MSB_USER_DATA=/tmp/msb-manual-ws npm run dev` 隔离数据目录）。以下每项先建数据：工作区下拉「+」新建工作区「测试组」，在其中新建 2 个会话 A、B。

1. **三键框呈现**：右键下拉中「测试组」行 → 菜单点「删除工作区」。预期：约 300ms 菜单动画后弹原生警告框，标题「删除工作区」，正文「将删除工作区「测试组」。是否同时删除其中 2 个会话？选择「保留会话」则会话移入「未分组」，会话数据不受影响。」，三键「取消 / 保留会话 / 删除全部会话」；弹框期间右侧浏览器页面内容可见不变白、不重载，主窗键盘鼠标输入被阻塞，关闭后即刻恢复。
2. **取消安全默认**：按 Enter、按 Esc、点「取消」各试一次（每次重新发起）。预期：零变化，工作区与会话原样。
3. **保留会话**：点「保留会话」。预期：弹框关闭，「测试组」从下拉消失，A、B 出现在「未分组」视野且登录态/页面数据不变；重启应用后会话仍在。
4. **删除全部会话**：重建「测试组」+ 2 会话并各开一个页面，删除时点「删除全部会话」。预期：会话与会话分区数据彻底删除（会话列表消失、重启后会话不复活），工作区删除，视野/激活级联正常（若删除的是当前视野，回落「全部会话」）。
5. **空工作区两键**：新建空工作区后删除。预期：两键「删除 / 取消」确认框（正文「该工作区没有会话。」），行为与改造前一致。
6. **失败反馈不部分执行**：代码审查路径——delete-batch 整单拒绝时工作区不删、出现行内反馈「删除工作区会话失败：会话列表已发生变化，请重试」。弹窗为窗口模态、弹框期间列表无法被改动，GUI 无法稳定构造该竞态（计划已注明以代码审查覆盖）。
7. **语言/主题随动**：设置切 English / 繁中后重复第 1 项，弹框文案随语言（按钮 Delete All Sessions / Keep Sessions 等）；外观切黑暗后弹框明暗随动（macOS）。
8. **回归**：删除单个会话（行菜单）、批量关闭选中会话两处确认框行为与改造前一致；重命名工作区、移动到工作区模态框零涉及。
