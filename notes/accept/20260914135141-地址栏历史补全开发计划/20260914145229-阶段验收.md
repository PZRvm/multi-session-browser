## 三、手动验收清单（照此从零复验）

进入应用后按序操作。**前置**：用左侧「新建会话」建两个会话（甲、乙），在甲会话地址栏输入并回车访问 2—3 个网址（如 `file:///tmp/a.html`、`https://example.com`）。

1. **输入触发**：点甲会话地址栏，输入已访问网址的 2 个以上字符 → 下方弹出建议面板（favicon + 标题左 + 网址右暗色）；输入 1 个字符 → 不弹。
2. **命中加粗**：输入的字符在网址/标题中出现时该段加粗；标题不含输入时不加粗（不硬凑）。
3. **键盘**：↓/↑ 环形移动高亮（面板可见的灰底行）；Enter 导航到高亮行；导航后地址栏显示该网址、面板收起。
4. **Esc 两段**：输入使面板弹出 → 按 Esc 一次 → 面板关闭、输入内容保留；再按 Esc → 地址栏还原为当前页面网址。
5. **鼠标**：面板行悬停高亮、点击即导航（点击不因失焦失效）。
6. **会话隔离**：点乙会话 → 地址栏输入同样字符 → **不弹任何建议**（乙无历史）；点回甲 → 建议恢复。
7. **持久化**：访问新网址后等 1 秒（去抖落盘）退出应用（Cmd+Q）；重新启动并选中甲会话 → 地址栏输入该网址片段 → 建议仍在。`MSB_USER_DATA 目录/history/<会话id>.json` 可见对应条目。
8. **克隆携带 / 删除清史**：甲会话行菜单「克隆会话」→ 克隆体地址栏输入同样片段 → 建议与甲一致；删除克隆体 → 其 history 文件消失、甲不受影响。
9. **不弹边界**：about:blank（主页按钮）不产生历史；输入无匹配字符不弹面板；删除全部会话后地址栏禁用。
10. **亮暗双主题**：板头外观入口切「黑夜」→ 面板深色底、选中行浅灰高亮清晰、无琥珀色、无阴影。
11. **独立窗口**（转人工/环境便利时）：从甲会话拖出一个 Tab 成独立窗口 → 独立窗口地址栏同样具备 1—9 行为（Toolbar 复用同构，主窗已全链验证）。
12. **Windows 平台**（转人工/环境受限）：本机无 Windows 环境，键盘/鼠标/主题链在 Windows 的实测留待人工。
