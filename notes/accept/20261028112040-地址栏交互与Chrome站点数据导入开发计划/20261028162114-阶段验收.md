## 二、地址栏融合与输入隔离

1. **融合形态**：主窗任一会话地址栏输入有历史匹配的文字（≥2 字符）→ 预期输入框下角与建议面板上角为直角、面板紧贴输入框无缝隙、接缝单发丝线无重线、面板下角保留圆角、底色连续。Esc 收起 → 输入框恢复四角圆角药丸。实测：CDP 断言 + 像素级扫描（亮 lum206 单线/暗 60）全过；亮暗两态截图见 /tmp/msb-step3-agent/shots/（81/82/83 号图）。
2. **贴边行为**：把窗口拖到屏幕最底沿输入 → 面板保持锚定按整行收窄；完全无空间时不显示面板且输入框保持独立形态；移回有空间处恢复。实测：45px 空间收窄为 1 行、-5px 拒绝展示、移回全量恢复（6/6）。
3. **新会话空输入**：会话 A 地址栏输入未提交文字 → 点左侧「新建会话」→ 新会话地址栏为空；会话 A 提交一个慢加载网址后立即新建会话 → 新会话地址栏为空（不残留待导航文本），等慢页落地后 A/B/A 往返，A 显示自己的 URL、B 干净。实测：修复前 S1/S2/S3b 全 FAIL，修复后全 PASS（含主页配置场景）。
4. **历史建议隔离**：新会话输入旧会话访问过的关键词 → 无建议（面板不开）；切回旧会话输入同词 → 建议命中。实测 PASS。
5. **需人工**（自动化不可达，逐条过）：真实鼠标拖出 Tab 成独立窗口后融合形态；中文输入法组合中按 Enter 只确认候选不提交；面板开着时真实拖动窗口贴底；Esc 退出 HTML 全屏的手感；不同缩放级别（⌘+/⌏）目检接缝。

## 三、四类型导入（原生界面全链路）

1. **入口与选择**：会话行右键/⋮ 菜单「导入 Chrome 数据…」→ 原生 sheet：Chrome Profile 下拉 + **四个内容勾选**（浏览历史/localStorage/Cookie/IndexedDB，默认全选）。实测：四勾选动态渲染 + Chrome 检出（fixture）全过。
2. **冲突裁决**：目标已有同名数据时第二段 sheet 呈现**逐类型权威摘要行**（如「localStorage（站点数据）：1 条记录与当前会话不同（涉及 1 个站点）」）+「以 Chrome 为准 / 以当前会话为准」单选。实测：摘要行渲染、policy 回传全过。
3. **执行与结果**：确认后原生结果框按类型/单位/状态汇总（完整成功/部分成功/不支持/失败/还原失败分别呈现，附真实计数）。实测：四类型结果行（done + unsupported 计数 + skipped）全过；结果框为原生模态（自动化不可点，已由日志与返回值核对内容）。
4. **Cookie**：明文记录导入（含 HttpOnly/Secure/SameSite/host-only/双 path）；v10 密文记录在未获钥匙串授权时如实计入不支持；CHIPS 与过期记录独立计数。实测：fixture 20 行 → added 12 / unsupported 7 / skipped 1，目标分区库 11 条持久 + 1 会话 Cookie（会话 Cookie 内存态不落盘属正常）；**Mac 真实钥匙串授权解密**：授权链路已由用户在真实终端打通（口令取得成功），算法/结构与真实密文的最终对账见「待操作」。
5. **IndexedDB**：同代（schema ≤15）站点快照完整导入（含 Blob 字节保真/索引/续写/重启持久）；版本过新站点（v16）整站点拒绝计入不支持、绝不拷入（防 Chromium 静默重置）。实测：v15 导入 + v16 拒 + 目标目录对拍全过；冲突两 policy（session 保留/chrome 整份替换+回滚）矩阵 10/10。
6. **生命周期**：用户放弃裁决 → 暂存即时释放（cancel 通道）；60s TTL 过期 → execute 报「导入准备已过期」且 tmp 快照零残留；执行后 cancel 幂等返回 false。实测全过。
7. **源一致性**：Cookie/IndexedDB 导入要求源 Chrome 已退出——mac 以 lsof 进程探测 + 复制后结构校验（不以 LOCK 文件存在当证据）；Chrome 运行中导入 → 如实报占用。实测：fixture 静止路径全过；真实 Chrome 运行中的拒绝路径需人工（见下）。
8. **需人工**：①真实 Chrome（已登录常用站点的 profile）完整导入一遍并在目标会话打开该站点核对登录态；②Chrome 正在运行时勾选 Cookie/IndexedDB 导入 → 预期提示关闭 Chrome 后重试；③QQ 邮箱样本（见「待操作」）；④三语界面（设置切 en-US/zh-TW）下 sheet 与结果框目检。
