## 2. 人工验收步骤（npm run dev 正式终端）

1. **红绿灯居中+左边距**：红绿灯垂直居中于工具条，且左缘留有呼吸边距（x=16）。
1b. **字号档**：文字工具档钮从左到右显「小 / 中 / 大」（32/42/54px 递增，「大」对应最大字号）。
2. **笔迹锁定**：画笔/马赛克（画笔与选区两模式）涂上后拖拽不动（定型）；矩形/椭圆/箭头/文字仍可拖（回归）；笔迹删除唯一路径 = Ctrl+Z。
3. **文字修复（重点）**：文字工具点画布 → 出现虚线框后**直接键入**（英文与中文 IME）→ 字上屏 → Enter 落版；双击重编辑；若本轮修复仍未解决，请告知现象细节（输入框是否出现/是否可聚焦/按键是否有反应），以便继续定位。
4. **裁剪确认钮**：呈主题主色实底（琥珀 #ffc133 系/雾蓝/苔绿随设置切换），字为深主题色。
5. **裁剪直退**：点「确认」→ 裁剪完成后**退出裁剪模式**回矩形工具（2026-10-14 续裁裁决）；点「取消」→ 直接退出；Esc 同语义；裁剪态 Ctrl+Z 撤框选仍工作。
6. **回归**：Ctrl+Z/Shift+Z 全工具、复制/下载产出、过期对账、× 直接关、三语、暗色。
