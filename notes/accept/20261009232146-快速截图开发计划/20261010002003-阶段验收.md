## 二、人工验收清单（需在可见窗口环境执行）

前置：dev 启动（见上），建会话「验收 A」并点击激活，开一个有内容的页面（如 https://example.com）。

1. **截图主路径**：点工具栏截图钮（DevTools 开关左侧相机钮）→ 页面无弹窗无打断；浏览器区顶部出现右对齐反馈条「已复制到剪贴板」+「下载」钮，约 2.4s 后淡出消失。到任意输入框粘贴 → 得到页面截图位图。
2. **下载次动作**：再次截图 → 反馈条出现时点「下载」→ 反馈条转「已保存：<路径>」；打开系统下载目录确认 `验收 A_YYYYMMDD-HHmmss.png` 存在且可打开、画面为该页可视区（不含左侧面板/Tab 栏/DevTools）。
3. **单槽过期**：截图 → 再截图 → 点「下载」→ 落盘的是第二张；若点第一次反馈条的下载（已被新截图覆盖）→ 反馈条红显「截图已过期，请重新截图」。
4. **同名序号**：同一秒内连续「截图+下载」两次 → 下载目录出现 `…HHmmss.png` 与 `…HHmmss-2.png`，互不覆盖。
5. **快捷键自定义**：设置 → 快捷键 → 截图行：默认键帽「无」；「录入」后按 `Cmd+Shift+C`（macOS）/ `Ctrl+Shift+C`（Windows）→ 键帽即时更新；页面聚焦态（点一下网页内）与界面聚焦态（点地址栏）分别按键 → 均触发截图出反馈条。
6. **冲突与非法**：录入 `Cmd+F` → 行内红显「与既有快捷键冲突」且原值不变；录入裸 `C` → 红显「该组合键不可用」；录入中 Esc → 取消退出录制。
7. **重启保留与清除**：设置键位后重启应用 → 键位仍在且可触发；「清除」→ 键帽回「无」，按键无行为。
8. **边界**：HTML 全屏（网页视频全屏按钮）期间按快捷键 → 不触发（壳层不可见）；零会话态截图钮禁用；独立窗口（拖出 Tab）内截图 → 反馈条出现在该独立窗、落盘文件名锚定该窗会话名；切会话后旧窗口反馈条不残留；录屏钮悬停有提示但点击无行为（inert，录屏专项未启）。
9. **三语与亮暗**：语言切 en-US / zh-TW → 反馈条、设置行、错误文案随切；亮暗两主题下反馈条与截图钮清晰可读。
