## 三、需人工执行项（自动化点击在本机验证不可靠后保留的观感验收）

按顺序操作，逐条对照预期：

1. **三钮功能**：点右上角最小化 → 窗口收任务栏；任务栏点回 → 复原。点最大化/还原 → 切换。点关闭 → 应用退出（Windows 关窗即退出）。
2. **Win11 Snap Layouts**：鼠标悬停最大化按钮 ~0.5s → 弹出系统贴靠布局浮层，选一种 → 窗口贴靠。预期：浮层为 Windows 原生样式。
3. **窗口拖动与双击**：按住左侧板头空白处拖动 → 窗口移动；按住 Tab 栏空白区（Tab 之间的空隙）拖动 → 同样移动；双击板头或 Tab 栏空白 → 最大化/还原切换。
4. **Tab 压力避让**（核心边界）：选一个会话，Ctrl+T 连开 15—20 个 Tab。预期：Tab 逐个收缩、标题省略，**最后一个 Tab 与「+」新建按钮均不进入右上角按钮区**；窗口拖宽/收窄、最大化/还原时避让实时跟随无跳变。
5. **暗色主题配色**：板头外观三段切「黑夜」→ 右上角三钮底色变深（≈#202124）、符号变浅（≈#e8eaed）；切回「白天」→ 恢复浅底深符号。预期：与 Tab 栏底色一致无色块分界。
6. **独立窗口不受影响**：拖出一个 Tab 成独立窗口 → 独立窗仍带**系统原生标题栏**，其 Tab 栏右侧**无**避让空隙（多 Tab 时排到右缘）。
7. **HTML 全屏**：会话内开视频站进全屏 → 全屏无壳层无按钮，Esc 退出后 Tab 栏与三钮恢复正常。
8. **设置窗/子窗形态**：板头齿轮开设置窗 → 仍带系统标题栏。

## 四、执行期事故记录（透明留痕）

- **事故**：自动化视觉复核时用 Win32 `SetForegroundWindow` 前置 dev 窗口静默失败（Windows 焦点权限限制），模拟点击落入用户**正在运行的正式版应用**，在真实数据误建会话「会话 1」。
- **处置**：立即停止 UI 点击自动化；从 `%APPDATA%\multi-session-browser\sessions.json` 原子移除该会话（备份 `sessions.json.bak-202610301313`）；正式版进程内存残留经覆盖安装自然关闭消解——安装后复核 sessions.json 保持 2 会话（「会话 1111」「管理员」），误建会话未回流，用户数据无损（分区数据全程未触碰）。
- **机制结论**：`MSB_USER_DATA` 隔离机制本身有效（MSYS 实测将 env 值转为 Windows 路径、setPath 生效、Chromium 层全部落入隔离目录）；事故根因是焦点前置失败导致点击目标错判，非隔离漏洞。
- **遗留物**：`sessions.json.bak-202610301313` 备份文件保留在 userData，确认无误后可删。
