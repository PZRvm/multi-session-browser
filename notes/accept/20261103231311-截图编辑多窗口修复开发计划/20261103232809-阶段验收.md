## 从零手动验收

在 iTerm 等正式终端进入 worktree，以分配端口启动；使用单独 userData，避免验收影响日常测试会话：

```bash
cd /Users/pangzerui/foreunit/multi-session-browser-wt/feature-capture-editor-multi-window
MSB_DEV_PORT=6175 MSB_USER_DATA=/tmp/msb-capture-manual npm run dev
```

1. 左侧新建一个会话，访问可展示明显内容的网页，在浏览器工具栏点击「截图」，再点通知条右侧「编辑」。预期出现 A 编辑窗，底图与页面一致。
2. 在 A 画一个矩形并保持窗口打开，回浏览器改变页面内容，再次点击「截图」→「编辑」。预期新开 B 窗，A 底图和矩形保留；两窗各显示自己的截图。本机同尺寸异内容自动化通过。
3. 回到同一条反馈条再点「编辑」。预期窗口数不变且聚焦 B；最小化 B 后再点「编辑」，预期 B 还原，原标注与撤销历史保留。自动化通过。
4. 回 A 点「复制到剪贴板」，再点「下载」，继续画标注再复制；回 B 先下载再复制。预期均成功、窗口不关闭、不切换另一张图，图片尺寸及内容正确，文件名使用拍摄时会话名，同秒同名以序号区分。自动化通过。
5. 在 A 撤销/重做、裁剪后确认并复制，观察 B。预期 A 的图幅与历史更新，B 状态不变。自动化通过。
6. 在浏览器新建一个 Tab，拖出到主窗外形成独立浏览器窗，再在那里截图并编辑；改变窗尺寸再截一张。预期两次各开独立编辑窗，每窗尺寸按各自图片适配。自动化通过。
7. 保留多个编辑窗，关闭其中一个。预期其他窗仍可产出；关闭当前最近截图编辑窗后，回反馈条再点编辑可重建。自动化通过。
8. 保留编辑窗，关闭主窗口。预期全部编辑窗关闭；macOS 点 Dock 图标重开主窗后，再截图编辑可用。自动化通过主窗关闭与 activate 重建；Dock 真实点击待人工。
9. 在多个编辑窗打开时切换应用语言及亮暗。预期文案、按钮与画布仍可用，各窗底图不被切换。英文及暗色状态自动化通过；三语完整观感、三套主题与缩放屏清晰度目检待人工。
10. 退出应用。预期所有编辑窗消失，无孤儿进程。自动化正常退出码 0，退出时编辑窗数 0。

## 并发与异常复验说明

`results.json` 的并发项使用真实写盘暂停点，确保新截图发生在下载 await 内，随后释放写盘并比对新截图 ID 与 PNG 字节；无需靠人工碰毫秒时序。关闭写盘中的编辑窗后，文件完成但条目不复活，重新编辑得到未被关闭窗口产出覆盖的当前版本。renderer 崩溃与页面 loadURL 拒绝均在隔离实例中注入，随后重开通过；注入只作用于测试进程，无源码残留。

验证脚本存于 `/tmp/msb-capture-validation-scripts/`，行为证据 JSON 与截图已复制至本目录。临时脚本最初位于 .smoke-tmp 被 ESLint 扫描，导致一次仅验证脚本的 lint 失败；移出仓库后最终 lint 退出 0，未改 lint 规则或忽略配置。验证过程中出现的未选择会话、零尺寸截图、关闭窗口异步等待与错误 DOM 主题属性断言均为脚本适配问题，最终脚本已用真实 store 激活、等待 closed 与 matchMedia 校验通过。
