## 三、需人工执行的验收项（如实标注，未自动化）

1. **macOS 真机菜单与 ⌘, 回归**：应用菜单「设置… ⌘,」在英文/中文下均可打开设置窗（自动化验证了菜单标签语言，未真实触发 click 路径——装配结构与晚绑定未改动，风险低）。
2. **建议子窗面板英文/中文文案**：需先在会话内产生 ≥2 条浏览历史（建议触发阈值），再聚焦地址栏输入触发面板；核对 aria「历史记录建议 / History suggestions」随语言。
3. **语言行下拉真实点选**：CDP 验证走 store invoke 链（与 Select onChange 同一 store.setLanguage）；真实鼠标展开下拉 → 点选 English → 观察全窗切换的手感与下拉面板视觉（抬升层底/发丝线/对勾）建议人工过一遍。
4. **Windows 平台**：菜单栏默认隐藏（autoHideMenuBar）、非 macOS 分支菜单、原生对话框按钮序——沿用 Windows 转人工惯例。
5. **英文界面长文案手感**：批量栏/行菜单/弹层在英文下的日常使用观感（布局无溢出已断言，主观密度感受建议人工）。
