## 一、启动与验证方式（可从零复现）

```bash
npm run build        # typecheck + electron-vite 构建（out/）
rm -rf /tmp/msb-accept
MSB_USER_DATA=/tmp/msb-accept \
  ./node_modules/electron/dist/Electron.app/Contents/MacOS/Electron \
  out/main/index.js --remote-debugging-port=9224
```

`MSB_USER_DATA` 隔离 userData（骨架横切约定 4，绝不触碰真实数据）；Chrome 数据侧**只读**（探测与拷贝均在导入动作内发生）。UI 链路经 CDP（`/json/list` → WebSocket → Runtime.evaluate）驱动真实渲染层：右键菜单 → 对话框 → 导入 → 结果反馈，驱动脚本模式 `SMOKE_MODE=real|fixture|none`（验收后已删除）。
