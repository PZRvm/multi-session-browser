## 三、手动验收用例（自动化已覆盖项注明证据；转人工项如实标注）

### A. 排序主链路（自动化 26/26 + 端到端 15/15 全过）

1. **新建 5 个会话**（板脚「新建会话」连点），普通模式下每一行按住拖动：
   - **下移**：拖行 1 到行 3 下半释放 → 行序变为 2,3,1,4,5；`sessions.json` 的 sessions 数组顺序同步且 activeId 不变。【证据：UI 冒烟 A2d/A2e——盘序与 UI 一致、写盘 inode 变化】
   - **上移**：拖行 5 到行 1 上半释放 → 行序 5,1,2,3,4。【A3b】
   - **首尾互换**：拖行 1 到末行下半释放。【端到端 E3b】
   - 预期：放下后**不切换激活会话**（琥珀反白行不变），右侧页面无任何变化。
2. **拖拽中视觉**：源行半透明（opacity 0.45，激活行反白随原会话保持）；目标行上/下缘出现 2px 墨色水平插入线（上半=上缘线=before，下半=下缘线=after），线不推挤行、显隐瞬切。【A2b/A2c/A4a/A4b + 亮暗双截图视觉模型目检（/tmp/msb-reorder-shots/drag-light.png、drag-dark.png）】
3. **no-op 零提交**：拖起一行放回原位 → 顺序不变、无 IPC（inode 不变实证）。【A5】
4. **取消**：拖起后按 Esc、或拖到列表外/右侧网页/窗口外释放 → 顺序不变、无残留指示（dragend 无条件清态）。【A6 覆盖 dragend 无 drop 路径；**OS 级真实拖拽（右区原生层上释放/窗外/Esc 物理按键）转人工**——CDP 无法合成 HTML5 拖拽会话；dragend 恒达是 HTML5 DnD 规范保证，风险面仅剩"指示线停留至释放"，无冻结/错序路径】
5. **多会话滚动**：建 12 个会话，列表滚动后跨多行拖拽 → 行序与落盘正确。【A10】
6. **窄栏**：拖分隔条到 220px 最窄 → 插入线全宽、源行半透明不受宽度影响（CSS left:0/right:0 无定宽，构造性覆盖）；**真实窄栏拖动手感转人工**。

### B. 右侧浏览器不变性（端到端 E1–E3）

1. 激活会话经地址栏打开 `file:///tmp/msb-reorder-page.html`（含输入框 + 2000px 长内容），在页面输入框输入标记文字、滚动到中部。
2. 打开 DevTools（工具栏「开发者工具」，aria-pressed=true）。
3. 对该会话行做首尾互换排序。
4. 预期（全部实测通过）：页面 webContents 未重建（CDP target 同源存活）、输入框文字与滚动位置原样（不重载）、DevTools 保持打开且绑定不变、激活会话不变。【E3c/E3d/E3e】

### C. 持久化与级联（端到端 E4–E6 + phase2）

1. **新建/克隆仍追加末尾**：排序后新建会话、菜单克隆会话，两者都出现在列表末位。【E4/E5】
2. **删除激活会话按新顺序首项级联**：把某会话拖到第一位，激活另一会话后删除它 → 级联激活的是当前顺序的第一行。【E6b】
3. **重启恢复**：排序后完全退出应用，同一 `MSB_USER_DATA` 再启动 → 行序、激活会话与磁盘一致。【phase2 R1/R2/R3】

### D. 互斥与回归（自动化 A7–A9、A11、A13）

1. **批量模式禁拖**：进入批量模式（板头勾选钮）→ 整列无 draggable 行；勾选/关闭选中/打开测试地址正常；退出恢复可拖。【A7/A10b】
2. **编辑态禁拖**：菜单「重命名」→ 该行不可拖（其余行可拖）；Enter/失焦提交、Esc 取消正常。【A8】
3. **交互控件起点不误触**：从「...」菜单按钮按住拖动 → dragstart 被取消（不进入拖拽态）。【A9】
4. **失败反馈**：IPC 整单拒绝时出现中文提示「会话排序失败，列表顺序已恢复」，界面回到主进程事实顺序。【A11——盘面分歧注入幽灵会话真实触发拒绝链】
5. **键盘回归**：行 Enter 激活、批量态 Space 勾选不变。【A13/A7b】
