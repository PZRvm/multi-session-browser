## 三、操作步骤与预期结果

1. 设置主页为 `https://example.com`。
2. 点 Tab 栏「+」→ 新 Tab 加载 https://example.com/，地址栏显示该地址并聚焦（focus-address 惯例保留）。
3. 页面聚焦态按 `⌘T`（点击页面内容使页面持有焦点后）→ 同上加载主页。
4. 左板「新建会话」→ 新会话首个 Tab 加载主页；克隆会话同（同一 applyRestore 兜底路径）。
5. 在被测页面执行 `window.open('https://example.org')` → 弹窗转新 Tab 且加载 example.org（**不**被主页覆盖）。
6. 会话存有多个 Tab 时完全退出再启动 → 各 Tab 按上次地址原样恢复（**不**注入主页、不额外多开）。
7. 主页设为 `file:///…` 路径或 `about:blank` → 新建 Tab 分别加载 file 页 / 空白页（白名单内直通）。
8. 清空主页提交 → 新建 Tab、新建会话均回 about:blank 空白页；工具栏主页按钮回默认。
9. 设置窗改主页为 `example.org` 回车 → 输入框回填 `https://example.org`；主窗紧接新建即用新值（changed 即时同步 + 主进程缓存即时更新）。

1. **页面聚焦态 ⌘T / Ctrl+T（核心待验项）**：CDP 合成键无法触达 WebContentsView 的 before-input-event（判别实验：既有 ⌘R reload 路径同样无法以合成键触发，证明是装置限制而非本次回归）。请在真机点击页面内容夺焦后按 ⌘T，预期新建 Tab 加载主页。代码路径：`manager.ts` case 'new-tab' → `newUserTab(tab.windowId)`，与已验证的 IPC 缺省分支共用同一函数，仅入口触发不同。
2. **克隆会话首 Tab**：与新建会话共用 applyRestore 空白兜底（同一代码路径，未单独走 UI）；可在真机右键/面板克隆任一会话复核。
3. **Windows / Linux 平台**：Ctrl+T 修饰键路径与 file:// 地址加载。
4. **独立窗（拖出标签页）内 ⌘T / +**：同组件同注入，主窗路径已验，独立窗建议复核一条。
