# 截图快捷键退役、工具栏图标气泡与 Tab 工具栏融合

> 记录时间：2026-10-29（Asia/Shanghai）
> 来源：用户本轮反馈；同日裁决修订：融合方向改为选中 Tab 对齐工具栏颜色，后退/前进 chevron 不动

## 1. 截图自定义快捷键退役

- 设置页「截图」快捷键录入行删除，版面回归固定键位速查表。
- 截图快捷键触发通道整体下线（shell 聚焦态 + 页面聚焦态），设置存储与 IPC 链同步拆除，旧配置残留容忍。
- 工具栏截图钮保留，气泡只显功能名；三语文案键族清理。

## 2. 导航四键自绘图标与悬停气泡

- 刷新、主页图标换自绘（与 chevron 同语言），观感改小；加载态停止钮的 X 一并换自绘。
- 后退/前进不动。
- 四键全部配悬停气泡，复用截图/录屏钮的气泡机制；原生 title 提示退役。
- 刷新气泡带快捷键键帽（⌘R / Ctrl+R 平台派生），其余只显功能名。

## 3. 选中 Tab 与工具栏融合

- 选中 Tab 颜色改与下方工具栏同色（亮色 #ffffff → #f1f3f4；暗色本就同值不动），工具栏背景不动。
- Tab 栏与工具栏之间的横向发丝线去掉，两者连成连续面。
- 选中 Tab 左下、右下角加反向圆角，与下方衔接柔和。
- 全部改动走 `--chrome-*` token 不写死色值，亮/暗两套主题块自动适配（外观三态经 nativeTheme 统一走同一暗色块；主题色三系不涉及 Chrome 侧），实施后亮暗双主题都要过目验。
