# 独立窗口合并回主窗口

2026-11-06 用户需求：独立窗口增加按钮，将本窗全部 Tab 合并回主窗口并关闭本窗；按钮文案与图标由开发确定，制定并执行开发计划。

- 仅独立窗口工具栏右侧提供图标钮，图形为两窗与向内箭头；气泡与无障碍名称「合并回主窗口」，繁中「合併回主視窗」、英文「Merge into main window」。
- 按源窗当前顺序追加到主窗同一会话末尾，保留源窗激活 Tab；不重建页面、不重载，不改变会话分区与 DevTools 绑定。其他独立窗口不受影响。
- 合并后切换主窗至源会话；当前工作区过滤隐藏该会话时切至其所属工作区（未分组对应未分组视野）。主窗缺席时重建，最小化时还原并聚焦。
- 主进程以 sender 决定源窗与会话，无窗口/会话/Tab 列表入参。拒绝主窗、未知来源与克隆/导入占用；并发点击单飞。失败走原生 information 框，未迁移的 Tab 留在源窗。
- 全部 Tab 归属更新后再发送快照，空独立窗沿已有机制关闭；逐 Tab 发生命周期通知供录制自动停止。
- 验收包括多 Tab 顺序/激活位、表单/滚动/登录态/webContents 身份、主窗其他会话/工作区/最小化/已关闭、重复请求与失败、三语言/亮暗/最小宽度。Windows 原生行为需人工执行。

2026-11-06 反馈：合并入口气泡右侧保留 8px，箭头按气泡实际位置对齐图标中心；按钮保持开发者工具右侧。共享气泡定位一并保证左侧 8px 边距，避免靠边提示框贴边。
