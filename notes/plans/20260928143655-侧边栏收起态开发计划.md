## 1. 当前基线

- **布局骨架**（`src/renderer/src/App.tsx`）：`MainShell` 持有 `panelWidth` 本地 state（`PANEL_MIN 220 / PANEL_MAX 420 / PANEL_DEFAULT 280`，**不持久化**），`.panel-left` 内联宽度 + `.panel-divider`（5px 命中区、`col-resize`）+ `.panel-right`；`htmlFullscreen` 时左栏与分隔条整组不渲染（`App.tsx:60-73`）。
- **左栏结构**（`src/renderer/src/components/SessionPanel.tsx`）：板头 `board-head`（契约高 40px：traffic-spacer + 外观入口 + 批量钮 + 设置齿轮 + 「会话」label + 计数砖）→ 工作区条 `workspace-bar`（下拉切换框，契约高 40px）→ 会话列表 `ul`（面板级拖拽事件委托挂 ul，行只带身份与视觉态属性）→ 板脚全宽「新建会话」主钮（文案键 `sessions.panel.newSession`）。批量态为面板本地 UI 态（`batchMode/checked` 等）。
- **会话行**（`src/renderer/src/components/SessionRow.tsx`）：状态点 `session-dot`（idle/loading 语义色）+ 名称 + 页面标题 + 备注 + 状态字 + ⋮ 菜单；整行包 contextMenu Dropdown（右键菜单受控）；拖拽经面板级委托（行上 `draggable` + `data-session-id`）；备注 Tooltip 惯例＝`mouseEnterDelay 0.2` + `getPopupContainer` 锁挂 `.session-panel`（弹层不越面板即不被右区 WebContentsView 原生层遮挡）。
- **视野过滤**（`SessionPanel.tsx:74-87`）：`activeWorkspaceId`（`'all' | 'ungrouped' | id`）驱动 `visibleSessions`，收起前所选组的会话集 = 现有视野过滤结果，**零新逻辑即可复用**。
- **红绿灯**：主窗 macOS `trafficLightPosition {x:14, y:12}`（`src/main/index.ts:182`，与板头 40px 强耦）；红绿灯为系统绘制常驻，收起态无需主进程改动。
- **overlay 机制**（`stores/ui.ts`）：菜单/弹层开启期间登记 overlay 收起右区原生层；纯 hover Tooltip（备注先例）不登记。
- **文档契约**：DESIGN.md「板头（Board Head）」「工作区切换框」「板脚」条目记录完整形态度量；PRD `docs/PRD.md` 3.1 左侧面板（3.1.1–3.1.5）+ 验收清单现至 34 条；`docs/项目骨架.md` 有 SessionPanel/SessionRow 职责行。

## 2. 范围边界

### 2.1 本阶段必须完成

- 主窗左栏「收起/展开」切换：展开态板头新增收起钮，收起态板头仅保留原生红绿灯（左侧，系统常驻）与展开钮。
- 收起态轨道：宽 48px（新常量）、工作区条不渲染、会话列表仅渲染当前视野会话的收起行（状态点 + hover Tooltip 会话名 + 点击切换会话）、板脚居中小图标新建钮。
- 收起态交互禁用面：拖拽排序、右键菜单、⋮ 菜单、行内编辑、批量模式（收起时批量态在途则先退出并清空勾选）。
- i18n 新增 2 键（收起侧边栏 / 展开侧边栏），zh/en 双语落库。
- 文档同步：PRD 3.1.6 + 验收 35、DESIGN 收起态条目与既有条目修订、`docs/项目骨架.md` 职责行。

### 2.2 本阶段明确不做

- 收起状态持久化（重启恢复展开态，与 `panelWidth` 不持久化同口径）——后续有需求另立修订。
- 收起/展开宽度动效（瞬切，离散跳变先例：设置版面切换、查找条显隐）。
- 收起态下的任何管理操作入口（重命名/克隆/移动/删除/备注/批量全不提供，展开后操作）。
- 快捷键切换收起态、独立窗口与 HTML 全屏形态的收起态（前者无左栏、后者左栏本就不渲染）。
- 主进程、`src/shared/` 类型、IPC 通道、preload 暴露面的任何变更（零新增通道）。

### 2.3 本阶段数据原则

- 收起态是纯渲染层瞬态 UI 态：不入 store 落盘、不入主进程、不产生任何 IPC；会话数据、归属、激活位、视野值零变化。
- 收起态列表如实渲染当前视野的真实会话集（含空视野：轨道区空白，不渲染空态文案——收起态零文案原则）；状态点颜色如实反映 idle/loading，不伪造加载态。
- 悬停 Tooltip 展示会话真实名称，不做截断改写。

### 2.4 契约核对

零共享类型/IPC 变更；以下为文档契约冻结点，编码前定稿、随实现同步落库：

1. **收起态度量冻结**：轨道宽 48px（`App.tsx` 常量 `PANEL_COLLAPSED_WIDTH = 48`）；收起行高 40px、状态点沿用 7px 语义色点；板脚图标钮 20×20（板头图标钮度量族）；板头/工作区条 40px 契约在收起态的呈现（板头 40px 保留、工作区条整条不渲染）。
2. **收起/展开钮位置与图标**：展开态位于板头右侧控件带**末位**（计数砖之后，紧贴分隔条——「往左收」的空间隐喻）；收起态位于板头右侧同位。图标候选 `DoubleLeftOutlined` / `DoubleRightOutlined` 对偶（最终图标与 tooltip 措辞在实现时按 AGENTS.md 走 `$impeccable` scoped 流程定稿，不绕过技能凭感觉写样式）。
3. **DESIGN「设置齿轮恒在不随左栏宽度降级」条款的显式例外**：该条款语境是宽度降级（Windows 唯一设置发现路径）；收起态是用户显式选择的模式，齿轮随板头整组隐藏、展开即恢复可达——此例外写入 DESIGN 收起态条目，避免与既有契约字面冲突。
4. **激活会话在轨道上的呈现**：沿用「选中 = 强调色反白」语义（整行 accent 反白条），状态点在反白底上用 `--accent-ink`；加载态点用 `--loading` 不反白（加载信号优先于位置信号时二者叠加按既有 loading 色呈现）。
5. **需同步更新的文档**：`docs/PRD.md`（3.1 增 3.1.6「侧边栏收起」+ 验收 35；docs/ 不入库）、`DESIGN.md`（新增「侧边栏收起态」条目 + 板头/工作区切换框/板脚条目修订）、`docs/项目骨架.md`（SessionPanel/SessionRow 职责行补收起态）、`notes/process.md`（完成时状态行）。

完成标志：本节各点在分步实施对应步骤落地后，`npm run typecheck` 通过且 DESIGN/PRD 与实现无字面冲突。
