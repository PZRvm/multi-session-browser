## 2. 范围边界

### 2.1 本阶段必须完成

- 窗形态：darwin `titleBarStyle:'hidden'` + `trafficLightPosition`（settings 先例）保留红绿灯；renderer 顶部 CSS 让位（红绿灯区不压工具条首个控件）；win/linux 保持系统框（平台注记入 DESIGN）。
- 椭圆工具钮改单纯圆形（CSS 字形）；DESIGN 图标裁决同步（审查低-2 闭环）。
- 画笔工具：自由路径绘制（`Line` points 折线、lineCap/Join round、三档粗细+色板、画后 draggable）、i18n `tools.brush` 三语。
- 马赛克双模式：工具栏马赛克激活时出「画笔 / 选区」模式切换（条件显示，同粗细选择器先例）；选区模式=现状；画笔模式=拖拽路径像素化打码（块径=块径档，路径节点画后可拖动）；导出链含画笔马赛克效果（toDataURL 合成验证）。
- 裁剪交互重构：进入裁剪工具**即**全图蒙版；拖动中选区与镂空实时跟随渲染；确认钮主题色（`--accent` 系 token）、取消钮红（danger）；Esc 取消退出裁剪；**裁剪态独立撤销栈**（⌘/Ctrl+Z 在裁剪态撤回上一次框选区域，+Shift 重做框选；确认后并入全局快照栈、清裁剪栈）；裁剪态其他工具钮禁用（锁定，确认/取消/Esc 为唯三出口）。
- 快捷键：`⌘/Ctrl+Z` 撤销、`⌘/Ctrl+Shift+Z` 重做（mac ⌘ 与 win/linux Ctrl 双识别；裁剪态路由到裁剪栈；**文本编辑态（textarea 聚焦）豁免**——交原生文本撤销，不拦截）。
- 收尾：审查遗留两项闭环（mouseup 统一清理、refreshSlotAfterApply 尺寸弱校验）、i18n 新键三语、impeccable polish 视觉轮（改动面：圆形字形/模式切换钮/确认取消配色/顶部让位）、PRD 3.10.1 与验收 39 修订、DESIGN 编辑器段修订、`docs/项目骨架.md` 核对（如无新文件则标注不适用）、三命令 + `npm run dev` 手动验证、上轮验收文档补记或新落本轮验收记录。

### 2.2 本阶段明确不做

- 马赛克的高斯模糊变体、自定义块径自由取值（仍三档）。
- 快捷键自定义/设置面（固定 ⌘/Ctrl+Z 系；与既有自定义截图快捷键体系无关）。
- 画笔独立粗细档（与形状工具共用三档）、橡皮擦。
- 裁剪选区的数值输入/比例锁定。
- Windows/Linux 自绘窗控（无标题条仅 darwin；其余平台系统框为终态）。

### 2.3 本阶段数据原则

- 沿用上计划 §2.3 全部（单槽=最近一次成品、过期如实报、零分区触达），本轮零新增数据面——改动全在编辑窗内交互层，产出链（edit-copy/edit-download）不变。
- 裁剪独立栈是**交互期瞬态**：确认才入全局快照栈（undo 域不变量「确认后的裁剪可整体撤销」保持）；取消/Esc/关窗即弃。

### 2.4 契约核对

- **无 IPC 通道/载荷变更**（shared/capture.ts 零改动）；preload 零改动。
- i18n 增键三语：`browser.captureEditor.tools.brush`（画笔/Brush/畫筆）、`browser.captureEditor.mosaicBrush`（画笔模式/Brush mode/畫筆模式）、`browser.captureEditor.mosaicRect`（选区模式/Region mode/選區模式）；zh-CN 为源、en-US/zh-TW 受完备性约束（typecheck 强制）。
- 基准文档先行修订：PRD 3.10.1 编辑小节（六→八钮口径含画笔与马赛克双模式、裁剪交互终态、快捷键、窗形态）；DESIGN.md「截图编辑器」段（图标 CSS 字形裁决、hiddenTitlebar 差异②落地、裁剪独立栈语义）；`docs/项目骨架.md`（预计无新文件——若实现拆出 mosaicBrush 渲染模块则同步条目）。
- 完成标志：i18n 三语落库 + PRD/DESIGN 段落修订落盘 + `npm run typecheck` 通过。

2. renderer/CSS 顶部让位：`.chrome-capture-editor-topbar` 首行左让（darwin 下 `-webkit-app-region` 无需拖拽带——系统红绿灯占左上 ~70px，工具条首个控件起位让出；用 `body[data-role='capture-editor']` 平台类或环境探测注入 padding，实现取最简可靠方案并注记）。
3. 椭圆工具钮：删 `AimOutlined`，改 CSS 圆形字形（span `.chrome-capture-editor-glyph-circle`：border 1.5px currentColor + border-radius 50% + 14px 见方，随 iconbtn 字号色系）；DESIGN 图标裁决同步（审查低-2 闭环注记）。
4. PRD/DESIGN 窗形态段落修订（2.4 列明）。

验收：`npm run typecheck`/`npm run lint` 通过；`npm run dev`（正式终端）macOS 下编辑窗无标题条、红绿灯三态在位且不压工具条首个控件；椭圆钮显示单纯圆形；win/linux 逻辑分支存在（代码注记即可，跨平台手动项转验收文档）。

### 步骤 2：画笔与马赛克双模式

任务：

1. `editorConstants.ts`：`Annotation` 联合扩 `'brush'`（points 折线，图像坐标）与 `'mosaicBrush'`（points + blockRadius）两型；工具枚举扩 `'brush'`；`EditorToolId` 相应。
2. `AnnotationStage.tsx`：画笔 = 拖拽采样 points（图像坐标，按显示像素步进抽稀）落版为 `Line`（stroke=色板、strokeWidth=粗细档、round cap/join、draggable 拖动写回）；马赛克画笔 = 拖拽路径像素化——实现择一（注记取舍理由）：a) 路径折线经 `sceneFunc` 构成遮蔽区域，对底图 crop+Pixelate 副本做合成（单节点，导出天然含）；b) 步进块阵列（按块径沿路径采样，每块一个小 mosaic 节点聚合为 Group）。块径取块径档、节点可拖动。
3. `EditorToolbar.tsx`：增画笔钮（`EditOutlined`，位次：箭头后、马赛克前）；马赛克激活时显「画笔/选区」模式切换两子钮（条件显示同字号档先例，aria 用新 i18n 键；模式态入 EditorWindow state 传 AnnotationStage 分派绘制行为）。
4. i18n 三键三语（2.4）。

验收：三命令通过；`npm run dev` 手动——画笔三档粗细六色可画可拖；马赛克两模式可切换：选区模式行为同旧、画笔模式涂抹处像素化（块径三档生效、Retina 无暗边——延续 #1591 修复注记）；复制/下载产物**含画笔与马赛克画笔效果**（导出合成验证）；撤销/重做覆盖新标注型。

### 步骤 3：裁剪交互重构

任务：

1. 进入裁剪工具即全图蒙版（整幅 rgba(0,0,0,.55)，未拖选时选区为空）+ 工具栏锁定（其他工具钮 disabled + 视觉禁用态；唯三出口确认/取消/Esc）。
2. 拖动实时渲染：选区镂空随指针逐帧更新（四块遮罩矩形 + 虚线框每 move 重算——Konva 受控重渲染，注意 move 事件节流至 rAF 级即可）。
3. 确认/取消钮配色：确认 = 主题色实底（`--accent-ink`/主题 token，与板面主钮同源）；取消 = 红色（danger 色系 token）。
4. Esc = 取消退出裁剪（清选区回蒙版初始态或直接退出工具——按微信语义定：清选区留在裁剪态，再 Esc 退出，实现注记）。
5. 裁剪态独立撤销栈：栈元素=框选矩形；拖完一框可再拖新框（旧框入栈，屏上只显当前框）；⌘/Ctrl+Z 撤回上一框、+Shift 重做（快捷键路由在步骤 4 接线）；确认 = `applyCropFrame` 入全局快照栈 + 清裁剪栈；取消/Esc/关窗 = 裁剪栈即弃。
6. PRD/DESIGN 裁剪交互终态段落。

验收：三命令通过；`npm run dev` 手动——选中裁剪即整图蒙版；拖动中选区实时跟随；确认主题色/取消红；Esc 生效；连拖两框后 Ctrl+Z 回到上一框；裁剪中其他工具钮不可点；确认后全局 Ctrl+Z 仍可整体撤销裁剪（回归保持）。
