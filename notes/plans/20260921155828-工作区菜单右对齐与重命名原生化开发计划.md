### 2.3 本阶段数据原则

- 确认与执行两段解耦（对齐 picker/确认框口径）：sheet 只返回结论（submitted(name) / cancelled），重命名执行仍由既有 `workspaces:rename` 通道闭环；本域不落盘、不触碰快照写入。
- 展示数据主进程权威：预填现名由主进程从权威快照现取（`currentName`），show 载荷只带 workspaceId 数据参数——渲染层不传名入 IPC、sheet 页面零事实。
- 返回语义诚实：submitted 仅当用户按下保存且 name 过主进程守卫；Esc/关窗/父窗缺失/建窗失败/工作区已消失（弹层窗口期内被并发删除）一律 cancelled，不伪造结果；守卫失败按 ipc-utils 惯例抛业务错误。
- name 双层校验不互替：sheet 侧 Input maxLength + 保存钮 trim 空 disabled 是 UI 面；主进程 pick 守卫（trim 非空 + ≤WORKSPACE_NAME_MAX）是契约面——跨 IPC 载荷防御惯例同 PICKER_IDS_MAX 先例。
